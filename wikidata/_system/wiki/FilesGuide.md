# ファイル操作

「ファイル一覧」の画面で、Wikiのページを、パソコンのファイルの一覧（エクスプローラー）と同じ形で見て、
開く・編集する・名前を変える・動かす・写す・作る・消すができます。

#img(ファイル一覧>files-list.png)

## 開きかた

**編集画面の下の「ファイル一覧」**を押すと、別のタブで開きます。編集していたページの
フォルダが開いた状態で出ます。編集中の本文はそのまま残ります。

- 左はフォルダの木、右は選んだフォルダの中身です
- 右の一覧には、名前・タイトル・更新日時・サイズ・添付の数・書きかたが並びます。見出しを押すと並べ替えます
- **フォルダ**は、中にページを持つWikiのフォルダです。入口のページ（`index`）があれば、その
  タイトルなどがフォルダの行に出ます
- Wikiのトップページは、いちばん上のフォルダに `(TopPage)` という名前で出ます
- 読む権限の無いページは出ません

右上のボタンで、アイコンの大きさ・一覧・詳細を切り替えたり、二画面にしたりできます。

## 画面の見かた

- **アドレスバー**（上）は、いまの場所をフォルダの区切りで出します。区切りを押すとそこへ
  移ります。空いたところを押すとパスを打ち込めます（Enter で移る、Esc でやめる）。
  区切りはドラッグ＆ドロップの落とし先にもなります
- **ステータスバー**（下）は、項目の数・選んでいる数（ページだけなら合計のサイズ）・切り取りや
  コピーで持っているもの・操作の結果の知らせを出します
- **二画面**にすると、2つの場所を並べて見られます（画面が横長なら左右、縦長なら上下）。
  画面のあいだでドラッグ＆ドロップや切り取り・貼り付けができます
- 表示の形と並べ替えの順は、ブラウザが覚えておき、次に開いたときも同じになります
- **ほかの人が変えた内容は、自動では出ません。** F5 か「更新」のボタンで読み直します

## 選ぶ

| 操作 | 動き |
|---|---|
| クリック | その項目だけを選ぶ |
| Ctrl を押しながらクリック | 選んだものに足す・外す |
| Shift を押しながらクリック | 前に選んだところから、そこまでをまとめて選ぶ |
| 何も無いところからドラッグ | 囲んだ項目を選ぶ（Ctrl を押しながらなら足す） |
| 矢印キー・Home・End | 選ぶ項目を動かす（Shift を押しながらなら範囲を広げる） |
| Ctrl+A | すべて選ぶ |
| Esc | 選択を外す（何も選んでいなければ、切り取り・コピーをやめる） |

## ページを開く・編集する

| 操作 | 動き |
|---|---|
| ページをダブルクリック・Enter | そのページを新しいタブで開く |
| フォルダをダブルクリック・Enter | フォルダの中に入る |
| フォルダを **Shift** を押しながらダブルクリック・Shift+Enter | フォルダの入口のページを新しいタブで開く |
| 右クリックの「ページの編集」 | そのページ（フォルダなら入口のページ）の編集画面を新しいタブで開く |

右クリックすると、そこでできることが並びます。

| フォルダを右クリック | ページを右クリック |
|---|---|
| &img(フォルダを右クリックしたところ>folder-menu.png); | &img(ページを右クリックしたところ>page-menu.png); |

- フォルダの「ページを参照」は入口のページを開きます。入口のページが無いフォルダでは
  「このフォルダにはページがありません」と出ます
- 「新しいタブで開く」「隣の画面で開く」は、ファイル一覧のままフォルダを別の場所に出します
- 「ページの編集」は、1つだけ選んでいるときに出ます
- 右クリックの代わりに、アプリケーションキーか Shift+F10 でもメニューが出ます
- 「プロパティ」は、場所・更新日時・サイズなどをまとめて見せます

## 新しく作る

ツールバーのボタンか、何も無いところを右クリックして選びます。作るとすぐ名前の入力に
なるので、名前を打って Enter を押します。

| 操作 | できるもの |
|---|---|
| 新しいフォルダ（**Ctrl+Shift+N**） | フォルダと、その入口のページ（`index`）。入口には、中のページの一覧（`#ls()`）が入る |
| 新しいテキスト ドキュメント | 新しいページ |

書きかたは、そのWikiの既定の書きかたになります（編集画面で変えられます）。

## 名前を変える

選んで **F2**、または右クリックの「名前の変更」で、名前の入力になります。

- フォルダの名前を変えると、中のページも一緒に動きます
- そのページを指していたリンクは、自動で新しい名前に直ります。添付ファイルも一緒に動きます

## 番号を振る（見出し連番）

ページを選んで右クリックの「見出し連番」を押し、開始値（`001` など）を入れると、選んだページの
名前の先頭に、いま並んでいる順に「番号.」を付けます（`001.はじめに`、`002.使いかた`…）。

- 桁数は開始値の桁数です（`01` なら2桁、`001` なら3桁。足りなくなれば桁が増えます）
- 先頭に元からある「数字.」は付け替えます。並べ替えてから振り直せます
- 同じフォルダにあって選んでいないページと名前がぶつかるときは、そのページには付けません
- 名前を変えたときと同じく、リンクは自動で直ります

## ページをフォルダにする（フォルダ化）

「フォルダ化」は、ページをフォルダとして扱えるようにする操作です。ページを選んで右クリックの
「フォルダ化」を押すと、そのページを入口として残したまま、同じ名前のフォルダを作ります。
元のページは、そのフォルダを開いたときに表示されるページ（`index`）になります。

- ページのURLは変わりません。リンクも添付ファイルもそのまま使えます
- 本文は変わりません（新しいフォルダのように `#ls()` は入りません）
- いくつか選んでまとめてフォルダにできます。編集できないページはそのまま残ります
- 中にページを作れば、ページを動かさずに下位ページを置けます

たとえば「会議記録」というページをフォルダ化すると、そのページは `/会議記録` のまま残り、
その中に `/会議記録/2026-10-07` のようなページを作れるようになります。

## 別のフォルダへ動かす

- **切り取り（Ctrl+X）→ 移し先のフォルダで貼り付け（Ctrl+V）**。フォルダを右クリックして
  「このフォルダに貼り付け」を選ぶと、中に入らずにそのフォルダへ貼り付けます
- **ドラッグ＆ドロップ**で、右の一覧のフォルダや左の木のフォルダへ落とす

いくつか選んでまとめて動かせます。動かせないものがあると、それだけが残り、残りは動きます。
名前を変えたときと同じく、リンクは自動で直ります。

名前の変更・移動・削除に時間がかかると、進み具合が出ます。［中止］を押すと、そこで止まります。

- まとめて消すときは、まだ手を付けていない項目がそのまま残ります
- **名前の変更・移動は、途中まで済んだ状態で止まります**（時間がかかりすぎたときも止まります）。
  何も無いところを右クリックして「中断した操作を続ける」を選ぶと、続きを行います。管理者と
  助手は、管理の画面の「中断した操作」からも続けられます
- 止まっているあいだ、その範囲のページの名前の変更・移動・削除はできません（編集はできます）

## コピーする

- **コピー（Ctrl+C）→ 写し先のフォルダで貼り付け（Ctrl+V）**
- **Ctrl** を押しながら、フォルダへドラッグ＆ドロップ

フォルダを写すと、中のページも全部写ります。ページと一緒に、次のものも写ります。

- **添付ファイル**
- **アクセス制限**（読める人・編集できる人を絞ったページは、写しも同じく絞られます）

写したページの中のリンクは、写し先から同じページを指すように直ります（写したページどうしの
リンクは、写しを指します）。元のページには触れません。

- 同じフォルダに貼り付けると「名前 - コピー」という名前で写します
- 写し先に同じ名前があると、上書き・スキップ・両方残すを尋ねます
- **読む権限の無いページを含むフォルダは写せません**
- トップページ `(TopPage)` は写せません

## 消す

選んで **Delete**、または右クリックの「削除」を押し、確かめのダイアログで「はい」を押します。

- フォルダを消すと、中のページも全部消えます
- **添付ファイルは `/trashbox` へ移ります**（編集画面で本文を空にして保存したときと同じ）。
  添付のあるページを消すときは、そのことを知らせるダイアログが出ます。
  `/trashbox` は管理者と助手だけが開けるので、添付を戻したいときは管理者か助手に頼みます
- 消したページの内容は[変更履歴](/BackupGuide)に残ります。同じ名前のページの編集画面の
  「履歴」タブから戻せます

## できないこと

- **トップページ** `(TopPage)` は、名前を変える・動かす・写す・消すができません
- 名前を変える・動かす・消すには、**動くページすべてを編集できる**必要があります。
  できない項目は、メニューやボタンが灰色になります
- 名前に使えないもの: `/`、`.` や `=` で始まる名前、`.txt` のように添付ファイルの拡張子で終わる名前

## キー操作

| キー | 動き |
|---|---|
| Enter | 開く（Shift+Enter でフォルダの入口のページ） |
| 矢印キー・Home・End / Ctrl+A / Esc | 選ぶ（上の「選ぶ」） |
| アプリケーションキー・Shift+F10 | 右クリックのメニューを出す |
| F2 | 名前の変更 |
| Ctrl+X / Ctrl+C / Ctrl+V | 切り取り / コピー / 貼り付け |
| Delete | 削除 |
| Ctrl+Shift+N | 新しいフォルダ |
| Backspace・Alt+← / Alt+→ | 戻る / 進む |
| Alt+↑ | 上のフォルダへ |
| F5 | 最新の情報に更新 |
