PukiWiki記法の''整形済みテキスト''の書きかたです。書きかたの枠のすぐ下に、その表示が並びます。

#contents

* 整形済みテキスト [#pre]

''行の始まりを半角スペースにする''と、書いたままの形で出ます。

#code(pukiwiki){{
 def hello():
     print("こんにちは")
}}

↓ こう表示されます

 def hello():
     print("こんにちは")

行頭のスペース1つは取り除かれ、2つ目以降の字下げは残ります。中の記法は解釈されません。

** 枠をつけて見せる（#pre）

[[#pre>/Syntax/Plugin/pre]] プラグインなら、行頭のスペースは要らず、枠や背景色も付けられます。

#code(pukiwiki){{{
#pre(){{
def hello():
    print("こんにちは")
}}
}}}

↓ こう表示されます

#pre(){{
def hello():
    print("こんにちは")
}}

コピー用のボタンを付けたり、背景色を変えたりもできます。

#code(pukiwiki){{{
#pre(copy, color=#eef4ff){curl https://example.com/}
}}}

↓ こう表示されます

#pre(copy, color=#eef4ff){curl https://example.com/}

** 中身の飾りを活かす（verb）

整形済みテキスト・#pre・#code は、中身をそのままの文字として出します。
#pre に ''verb'' を付けたときだけ、中身の''インライン記法・インラインプラグイン''が展開されます。

#code(pukiwiki){{{
#pre(verb){{
''強調''と &size(150%){大きな文字}; が効きます
}}
}}}

↓ こう表示されます

#pre(verb){{
''強調''と &size(150%){大きな文字}; が効きます
}}

- 中身に波かっこが出てくるときは、上の例のように波かっこ2つで挟みます（閉じる波かっこ2つが中に出るなら3つ）
- 見出しや箇条書きのような''行単位の書きかたは展開されません''

** 使い分け

|~書きかた|~中身の展開|~色分け|~向いているもの|h
|行頭にスペース|しない|なし|ちょっとした桁揃え、短い抜き書き|
|#pre()|しない|なし|枠や背景色、コピーボタンを付けたいとき|
|#pre(verb)|インラインだけ|なし|等幅のまま一部を飾りたいとき|
|#code(言語)|しない|''あり''|プログラムのコード|

色分けは [[#code>/Syntax/Plugin/code]] で言語名を指定します（このページの「書きかた」の枠）。
