# ページ編集

ブラウザの編集画面で、ページを書く・直す・消す方法です。編集の始めかたは [編集する](/UsageGuide/Edit)、
書く内容（書きかた・プラグイン）は [書きかた](/Syntax) にあります。

## 編集画面

#img(編集画面>/UsageGuide/Edit/edit-screen.png)

| タブ | できること |
|---|---|
| 編集画面 | 左の入力欄に書き、右の**プレビュー**で仕上がりをすぐ確かめる。上のツールバーで見出し・太字・リンクなどを挿入できる |
| 更新状況 | 保存されている内容と、いま書いている内容の差分を見比べる（[ページの履歴管理](/UsageGuide/Edit/History#保存した内容と比べる)） |
| 添付ファイル | 画像やファイルを足す・消す・別のページへ移す（[添付ファイル](/UsageGuide/Edit/Attach)） |
| 履歴 | そのページの変更の記録を見て、過去の内容に戻す（[変更履歴](/BackupGuide)） |

| 更新状況 | 添付ファイル |
|---|---|
| &img(更新状況のタブ>/UsageGuide/Edit/diff-tab.png, w100%); | &img(添付ファイルのタブ>/UsageGuide/Edit/attach-tab.png, w100%); |

左のサイドバーには、メニューの代わりに**ページ一覧**が出ます（[下記](#ページ一覧)）。
画面の高さが足りないときは、ツールバーや足もとのボタンが省かれ、書く欄が広くなります。

### ボタン

| ボタン | 動き |
|---|---|
| 保存（**Ctrl+S**） | 保存する。差分が自動で記録される。**連続編集**のチェックがあれば編集画面に留まり、無ければページに戻る |
| 一時中断（**Esc**） | 書きかけを預けてページに戻る。次に編集画面を開くと続きから書ける |
| 内容破棄 | 預けてある書きかけを消す（取り消せないので確認が出ます）。戻り先は保存と同じ |
| ファイル一覧 | 別のタブで[ファイル一覧](/FilesGuide)を開く。ページやフォルダの名前の変更・移動・コピー・削除・新規作成はここから |
| 連続編集（チェック） | 入っていると、保存・内容破棄のあともページに戻らず、そのまま書き続けられる。初めは入っていて、外すとその選択を覚えておく。ページへは「一時中断」か右上の「ページを見る」で戻る |

**「一時中断」は書きかけを残し、「内容破棄」は消します。**

### ツールバーと書きかた

ツールバーのボタンで、選んだ文字を囲む・行頭に記号を付ける・定型文を入れる、ができます。
何も選ばずに押すと、見本の文字が入ります。

**書きかた（Markdown／PukiWiki）は、ツールバーの右端のラジオボタンで選び直せます。**
初めは、開いたページの拡張子（`.md`／`.txt`）で決まります。まだ無いページは PukiWiki記法で始まります。

- プレビューは、選び直した書きかたですぐ確かめられます
- 保存すると、選んだ書きかたの拡張子（`.md`／`.txt`）のファイルになります。拡張子が変わっても、ページの名前（URL）は変わりません
- **本文は自動では変換されません。** 書きかたを移すときは、自分で書き直します

書きかたは [Markdown記法](/Syntax/Markdown)・[PukiWiki記法](/Syntax/PukiWiki)・[共通の書きかた](/Syntax/Common) にあります。

### ページ一覧

編集画面のサイドバーのページ一覧は、次に開くページをその場で選ぶためのものです。

- 行には**ページのタイトル**かファイル名が出ます。一覧の上の帯（**自動**・**ファイル名**・**タイトル**）で切り替えられ、選んだものは次に開くときも同じです。出していないほうは、行にマウスを乗せると分かります。長い名前は「…」で切れます
  - **自動**: ページの書きかたごとの設定に従います（初めの設定では、Markdownはタイトル、PukiWiki記法はファイル名）
  - **ファイル名**・**タイトル**: すべての行をそろえます
- 並びは、出している名前の順です（ファイル名を出していればファイル名順、タイトルならタイトル順）。いずれも、フォルダが先でページが後です
- 選んでいる行（塗りつぶし）が、いま編集しているページです
- フォルダの行がその中の `index` を兼ねます。トップページは `(TopPage)` の行です
- 開けるのは上下左右の矢印キーでもできます。Enterで決定、Tabで本文の欄へ移ります
- サイドバーとの境目をドラッグすると幅を変えられ、次に開くときも同じ幅です
- 画面が狭いときは、一覧は閉じていて、左上の三本線のボタンで開きます。一覧の外・行を押す・`Esc` で閉じます

## ページの名前とフォルダ

ページの名前は、`Tech/ThemeGuide` のようにフォルダでまとめられます。**下位のページを作るときは、
同じ名前のページを自動でフォルダに作り替えます。**

```
Tech/ChangeLog.md    →   Tech/ChangeLog/index.md   ＋  Tech/ChangeLog/2026-08-11.md（新しいページ）
```

URLは `/Tech/ChangeLog` のままで、リンクも添付も切れません。下位のページを全部消して入口の `index` だけに
なったフォルダは、元のページに戻ります。

### ページの名前のルール

- `=` と `.` で始まる名前は使えません（`=` は別Wikiの指定、`.` はシステムの画面）
- `memo.txt` のように添付ファイルの拡張子で終わる名前は使えません（リンクに書くと添付ファイルと読まれるため）。`ver1.2` は使えます

詳しくは [共通の書きかた](/Syntax/Common#ページの名前のルール)。

## ページを消す

**本文をすべて消して保存すると、ページは削除されます。** 空白や改行だけでも削除になります。
保存を押すと、消してよいかを［はい］［いいえ］で確かめます（初めは［いいえ］が選ばれています）。

- そのページの添付ファイルは、`/trashbox`（管理者と助手だけが開けるページ）へ移ります。添付のあるページでは、確かめるときにそのことも知らせます。消した本人は自分では取り戻せません
- 消える直前の内容は変更の記録に残るので、[履歴](/BackupGuide)から戻せます（添付は戻りません）
- **連続編集**のチェックがあれば、消したあとも同じ名前の（まだ無い）ページの編集画面に留まります。そのまま書いて保存すると、ページを作り直せます
- まだ無いページを空のまま保存しても、ページは作られません
- ファイル一覧からも消せます（[ファイル操作](/FilesGuide#消す)）

## 保存したときに起きること

- 差分が自動で記録されます。10分以内の保存はまとめて1つの記録になります（少しずつ直しても、記録が推敲の途中だらけになりません）
