# ページの履歴管理

書いている途中の内容と、保存したあとの内容を、守る・比べる・戻す方法です。ブラウザの編集画面の使いかたは
[ページ編集](/UsageGuide/Edit/Page)、記録の見かたと、過去の内容へ戻す操作は [変更履歴](/BackupGuide) にあります（このページは、書きかけの預かり・差分・同時に編集されたときです）。

| やりたいこと | 使うもの |
|---|---|
| 書きかけを残して、あとで続きを書く | [書きかけの預かり](#書きかけは自動で預けられる) |
| 保存した内容といま書いている内容を比べる | 編集画面の「更新状況」タブ（[下記](#保存した内容と比べる)） |
| 別の人の保存と食い違った | [統合する画面](#同時に編集されていたとき) |
| 過去の内容に戻す | 編集画面の「履歴」タブ（[変更履歴](/BackupGuide#前の状態に戻す)） |
| 消したページを戻す | 同上（[下記](#消したページを戻す)） |

## 書きかけは自動で預けられる

- 入力が30秒止まるたびに、書きかけが自動で預けられます
- ページ一覧から別のページを選ぶときも、預けてから移ります
- 預けた書きかけは、次に編集画面を開いたときに、続きとして出ます。預かりがあるページは、ページ一覧に**赤い太字**で出ます
- 保存すると、書きかけは消えます
- 預けた書きかけは、保存したことにはなりません。変更の記録にも残りません
- 預けられなかったときは、その場に知らせが出ます
- ブラウザの戻る・URLの直接入力など、ページ一覧以外から離れるときは、確認が出ます

## 保存した内容と比べる

編集画面の**「更新状況」タブ**で、保存されている内容と、いま書いている内容の差分を見比べられます。
差分は、書くたびに取り直されます。

## 同時に編集されていたとき

書いている間に同じページが別に保存されていると、保存を押したときに**統合する画面**が
開きます。左が相手の更新、右が自分の編集です。相手の変更を相違点ごとに矢印で右へ
取り込んでから保存してください（**右がそのまま保存されます**）。初めは1行ごとに取り込み、
「まとめて」に切り替えることもできます。

書いた内容は預かってあるので、この画面を離れても失われません。「編集画面へ戻る」で戻り、
そのまま保存すると、またこの画面に来ます。統合した結果が空のとき・いまのページと同じときは保存できません。
過去の内容へ戻した（履歴からの復元）あとも、書きかけがあれば同じ画面で突き合わせます。

## 前の状態に戻す

編集画面の**「履歴」タブ**で戻します。「すべて戻す」と、「部分的に戻す」（まとめて・1行ごと）があります。
手順・ボタンの意味・図は [変更履歴](/BackupGuide#前の状態に戻す) にあります。

## 消したページを戻す

**消したページの記録も残ります。** 同じ名前のページの編集画面を開き（まだ無いページとして開きます）、
「履歴」タブを選ぶと見られ、戻すこともできます。ページを消したときに `/trashbox` へ移った添付ファイルは、
履歴からは戻りません（[ページ編集](/UsageGuide/Edit/Page#ページを消す)）。

仕組みは [保存の仕組み](/Tech/EditGuide/Save)・[変更履歴の仕組み](/Tech/BackupUI)・[統合する画面の仕組み](/Tech/ConflictMerge) にあります。
