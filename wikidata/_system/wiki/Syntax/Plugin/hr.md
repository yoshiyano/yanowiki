# hr — 水平線（区切り線）を引く

| 使える記法 | |
|---|---|
| ブロック `#hr()` | ○ |
| インライン `&hr();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

段落の間に短い横線を引きます。本家PukiWikiの `hr` の移植で、引数はありません。

### 書きかた

```pukiwiki
前の段落です。

#hr()

後の段落です。
```

表示:

前の段落です。

#hr()

後の段落です。

出力は `<hr class="short_line">` です。本文に直接 `---`（Markdown）・`----`（PukiWiki）と書いた線（クラスなしの `<hr>`）とは、
幅80%・中央寄せの見た目で区別されます（本家の `pukiwiki.css` の `.short_line` と同じ）。

### エラーについて

引数を書くとエラーになります。インライン（`&hr();`）でもエラーです。

```pukiwiki
#hr(foo)
```

#hr(foo)

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
