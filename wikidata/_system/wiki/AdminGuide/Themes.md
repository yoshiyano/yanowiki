# テーマと見た目

Wiki全体の見た目を変える方法です。ここに書く操作は、そのWikiの管理者と助手が行います。
読む人が自分のブラウザで見た目を選ぶ方法は [見た目を変えよう](/ThemeGuide) にあります。

## 設定で変える

[Wikiの設定](/AdminGuide/Config) の「テーマと画面」タブで変えます（`config/default.yaml` の `theme:`）。

| 画面の項目 | 設定のキー | 中身 |
|---|---|---|
| テーマ | `theme.name` | そのWikiの既定のテーマ（例: `base`）。一覧から選ぶ。提供されたテーマと、このWiki専用（local）のテーマの両方が並ぶ |
| サイト名 | `theme.site_title` | ヘッダに出す名前 |
| テーマを選ぶセレクタを出す | `theme.selector` | メニューの先頭に、読む人がテーマを選ぶ欄を出す |
| サイドバー上段のページ・下段のページ | `theme.menu1_page`・`theme.menu2_page` | メニューにするページ（既定は `mainmenu`・`submenu`） |
| 上段・下段を開いたままにするページ | `theme.menu1_mode`・`theme.menu2_mode` | 狭い画面でも、メニューを畳まずに出すページ |
| 標準の拡大率（%） | `theme.zoom` | ページを開いたときの拡大率（70〜165から選ぶ。既定は100）。ページ全体が同じ比率で変わる |
| 本文の幅の上限を、標準で外す | `theme.content_wide` | ページを開いたとき、本文の幅の上限を外した状態にする（既定は上限あり） |

標準の拡大率と幅は、読む人がボタンで選んだ値があれば、そのブラウザでは**読む人の選択が先**です。
拡大縮小のボタンが無いテーマ（pkwk・post_it_1）では、読む人が選べないので標準の拡大率だけが効きます。
幅の上限を外す設定は、そのボタンのあるテーマ（base・fresh・bloom・post_it_1・pukiwiki_default・pkwk）にだけ効き、
スロット型のテーマと tdiary 系のテーマには効きません。編集画面など、テーマを使わない画面には、どちらも効きません。

目次に入れる見出しの深さは、「Markdown」タブの「目次に出す深さ」（`markdown.toc_depth`）です。

## 2種類のテーマ

| | スロット型のテーマ（おすすめ） | Jinja2 のテーマ |
|---|---|---|
| 向いていること | 配色・配置・ロゴなど、簡単なデザイン変更 | 構造から作り直す、複雑なテーマ |
| 書くもの | 目印を付けた HTML と、CSS・画像・フォント | テンプレート（式・ループ・継承）と、CSS・画像・JavaScript |
| 置き場所 | `slottheme/`（そのWiki用は `wikidata/<Wiki名>/slottheme/`） | `theme/`（そのWiki用は `wikidata/<Wiki名>/theme/`） |
| 安全 | テーマからプログラムもスクリプトも動かない | テンプレートからサーバのプログラムを動かせる |
| 作れる人 | 管理者と助手（テーマのファイルの画面） | Wiki の設置者（サーバを管理する人） |
| 書きかた | [スロット型のテーマでデザインを変える](/SlotThemeGuide) | [テーマの開発](/Tech/ThemeGuide) |

そのWiki用のテーマ・ファイルは、全Wiki共通のものより先に使われます。共通のものを写して直せば、そのWikiだけ見た目が変わります。

## テーマのファイルの画面

管理者メニューの「テーマのファイル」（`/.admin/themes/`）で、テーマのファイルを扱います。

#img(themefiles.png)

左のツリーに4つのフォルダが並びます。

| フォルダ | 中身 | できること |
|---|---|---|
| `common` | 全Wiki共通の Jinja2 のテーマ | 見るだけ・コピー |
| `sitetheme` | このWiki用の Jinja2 のテーマ | CSS と画像の追加・編集。html はコピーだけ |
| `slotcommon` | 全Wiki共通のスロット型のテーマ | 見るだけ・コピー |
| `slottheme` | このWiki用のスロット型のテーマ | HTML・CSS・画像・フォントの追加・編集 |

助手が初めから使えるのは `common`・`slotcommon`・`slottheme` です。`sitetheme` は管理者だけですが、
管理者は [助手の権限](/AdminGuide/StaffPerms) で、助手ごとに見せる・編集させることができます。

### 共通のテーマから写す

共通のテーマは直接は直せないので、このWiki用のフォルダへ写してから直します。

1. `common` で写したいファイル（またはフォルダ）を右クリックし、「sitetheme へコピー」を押します

   #img(themes-copy-menu.png)

2. このWiki用のフォルダ（`sitetheme`）の同じ場所へ写り、そのフォルダが開きます。下の帯に、写した件数が出ます

   #img(themes-copied.png)

3. 同じ名前のファイルが既にあるときは、上書きするかを尋ねます。
   「はい」で上書きし（前のファイルはごみ箱へ移ります）、「いいえ」なら、それを飛ばして残りを写します

   #img(themes-overwrite.png)

スロット型のテーマも同じで、`slotcommon` のファイルを右クリックして「slottheme へコピー」を押すと、`slottheme` へ写ります。

#img(themes-slot-copy.png)

Ctrl+C で写して貼り付ける、ドラッグする、でも写せます（こちらは写す先を自分で選びます）。

### ファイルを置く（アップロード）

ツールバーのアップロードのボタンか、ファイルの無いところを右クリックして「アップロード」を押すと、ダイアログが出ます。
「ファイルを選ぶ…」「フォルダを選ぶ…」で選ぶか、ファイルをダイアログにドロップして、「アップロード」を押します。
ダイアログを開かずに、ほかのアプリからファイルを一覧へドロップしても置けます。

#img(themes-upload.png)

1ファイルの大きさの上限は、添付ファイルと同じです。置けるファイルは、フォルダで決まっています。

| | sitetheme | slottheme |
|---|---|---|
| アップロード | CSS と画像（png・jpg・jpeg・gif・webp・avif・ico） | HTML・CSS・画像・フォント（woff・woff2） |
| テキストの編集 | CSS | HTML・CSS |
| 名前の変更 | ほかの種類のファイルを html・js・svg などにはできない | HTML・CSS・画像・フォント以外にはできない |

新しいファイル・フォルダ、名前の変更、移動、削除は、ふつうのファイル一覧と同じです。消したものはごみ箱から戻せます。

### テキストを編集する

CSS（`slottheme` では HTML も）を右クリックして「テキストを編集」を押すと、中身を直せます。
直したら「保存」（Ctrl+S でも）、やめるときは「キャンセル」です。

#img(themes-edit.png)

保存すると前の中身は残りません。大きく直す前は、共通のテーマから写し直せることを頼りにしてください。

### 保存できないとき（slottheme）

`slottheme` の HTML・CSS は、描くときに取り除かれるもの（`<script>`・`onclick`・`@import`・外への `url()` など）が
入っていると保存されません。テキストの編集では、ダイアログの下に理由が赤い字で出て、書いた中身のまま残ります。
理由に出たものを消してから、もう一度「保存」を押します。

#img(themes-slot-refuse.png)

アップロードでも、同じ理由のファイルは置かれません。書ける HTML・CSS は [スロット型のテーマでデザインを変える](/SlotThemeGuide#書けないもの) にあります。

### 例: 標準のテーマの色を変える

1. `common` の `base.css` を「sitetheme へコピー」で写す（[共通のテーマから写す](#共通のテーマから写す)）
2. `sitetheme` の `base.css` を「テキストを編集」で開く（[テキストを編集する](#テキストを編集する)）
3. 先頭の `:root { … }` の色を書き換えて保存

```css
:root {
  --bg: #ffffff;      /* 背景の色 */
  --fg: #1f2328;      /* 文字の色 */
  --accent: #0969da;  /* リンクの色 */
  --panel-bg: #f6f8fa;/* サイドバーの色 */
  --table-border: #d0d7de; /* 表の罫線の色 */
}
```

端末がダークモードのときの色は、そのすぐ下の `@media (prefers-color-scheme: dark)` の中にあります。

`base.css` を読み込むテーマ（`base` のほか、`fresh`・`pukiwiki_default` など）にも効きます。テーマが自分で色を上書きしているところは変わりません。

### 操作の記録

助手が `slottheme` で行った操作（追加・編集・名前の変更・移動・削除・ごみ箱から戻す）は、
[助手の操作の記録](/AdminGuide/Maintenance#助手の操作の記録) に残ります。編集は前の中身も控えます。
