# タイトルの扱い（1行目のh1）

Markdownの1行目のh1をページタイトルとして扱う仕組みです（目次を扱うプラグインに関係します）。

`first_h1_as_title` が有効なとき、文書の**先頭ブロック**がh1なら、それをタイトルとして取り出し、本文と目次から
取り除きます（設定は[プラグイン開発#レンダリングの設定](/Tech/dev_plugin#レンダリングの設定)）。

**この扱いはMarkdown（`.md`）だけのものです。** PukiWiki記法（`.txt`）ではページ名が
そのままタイトルなので、設定にかかわらず抜き出しません（`render.uses_title_heading`）。

文章が始まったあとのh1は、最初のh1でも章見出しです。構文の拡張ではないので、GitHubなどで開いても普通に読めます。

## 目次のlevelについて

`build_toc()` が返す `level` は、そのページで最も浅い見出しを1とした相対的な深さです。
`# タイトル` + `## 節` でも `# タイトル` + `# 章` でも、目次の字下げが同じになります。

## 副作用

- 1つの文書に複数の `<h1>` が出ます（HTML5では許容されるが、タイトルと章を区別できない）
- タイトルは本文から取り除かれるので、テーマが `page_title` を描画します（標準テーマの `page_heading` ブロック）

`first_h1_as_title: false` にすると、1行目のh1も本文中の見出しとしてそのまま描画され、目次にも並びます。
