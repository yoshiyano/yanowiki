PukiWiki記法の、文字の飾りや注釈、保存したときに自動で入るものの書きかたです。書きかたの枠のすぐ下に、その表示が並びます。

#contents

* 文字を飾る [#inline]

ここからは[[インライン>/Syntax/PukiWiki#kind]]の書きかたです。

#code(pukiwiki){{
''強調''
'''斜体'''
%%打ち消し%%
%%%下線%%%
}}

↓ こう表示されます

''強調'' / '''斜体''' / %%打ち消し%% / %%%下線%%%

#note(type=warn){囲む記号はシングルクォート（Shift+7）です。ダブルクォートではありません。''強調が2つ、斜体が3つ''です。}

* 注釈 [#note]

''(('' と ''))'' で囲むと、中身がページの末尾にまとまります。

#code(pukiwiki){{
本文中に注釈((ここに書いた文章が、ページの末尾にまとまって出ます))を挟めます。
}}

↓ こう表示されます

本文中に注釈((ここに書いた文章が、ページの末尾にまとまって出ます))を挟めます。

- 本文に出るのは番号だけで、マウスを乗せると中身が出ます（長いものは途中まで）
- 番号を押すと末尾の一覧へ飛び、一覧の矢印で戻れます
- 注釈の中でも飾りやリンク、注釈が使えます

* 書いても表示されないもの [#hidden]

行頭に ''//'' を書くと、その行は表示されません。

#code(pukiwiki){{
// この行は表示されません
}}

* 日付を自動で入れる [#subst]

''開くたびに、そのときの値''に置き換わります。

#code(pukiwiki){{
&_date;      今日の日付
&_time;      いまの時刻
&_now;       日付と時刻
&lastmod;    このページを最後に更新した日時
}}

↓ こう表示されます

|~書きかた|~表示|h
|今日の日付|&_date;|
|いまの時刻|&_time;|
|日付と時刻|&_now;|
|最後に更新した日時|&lastmod;|

#note(type=warn){''名前の先頭のアンダースコア（_）が要ります。'' 下線の無い &amp;date; &amp;time; &amp;now; は、保存時に一度だけ置き換わる別のもの（下の節）です。}

* ページ名を自動で入れる [#pagename]

''保存したときに一度だけ''、編集中のページ名に置き換わります（本文には値だけが残ります）。

#code(pukiwiki){{
page=&page; / fpage=&fpage;
}}

「hogehoge/hoge」で保存すると、本文はこうなります。

#code(pukiwiki){{
page=hoge / fpage=hogehoge/hoge
}}

&amp;fpage; はページ名そのまま、&amp;page; は最後の階層だけです。
&amp;date; &amp;time; &amp;now;（日付・時刻・両方）と &amp;t;（タブ文字）も、保存時に一度だけ置き換わります
（開くたびに置き換わる[[日付の自動入力>#subst]]とは別です）。

* 顔文字を出す [#facemark]

決まった名前を書くと、絵文字に置き換わります。

#code(pukiwiki){{
&heart; &smile; &bigsmile; &wink; &sad;
}}

↓ こう表示されます

&heart; &smile; &bigsmile; &wink; &sad;

使える名前は設定ファイル（config/pukiwiki.extrarules.example.yaml、Wikiごとなら wikidata/<Wiki名>/config/pukiwiki.extrarules.yaml）で
管理者が決めます。同じ仕組みで、文字列を置き換える「ユーザ定義ルール」も足せます。

* 文字参照 [#charref]

HTMLの文字参照（&amp;amp; や &amp;#38;）が、allow_html の設定に関わらず使えます。

#code(pukiwiki){{
1 &lt; 2 &amp;&amp; 3 &gt; 2
}}

↓ こう表示されます

1 &lt; 2 &amp;&amp; 3 &gt; 2

プラグインの書きかたそのものを見せるときに使います。

#code(pukiwiki){{
&amp;counter;
}}

↓ こう表示されます

&amp;counter;

プラグインとして呼び出されず、文字列だけが出ます。
