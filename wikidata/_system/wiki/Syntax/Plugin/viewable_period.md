# viewable_period — 指定した期間の外ではページの本文を表示しない

| 使える記法 | |
|---|---|
| ブロック `#viewable_period()` | ○ |
| インライン `&viewable_period();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

指定した期間の外では、ページの本文の代わりに案内文を表示します。「公開は来月から」「掲載期間が終わった」のように、見せるのを一時的に止めたいときに使います。

### 書きかた

```pukiwiki
#viewable_period(start,end)
#viewable_period(start,end){期間外に出す1行の案内文}
#viewable_period(start,end){{
複数行の案内文
}}
#viewable_period(start,end,editor1,editor2,...)
```

| 引数 | 書式 | 既定 | 意味 |
|---|---|---|---|
| `start` | `YYYY/MM/DD HH:MM:SS` | 制限なし | 表示を始める日時 |
| `end` | 同上 | 制限なし | 表示を終える日時 |
| `editors` | ログインIDを `,` 区切りで列挙（`end` のうしろ） | なし | 期間外でも本文を見られる編集者 |

- `start`・`end` は位置引数で、どちらも省略できます（両方省略すると常に表示）
- 案内文を省略すると「このページは現在閲覧できません。」と出ます。案内文には記法やプラグインを書けます
- 同じページに複数書かれていれば、先のものが効きます（あとのものは黙って無視）

### 日時の書式

- 年月日は `/`、時刻は `:` で区切ります。年は4桁・2桁（`2000+YY` 年）・省略（`MM/DD`）のどれでも書けます
- 時刻を省略すると、`start` は `00:00:00`、`end` は `23:59:59` です。`HH:MM` も書けますが、`HH` だけは書けません
- 境界は両端を含みます
- 年を省略したときの年:
  - `end` があるとき: まず `end` の年を決め、`start` は「`end` 以前で、今日より後のいちばん近い年」（無ければ今日より前のいちばん近い年）
  - `end` が無いとき: `start` は「ページの最終更新日以降で、最初にそのMM/DDを迎える年」

**`end` はページの最終更新日より過去にできません。** 保存すると最終更新日が今日になるので、今日のうちに終わったことにしたいときは、時刻まで書いてすでに過ぎた時点を指定してください（`2026/09/05 00:00:00` など）。日付だけだと、その日の `23:59:59` まで表示されます。
`start` は過去でもかまいませんが、`end` より後にはできません。

### 編集者を指定する

`end` のうしろに並べたIDでログインしている人は、期間外でも本文を見られます。公開前・公開後に自分で下見するためのものです。`editors` が無ければ、期間外は書いた本人でも見られません。

その人には、期間の内外を問わず、本文の先頭に「ページ表示期間設定」のパネル（`fieldset.viewable-period`）が出ます。
中身は、いまの状態（**閲覧可能**＝緑／**閲覧不能**＝赤）、表示可能期間、編集者の一覧です。ほかの閲覧者には出ません。

```pukiwiki
#viewable_period(2099/01/01, 2099/12/31, alice, bob){{
**近日公開予定です。**
}}
本文です。
```

2099年より前にこのページを開くと、`alice`・`bob` には閲覧不能のパネルと本文が、ほかの人には「**近日公開予定です。**」だけが出ます。
存在しないIDを書いても、エラーにはならず特例にならないだけです。

### これは「見せない」であって「読ませない」ではない

止まるのは、ページを開いたときの本文の表示だけです。**秘密を守る用途には使えません。**
編集の権限がある人には編集ボタンもふだんどおり出て、次からも本文を読めます。

- 編集画面（「履歴」タブも含む）
- 検索結果の抜粋、`#ls`・`#recent` に出るタイトル

例外は2つです。

- セクション編集（`/.section/<ページ名>`）は、期間外のページでは取り出しも保存も403で断ります。通常の編集画面から編集してください
- ほかのページから [`#include`](/Syntax/Plugin/include) で差し込まれると、このページの案内文が入ります（`title` の見出しはそのまま出ます）

### エラーについて

| 書きかたの例 | エラーになる理由 |
|---|---|
| `#viewable_period(2026-09-05)` | `/` 区切りでない、または年月日として解釈できない |
| `#viewable_period(2026/13/01)` | 月が範囲外 |
| `#viewable_period(2026/02/30)` | 存在しない日付 |
| `#viewable_period(2026/09/05 10)` | 時刻が `HH` だけ |
| `#viewable_period(2026/09/05 10:70)` | 分が範囲外 |
| `#viewable_period(,2000/01/01)` | `end` がページの最終更新日より過去 |
| `#viewable_period(2027/01/01, 2026/01/01)` | `start` が `end` より後 |

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
