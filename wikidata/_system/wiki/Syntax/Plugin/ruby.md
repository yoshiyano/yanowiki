# ruby — 文字にふりがな（ルビ）を振る

| 使える記法 | |
|---|---|
| ブロック `#ruby()` | × |
| インライン `&ruby();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

中身の文字にふりがなを振ります。本家PukiWikiの `ruby` の移植です。

### 書きかた

```pukiwiki
&ruby(reading){text};
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `reading` | ふりがなの文字 | （必須） | 中身（`text`）に振るふりがな |

中身の記法やプラグインは展開したうえで、**文字だけ**を使います（太字や色などの飾りは外れます）。`&amp;` のような文字参照は、その文字として表示されます。`<` `>` はタグになりません。

### 表示例

```pukiwiki
&ruby(かんじ){漢字};を読みます。
```

&ruby(かんじ){漢字};を読みます。

出力は `<ruby><rb>漢字</rb><rp>(</rp><rt>かんじ</rt><rp>)</rp></ruby>` です。ルビに対応しない環境では「漢字(かんじ)」と読めます。

### エラーについて

`reading` と中身（`{text}`）は、どちらも省略するとエラーになります。

```pukiwiki
&ruby(){text};
&ruby(かんじ);
```

&ruby(){text};

&ruby(かんじ);

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
