# 名前と置き場所を変える

ページ・フォルダの名前と置き場所を変える（`pagerename.rename_page`）。画面はファイル一覧
（`/.files/`、`filesui.py`）で、名前の変更と移動がここを呼ぶ。以前の `/.rename` の画面は
2026-09-29 に外した。

| 対象 | 動くもの |
|---|---|
| `Tech/Foo`（ふつうのページ） | そのページと、`Tech/Foo/` の下にあるページ |
| `Tech/Foo/index`（フォルダの入口） | フォルダごと。下にあるページ全部 |

## 移し先は、すでにある場所に限る

置き場所は、すでにあるページの場所に限る（`check_folder`）。どこにも辿り着けない場所へ
置くのを防ぐため。ファイル一覧では、見えているフォルダへ動かす形になる。

まだ下位ページを持たないページを移し先にすると、そこが新しくフォルダになる。

## 一緒に動くもの

| 動かすもの | 置き場所 |
|---|---|
| ページ本体 | `wiki/<subpath>.<ext>` |
| 添付ファイル | `attach/<subpath>/` |
| 変更の記録 | `pageinfo/backup.db`（記録が指すページ名を付け替える） |
| 書きかけ | `pageinfo/draft/<ページ名>` |
| DBの行 | `pageinfo/wikiall.db`（本文・タイトル・目次・リンク） |

## 指していたリンクを直す

指しているページは `links` の表から拾い、本文のリンク先を書き換える（`pagelinks.rewrite_links`。
詳しくは[リンクを直す](/Tech/PageDataBase/Writes#リンクを直す)）。ページも添付も、指す先を
「持ち主のページパス＋添付ならファイル名」にそろえて同じ計算で書き換える。自分自身の添付
（`logo.png` `./logo.png`）は添付フォルダごと動くので触らない。

| 相手 | 何が起きたか |
|---|---|
| 動いていないページ | 指し先が変わっただけ。書きかたはそのまま置き換える |
| 動いたページ自身 | 自分の位置が変わったので、相対の書きかたを見直す |

リンクの直しは、編集画面からの保存と同じ扱い（差分がバックアップに残り、DBも入れ直す）。

## コードブロック・コメントの中は地の文として除ける

`pagelinks.link_spans` は正規表現なので、そのままではコードブロックに書いた記法の
サンプルやHTMLコメントの中もリンクとして拾う。そこで、実際のパーサ（markdown-it /
pukiwiki、どちらも同じToken列を返す）に本文を1度通し、`fence`・`code_block`・`html_block` の
行範囲と `code_inline` の位置を候補から除く。リンクの解決（`resolve_href`）は文字列のまま。

`rewrite_links` の `engine` 引数に、呼び出し側（`pagerename.py`）の `MarkdownIt` インスタンスを
渡せる。候補が無いページや、コード・HTMLブロックが無いページでは除外の判定を行わない。

## 絶対と相対はどちらで書くか

書き換えたあとの近さで決める。近さは相対の書きかたに含まれる `/` の数（上下は区別しない）。

| 書きかた | 移動量 |
|---|---|
| `target` | 0 |
| `../target` `age/ten` | 1 |
| `../../target` | 2 |

| 元の書きかた | どうするか |
|---|---|
| 絶対 | 絶対のまま。ただし動いたページの本文で、相対にすると移動量1まで近づいた場合は相対にする |
| 相対 | 相対のまま。ただし動いたことで移動量が**増える**場合は絶対にする |

`../../p3/page/age/ten` のような書きかたを残さないための決まり。位置関係が変わらなければ
何もしない（`X` を同じ場所で改名したとき、配下への `kid` はそのまま）。

相対を組み直したら `resolve_link` に通し直して狙った先に解けることを確かめ、解けなければ
絶対にする。パーセント符号化されていたものは符号化したまま戻す。

**添付ファイルは、遠くなっても絶対にしない。** farmをまたいで安全な絶対の書きかたが無い
ためです。`/持ち主/ファイル名` はページとして解決され、`/.attach/持ち主/ファイル名` は
システムのURLとして素通りして（`"keep"`）farmの接頭辞が付かないので、別のfarmで開くと
意図しない添付を指してしまう。

## 使えない名前

| 断る場合 | なぜ |
|---|---|
| 空 | 名前が要る |
| `/` を含む | 置き場所は「フォルダも変更する」で選ぶ |
| 移し先がまだ無い | 選ぶものなので、先にそこへページを作ってもらう |
| 自分の中へ移そうとした | 動かすと行き場が消える |
| `=` や `.` で始まる | システムが使う目印（[ページの名前のルール](/Tech/Reference/Routing)） |
| 拡張子の形で終わる | リンクに書いたとき添付ファイルと見分けが付かない |
| すでに使われている | 上書きしない |
| 変わっていない | 何もすることがない |
