# 使ってみよう

#code()

## ページを見る

アドレスバーにページ名を入れると開きます（`/Tech/ThemeGuide` のようにフォルダで
まとめられます）。フォルダ名で開くと、その中の `index` のページが開きます。

## ページを編集する


| 開きかた | どこで |
|---|---|
| ヘッダの「編集」を押す | 開いているページを直すとき |
| **Alt+E** を押す | 「編集」が出ているページで |
| ヘッダの「新規」を押し、ページ名を入れる | 新しいページを作るとき |
| 「このページを作る」を押す | まだ無いページを開いたとき |

新しいページは保存した時点でできます。「編集」「新規」が出ていないときは、
編集の権限がありません（ログインすると編集できるWikiもあります）。

編集画面のタブとボタンは次のとおりです。

#img(編集画面>edit-screen.png)

| タブ | できること |
|---|---|
| 編集画面 | 左の入力欄に書き、右の**プレビュー**で仕上がりをすぐ確かめる。上のツールバーで見出し・太字・リンクなどを挿入できる |
| 更新状況 | 保存されている内容と、いま書いている内容の差分を見比べる |
| 添付ファイル | 画像やファイルを足す・消す・別のページへ移す（ドラッグ&ドロップ可、1ファイル20MBまで） |
| 履歴 | そのページの変更の記録を見て、過去の内容に戻す（[変更履歴](/BackupGuide)） |

| 更新状況 | 添付ファイル |
|---|---|
| &img(更新状況のタブ>diff-tab.png, w100%); | &img(添付ファイルのタブ>attach-tab.png, w100%); |


| ボタン | 動き |
|---|---|
| 保存（**Ctrl+S**） | 保存してページに戻る。差分が自動で記録される |
| 一時中断（**Esc**） | 書きかけを預けてページに戻る。次に編集画面を開くと続きから書ける |
| 内容破棄 | 預けてある書きかけを消してページに戻る（取り消せません） |
| ファイル一覧 | 別のタブで[ファイル一覧](/FilesGuide)を開く。ページやフォルダの名前の変更・移動・削除はここから |

- 書きかけは、入力が30秒止まるたびに自動で預けられます
- 添付したファイルは `![説明](ファイル名.png)` のようにファイル名だけで参照できます
- **本文をすべて消して保存すると、ページは削除されます。** 添付ファイルがあるときは
  先に片付けてください

### 同時に編集されていたとき

書いている間に同じページが別に保存されていると、保存を押したときに**統合する画面**が
開きます。左が相手の更新、右が自分の編集です。相手の変更を相違点ごとに矢印で右へ
取り込んでから保存してください（**右がそのまま保存されます**）。書いた内容は預かって
あるので、この画面を離れても失われません。

## ページの書きかた

**Markdown記法とPukiWiki記法のどちらでも書けます。** 記法は拡張子（`.md`/`.txt`）で
決まり、編集画面のツールバーの右端で選び直せます。

| 知りたいこと | ページ |
|---|---|
| とりあえず書き始めたい | [まずはこれだけ](/Syntax/Markdown#まずはこれだけ) |
| Markdownの書きかた全般 | [Markdown記法](/Syntax/Markdown) |
| PukiWiki記法の書きかた | [PukiWiki記法](/Syntax/PukiWiki) |
| リンクや添付ファイルの指しかた | [共通の書きかた](/Syntax/Common#リンクとファイルの指しかた) |
| 目次や囲み枠を差し込みたい | [プラグイン](/Syntax/Plugin) |
| ページ名に使えない文字 | [共通の書きかた](/Syntax/Common#ページの名前のルール) |

## ファイルを直接置いたとき

ページの実体はテキストファイルなので、エディタで直に書くこともできます。
**書き換えたら取り込みを実行してください**（変更の記録・検索・一覧に反映されます）。

```bash
./wiki.py updatepage =_system   # wikidata/_system/ のページを直したとき
```

## ページの名前のルール

- `=` と `.` で始まる名前は使えません（`=` は別Wikiの指定、`.` はシステムの画面）
- `memo.txt` のように拡張子の形で終わる名前は使えません（添付ファイルと区別できないため）

詳しくは [共通の書きかた](/Syntax/Common#ページの名前のルール)。

## 探す・追いかける

検索窓でサイト全体・このページ内を探せます。用語を色分けしてページをまたいで
追いかけるマーカーもあります（[検索・マーカー](/SearchMarkerGuide)）。

## 前の状態に戻す

保存のたびに変更が記録され、編集画面の「履歴」タブから過去の内容を確かめたり
戻したりできます。消したページの記録も残ります（[変更履歴](/BackupGuide)）。

## 最近の更新を並べる

`recent` プラグインで、更新の新しい順にページを並べられます。

```pukiwiki
#recent()                    最大10件（省略時）
#recent(5, Tech/ChangeLog)   Tech/ChangeLog を除いて5件
```

閲覧の権限が無いページは並びません。フォルダの中身を並べるなら [ls](/Syntax/Plugin/ls)。

## ページの一覧の見かた

編集画面などに出るページ一覧では、**フォルダの行がその中の `index` ページを兼ねます**
（`index` の行は出ません）。開け閉めは左の三角、選んでいる間は ↑↓→← でも辿れます。

## 画面の見かた

配置はテーマによりますが、標準はサイドバーつきの2段組みです。

#img(標準のテーマで開いたトップページ>layout.png)

- **ヘッダ** … サイト名、「ログイン」「トップ」「編集」「新規」のボタン、検索窓
- **本文** … ページの中身
- **サイドバー** … メニューと、そのページの目次
- **フッタ** … 共通のおしらせと、動いている版の番号

メニューは普通のWikiページ（`mainmenu` と `submenu`）なので、編集すればすぐ変わります。
見た目は [見た目を変えよう](/ThemeGuide) で変えられます。

## 複数のWikiを使う

`/=名前/` の形で別のWikiに移れます。Wikiを足すのは `/.newwiki`（管理者と助手だけ）です
（[新しいWikiを作る](/NewWikiGuide)）。
