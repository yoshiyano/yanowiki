# popular — 人気ページの順位を差し込む

| 使える記法 | |
|---|---|
| ブロック `#popular()` | ○ |
| インライン `&popular();` | — |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

アクセスログを集計し、よく見られているページの順位を差し込みます。
サイドバーのメニュー（`mainmenu`）に置く使いかたを想定しています。

### 書きかた

```pukiwiki
#popular()
#popular(7d, 5)
#popular(day=7, num=5)
#popular(10d, 10, Tech/ChangeLog)
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `day` | 日数（`7` でも `7d` でも同じ） | `30` | 集計する期間（直近何日ぶんか） |
| `num` | 1以上の数字 | `10` | 何位まで出すか |
| `exclude` | ページ名 | （除外しない） | 並べないページ。書きかたは [recent](/Syntax/Plugin/recent) と同じ（`*`・`?` を含めばワイルドカード、含まなければ部分一致。複数は `;` で区切る）。除いてから何位までを切る |

どれも位置引数で書けます。1未満や数字でない値はエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。

### 表示例

このWikiの直近30日・上位5件（`Tech/ChangeLog` を除く）:

#popular(30d, 5, Tech/ChangeLog)

見出しは「人気ページTop{num}({day}d)」の形で固定です。記録が無ければ「（この期間のアクセスの記録はありません）」と出ます。

### 何を数えるか

- そのWikiのページの閲覧だけを数えます。添付ファイルへのアクセスや、ほかのWikiへのアクセスは数えません
- 同じ人の短い間隔の連続アクセス（再読み込みの連打など）は1回と数えます
- 同じページが別のURL（`/=Wiki名/...` と、既定のWikiとしての `/...`）で記録されていても、1つにまとめます
- 閲覧する権限の無いページは順位に入りません（[ページごとの権限](/Tech/PagePermissions)）
- 消したページは、閲覧の記録が残っていても順位に入りません
- 件数が同じなら、直近によく見られているほうが上です
- フォルダの入口ページは、`ls`・`recent` と同じくフォルダ名で出ます（`Tech/ChangeLog/index` ではなく `Tech/ChangeLog`）。Wikiの一番上のページは `/` です
