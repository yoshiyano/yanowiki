# 管理者権限でできること

管理者と助手が、ログインしたあとに使うツールの使いかたです。ページを書く・読む人向けの案内は
[使ってみよう](/UsageGuide) にあります。

## ツールの開きかた

ヘッダの「ログイン」から管理者（`admin`）か助手としてログインすると、ログインの画面に
**「管理者メニュー」**のタブが加わります。ここに管理ツールが並びます。

#img(ツールの一覧の画面（管理者メニュー）>/Tech/AdminPages/admin-tools.png)

初めてのときは、先に管理者のパスワードを決めます（[インストールと起動](/InstallGuide)）。

## 管理者と助手

- **管理者**（`admin`）は1人で、すべてのツールを使えます
- **助手**は、管理者が管理作業を任せた人です。システムでは `staff` グループのメンバーとして登録します。
  助手は管理者の代わりに多くのツールを使えます。
  **どのツールのどの操作を使えるかは、管理者が助手ごとに決められます**（[助手の権限](/AdminGuide/StaffPerms)）。
  何も決めなければ、**アカウントの一覧と、助手の操作の記録、Jinja2 のテーマ（sitetheme）は管理者だけ**です。
  他人のパスワードを書き換えると、そこから管理者になれてしまうためです
- 助手の操作は記録に残ります（[助手の操作の記録](/AdminGuide/Maintenance#助手の操作の記録)）

開けないツールも、メニューには「権限がありません」「管理者だけ」と印を付けて並びます。
下の表の「開ける人」は、**助手の権限を何も決めていないとき**の状態です。

## 管理者メニューのツール

| やりたいこと | メニューの項目 | 開ける人 | 案内 |
|---|---|---|---|
| アカウントを見る・直す・増やす・消す | アカウント | 管理者（助手に許せる） | [アカウントと助手](/AdminGuide/Accounts) |
| 申請されたアカウントを承認する | アカウントの承認 | 管理者・助手 | [アカウントと助手](/AdminGuide/Accounts#承認制のとき) |
| 助手を増やす・外す | 助手グループ | 管理者・助手 | [アカウントと助手](/AdminGuide/Accounts#助手を増やす) |
| ふつうのグループを作る・メンバーを直す | グループ | 誰でも | [グループ](/AccessGuide/Groups) |
| 助手ごとに、使える操作を決める | 助手の権限 | 管理者だけ | [助手の権限](/AdminGuide/StaffPerms) |
| ページごとに、読める人・書ける人を決める | アクセス制限 | 管理者・助手 | [ページのアクセス制限](/AccessGuide/Privileges) |
| `#readauth`・`#writeauth` の行を消したページの記録を、すぐ消す | ページの権限の記録の後始末 | 誰でも（開くとすぐ行う） | [readauth](/Syntax/Plugin/readauth) |
| サイト名・編集・添付などの設定を変える | Wikiの設定 | 管理者・助手 | [Wikiの設定](/AdminGuide/Config) |
| テーマの CSS・画像・スロット型のテーマを直す | テーマのファイル | 管理者・助手 | [テーマと見た目](/AdminGuide/Themes)・[スロット型のテーマ](/SlotThemeGuide) |
| 助手の操作を確かめて、元に戻す | 助手の操作の記録 | 管理者（助手に許せる） | [保守と運用](/AdminGuide/Maintenance#助手の操作の記録) |
| 途中で止まった名前の変更・移動を続ける | 中断した操作 | 管理者・助手 | [保守と運用](/AdminGuide/Maintenance#中断した操作を続ける) |
| 消したページの添付を `/trashbox` へ集める | 削除したページの添付 | 管理者・助手 | [保守と運用](/AdminGuide/Maintenance#消したページの添付を集める) |
| Wikiを新しく作る | 新しいWikiを作る | 起点Wikiの管理者・助手 | [Wikiの新規作成](/AdminGuide/NewWiki) |
| Wikiを消す | Wikiを消す | 起点Wikiの管理者・助手 | [Wikiの削除](/AdminGuide/DelWiki) |
| どんなWikiがあるかを見る | Wikiの一覧 | 起点Wikiの管理者・助手 | [Wiki Farm](/FarmGuide#どんなwikiがあるか) |
| サービスを再起動する | サービスの再起動 | 起点Wikiの管理者・助手 | [保守と運用](/AdminGuide/Maintenance#サービスを再起動する) |

**起点Wikiの管理者・助手**とあるものは、いま開いているWikiではなく、起点Wiki
（[Wiki Farm](/FarmGuide)）のアカウントで判断されます。

## メニューに無い操作

次の操作は、管理者メニューに項目がありません。アドレス欄に入力して開きます。

| やりたいこと | 入力するアドレス | 開ける人 | 案内 |
|---|---|---|---|
| `#readauth`・`#writeauth` の記録をすぐ消す | `/.updatePageAuth` | だれでも | [ページのアクセス制限](/AccessGuide/Privileges#消したあとの記録の後始末) |

サーバーのコマンドで行うもの（PukiWikiの取り込み、管理者のパスワードの入れ直し）は、
[PukiWikiから移す](/AdminGuide/ConvWiki)・[アカウントと助手](/AdminGuide/Accounts#管理者が入れなくなったとき) にあります。

ログイン・パスワード・グループなど、ログインしている人ならだれでもできる操作は
[アカウント](/AccessGuide) にあります。
