# html — 中身をそのままHTMLとして表示する

| 使える記法 | |
|---|---|
| ブロック `#html()` | ○ |
| インライン `&html();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

中身に書いたHTMLをそのまま表示します。本家PukiWikiには無い、このシステム独自のプラグインです。

### 書きかた

```pukiwiki
#html(){{
<div class="custom-box">好きなHTMLをそのまま書けます</div>
}}

文中に &html(){<b>強調</b>}; を差し込むこともできます。
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `all` | 単語を書くだけ | 書かない | タグ・属性を絞り込まず、すべて通す |

### 設定（allow_html）との関係

本文に直接書いた生HTMLをどこまで通すかは、設定 `markdown.allow_html`／`pukiwiki.allow_html` で決まります（[HTMLの扱い](/Tech/HtmlPolicy)参照）。
このプラグインの中身は、その設定に関わらず表示されます。

| 書きかた | 通るもの |
|---|---|
| `#html()` | 許可されたタグ・属性だけ（`allow_html: true` で本文に適用されるものと同じ） |
| `#html(all)` | 書いたとおりすべて |

たとえば `#html()` の中の `<script>alert(1)</script>` は、タグにならず文字として表示されます。`#html(all)` ならそのまま通ります。

#note(type=warn){{
`#html(all)` は `<script>`・`<iframe>`・`onclick=` なども通すので、閲覧者のブラウザで任意の動作をさせられます。
自分で書いた内容か、信頼できると確かめた内容だけに使ってください。

`all` は `allow_html` では止められません。止めたいWikiでは、`wikidata/<Wiki名>/plugin/` に同じ名前の `html.py` を置いて差し替えます（共通の `plugin/` より優先されます）。
}}

### 性質

- 中身の記法やプラグインは展開されず、HTMLの一部として扱われます
- 閉じ忘れたタグは中身の終わりで閉じ（`<div><span>text` → `<div><span>text</span></div>`）、対応する開始タグの無い閉じタグは捨てます。周りの表示を崩さないための簡易な補修で、`<p>`・`<li>` の暗黙の閉じかたまではブラウザと同じにしません
- 中身を省略する・空にするとエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）
