# アカウントと助手

アカウントはWikiごとに持ちます（[Wiki Farm](/FarmGuide)）。ここでいう助手は、管理者から管理作業を任された人です。
管理者のツールは
[管理者権限でできること](/AdminGuide) から開きます。

## アカウントの一覧（管理者だけ）

管理者メニューの「アカウント」で、登録されているアカウントを表で見て、その場で直せます。

#img(アカウントの一覧（パスワード欄は伏せ字にしてあります）>/Tech/Accounts/AccountList/accounts.png)

| やりたいこと | 操作 |
|---|---|
| ID・名前・パスワードを直す | 表の中で書き換えて「変更を更新」。値を変えた行だけが更新されます |
| パスワードを新しく決める | パスワード欄に書き、右の「パスワードとして入力」にチェックを入れる。チェックが無いと、書いたものをハッシュ値として扱います |
| アカウントをロックする | パスワード欄を空にして更新する（確認が出ます） |
| 消す | 番号の右のチェックボックスで選び、「選んだ行を削除」。`admin`（番号1）は選べません |
| 増やす | 下の欄に新しいIDとパスワードを入れる |

IDを変えるときは、パスワードも付け直します。

#note(type=warn){{
最初のパスワードを既定のまま使い続けないでください。Wikiを作るときと
`./wiki.py initusers` では、パスワードを必ず決めてもらいます。
}}

## ログインを間違えたとき

5回間違えると10分入れず、通算15回でロックされます（[アカウント作成とログイン](/AccessGuide/Login#間違えたときロックされたとき)）。
ロックされたアカウントは、一覧に 🔒 が付きます。**管理者が一覧でパスワードを付け直すと解けます。**

## 管理者が入れなくなったとき

パスワードを忘れたときや管理者がロックされたときは、画面からは戻れません。サーバーで次を実行します
（ロックもこれで解けます）。

```bash
./wiki.py resetpw =<Wiki名>
```

Wiki名を省くと一覧から選べます。続けて、そのWikiのトップページのフッターを丸ごと貼り付けると
（別のWikiを選んでいないかの確かめです）、新しいパスワードを2回聞かれます。

## 承認制のとき

Wikiの設定（[Wikiの設定](/AdminGuide/Config) の「アカウント」タブ）で、新しいアカウントの受け入れかたを選べます。

| 設定 | 動き |
|---|---|
| 誰でも作れる（初期値） | アカウントを作ったらすぐ使える |
| 承認制 | 誰でも申請できるが、助手か管理者が承認するまで使えない |

承認制のとき、承認待ちがあると、管理者と助手のログインの欄に赤字で「承認待ち x人」が出ます。
押すか、管理者メニューの「アカウントの承認」を開いて、「承認する」で使えるようにし、「断る」で申請を消します。
承認したあとに止めたいときは、管理者が一覧で消すかロックします。

申請の受付には限りがあります。

- 申請から3日たっても承認しなければ、断ったときと同じく申請は消えます
- 承認待ちの申請が20件あるあいだは、新しい申請を受け付けません（アカウントの承認の画面と、承認できる人が開くページのタイトル右端に、青い丸の i で「受付を止めています」と出ます。押すと承認の画面が開きます）。承認するか断ると再開します
- 同じ IP アドレスからの申請は、1時間に3件までです
- 名前（表示名）は32文字までです（管理者が作る・直すときも同じ）

誰が何を読めて書けるかは、ここではなく [ページのアクセス制限](/AccessGuide/Privileges) で決めます。
Wikiを作るとき、使いかたを選ぶと両方が一緒に決まります（[Wikiの新規作成](/AdminGuide/NewWiki#使いかた)）。

## 助手を増やす

助手は、管理者の代わりに管理ツールを使う人です。使える操作は、管理者が助手ごとに決められます（[助手の権限](/AdminGuide/StaffPerms)）。
何も決めなければ、[アカウントの一覧と助手の操作の記録は管理者だけ](/AdminGuide#管理者と助手)です。
助手は `staff` という名前のグループのメンバーです。新しく助手になった人は、何も決めていない状態から始まります。

1. 管理者メニューの「助手グループ」を開く
2. 追加するには、ユーザー名をスペースかカンマで区切って入れる。外すには、左のチェックボックスで選んで「削除」
3. 全員が抜けても、管理者だけのグループに戻ります

## ふつうのグループ

ログインしていれば、だれでも自分のグループを作れます（[グループ](/AccessGuide/Groups)）。
グループは [ページのアクセス制限](/AccessGuide/Privileges) で `g:グループ名` と書いて使います。管理者と助手は、どのグループのメンバーも直せます。

仕組みは [アカウントの仕組み](/Tech/Accounts)・[グループ管理](/Tech/Groups) にあります。
