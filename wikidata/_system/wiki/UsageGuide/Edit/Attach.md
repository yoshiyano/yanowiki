# 添付ファイル

ページに画像やファイルを添付します。編集画面の「添付ファイル」タブで、足す・消す・別のページへ移すができます
（編集画面は [編集する](/UsageGuide/Edit)）。

#img(添付ファイルのタブ>/UsageGuide/Edit/attach-tab.png)

## 足す

- **ファイルを選ぶ**と、そのまま送られます（「追加」ボタンは要りません）。**複数まとめて選べます**
- **追加の欄にドラッグ&ドロップ**しても追加できます（複数可）
- **クリップボードの画像を貼り付ける**こともできます（下記）
- 同じ名前のファイルは、初めは上書きしません。「同名を置き換える」にチェックを入れてから選ぶと、置き換わります
- 1ファイルの上限は、初めは**20MB**です（管理者が [Wikiの設定](/AdminGuide/Config) の `attach.max_size` で変えられます）。
  上限を超えるファイルは、送る前に名前・大きさ・上限を添えて知らせ、収まるものだけを送ります
- 中身が空のファイルは受け付けません
- 送信中は進み具合が出ます。複数選んだときは全部の合計です

ファイルの名前は、日本語や空白を含んでいてもそのまま使えます。ただし `../`・制御文字・`:*?"<>|` は取り除かれ、
前後の `.` と空白も落とされ、255文字までに切られます。

### クリップボードから貼り付ける

画像は、ファイルを選ばずに貼り付けでも追加できます。

| 方法 | 使える場面 |
|---|---|
| `Ctrl+V`（添付タブを見ているとき） | パソコン。画面のどこをクリックしたあとでも効きます（添付欄の外の文字入力欄へ貼るときだけは、そちらに入ります） |
| 「クリップ貼付」ボタン | https か localhost で開いているとき |
| 「クリップボードからペースト」の枠 | スマートフォン。枠に貼ります。写真アプリで編集した写真を、ファイルに書き出さずに貼れます |

名前の無い画像には、`clip001` のような連番の名前が付きます。

#### 貼り付けられないとき

画像が届かなかったときは「**クリップボードに画像がありません**（届いた形式: …）」と出ます。届いた形式で、何がコピーされていたかが分かります。

| 届いた形式 | コピーされていたもの | 対処 |
|---|---|---|
| （形式が出ない） | 何も無い。コピーしたプログラムが、渡す前に終わっていることが多い | 下の「画面を撮ってすぐ貼るとき」 |
| `text/uri-list`・`text/plain` | ファイルマネージャで**ファイルそのもの**をコピーした（中身ではなく場所だけが届く） | そのファイルを添付欄へドラッグするか、ファイルを選ぶ |
| `text/html` | Webページの画像を**範囲選択して**コピーした（画像のURLだけが届く） | 画像を右クリックして「画像をコピー」でコピーし直す |

#### 画面を撮ってすぐ貼るとき（Linux）

X11 のクリップボードは、コピーしたプログラムが動いている間だけ中身を渡せます。
撮ってすぐ終わるツールは、終わる前に中身をクリップボードマネージャ（Xfce では
`xfsettingsd`）へ預けないと、画像が消えます。

**Ubuntu 22.04（jammy）の `xfce4-screenshooter -c` はこれに当たり、コピーされません。**
jammy のバージョン（1.9.9）には、コピーし終える前に終わってしまう不具合があります
（本家の 1.10.2 で直っています。Ubuntu では 24.04 の 1.10.5 から）。
jammy では、撮った画像を `xclip` に渡して、`xclip` にクリップボードを持たせてください。

```
xfce4-screenshooter -r -o 'xclip -selection clipboard -t image/png -i'
```

`-r` は範囲を選んで撮る指定です（全画面は `-f`、ウィンドウは `-w`）。
Xfce の「設定」→「キーボード」→「アプリケーションショートカット」に登録しておくと、
キー1つで撮って貼れます。`xclip` が無ければ `sudo apt install xclip` でインストールします。

## 一覧の見かた

| 列 | 内容 |
|---|---|
| 種別 | 拡張子から判定したアイコンと名前（画像・動画・音声・PDF・文書・表計算・スライド・圧縮・コード・テキスト） |
| ファイル名 | クリックすると別タブで開く |
| 大きさ | 読みやすい単位に丸めた値 |
| 日時 | 最終更新 |
| 本文での書きかた | クリックすると、本文に貼れる形でコピーされる |

- 画像の行にマウスを乗せると、サムネイルが出ます
- 画面が狭いと、右の欄から順に隠れます（ファイル名と操作は残ります）

## 本文から使う

「本文での書きかた」の欄に、**そのまま貼れる形**が出ます。隣の「コピー」を押すとクリップボードに入ります。

| 書きかた | 画像 | ほかのファイル |
|---|---|---|
| Markdown | `![名前](::名前)` | `[名前](::名前)` |
| PukiWiki記法 | `&img(名前);` | `[[::名前]]` |

`::` を付けると「そのページの添付ファイル」を指します（[共通の書きかた](/Syntax/Common#リンクとファイルの指しかた)）。
コピーできない環境では、書きかたが選択された状態になるので、`Ctrl+C` で写します。

## 別のページへ移す

各行の「移動」を押すと、ページ選択のダイアログが開きます。移動先を選ぶと、そのページの添付になります。
書いているうちに「この画像は別のページに置くべきだった」となったときに使います。

- **まだ無いページも選べます**（先に添付だけ置いておけます）。そのときは「移動先のページはまだありません」と添えます
- 移動先に同じ名前があるときは、初めは移しません。「同名を置き換える」を選んだときだけ置き換えます
- ダイアログの一覧は、ページ名で絞り込めます

## 消す

各行の「削除」を押すと、ファイル名を見せて確認が出ます。**削除は取り消せません。**
ページ自体を消したときは、添付は `/trashbox` へ移ります（[編集する](/UsageGuide/Edit/Page#ページを消す)）。

仕組みは [添付ファイルの管理（技術ドキュメント）](/Tech/EditGuide/Attach) にあります。
