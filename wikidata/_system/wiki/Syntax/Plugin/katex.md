# katex — LaTeX数式をKaTeXで表示する

| 使える記法 | |
|---|---|
| ブロック `#katex()` | ○ |
| インライン `&katex();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

LaTeX形式の数式を [KaTeX](https://katex.org/) で組版して表示します。本家PukiWikiには無い、このシステム独自のプラグインです。

### 書きかた

```pukiwiki
#katex(){{
E = mc^2
}}

文中に &katex(){x^2 + y^2 = z^2}; を差し込むこともできます。
```

中身にはLaTeXをそのまま書きます。記法やほかのプラグインは展開されません。
中身に `}}` だけ（`}` が2つ以上だけ）の行ができると、そこで中身が終わったと読まれます。
そのときは `{{{ ... }}}` のように波括弧3つ以上で囲んでください。

### 表示例

ブロックは独立した数式として中央に、インラインは文中に、行の高さに収まる形で組まれます（KaTeXの [`displayMode`](https://katex.org/docs/options) が `true`／`false`）。
分数や総和のように縦に大きくなる式で、違いがはっきり出ます。

```pukiwiki
文中に差し込むと &katex(){\sum_{i=1}^{n} i = \frac{n(n+1)}{2}}; のようになります。

#katex(){{
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
}}
```

文中に差し込むと &katex(){\sum_{i=1}^{n} i = \frac{n(n+1)}{2}}; のようになります。

#katex(){{
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
}}

### 組版されないとき

組版するのはページを開いたブラウザで、このWikiに同梱したKaTeX本体（CSS/JS/フォント）を使います（外部のCDNは使いません）。

| 状況 | 表示 |
|---|---|
| KaTeXが解釈できないLaTeX | その数式の位置に赤字のエラー（ほかの数式はふつうに表示） |
| KaTeX本体の読み込みに失敗 | 同じく赤字のエラー（「KaTeX本体の読み込みに失敗しました」） |
| JavaScriptが無効 | LaTeX原文のまま、直前に「⚠ JavaScriptが無効なため…」の注記 |

中身を省略する・空にすると、プラグインのエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
