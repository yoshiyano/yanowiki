# pagediv — いくつかのページの本文を、枠に入れて縦横に並べて差し込む

| 使える記法 | |
|---|---|
| ブロック `#pagediv()` | ○ |
| インライン `&pagediv();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

指定したいくつかのページの本文を、ページ名の見出し付きの枠に入れて、表のように縦横に並べて差し込みます。
トップページに、よく見るページを一覧で並べておくような使いかたに向きます。1つのページを差し込むだけなら [include](/Syntax/Plugin/include) を使います。

PukiWikiで使っていた `pagediv` の移植で、**PukiWikiで書いた `#pagediv(…)`・`#pagediv{{ … }}` はそのまま動きます。**
表示は表（`<table>`）ではなくCSSグリッドで組み直しており、**狭い画面では自動で縦1列に積み直します。**

## 書きかた

### 横に並べる

ページ名をカンマで区切って並べます。

```pukiwiki
#pagediv(研究テーマ, テーマ別情報;40%)
```

### 縦横に並べる

`{{ }}` の中に、表と同じ形で書きます。1行を `|` で始めて `|` で終え、セルを `|` で区切ります。

```pukiwiki
#pagediv{{
|>|日記TOP|暫定メモ;40%|
|日記VIEW;30%|大学業務ページ;30%|メモ|
|^|OS情報|工作|
}}
```

- `>` … そのセルを**右のセル**とつなぎます（右のセルが横に2つ分の大きさになる）。`|>|>|ページ|` と続ければ3つ分です
- `^` … そのセルを**上のセル**とつなぎます（上のセルが縦に2つ分の大きさになる）
- 何も書かないセル（`||`）は空いたままになります

上の例はこう並びます。

| 1列目（30%） | 2列目（30%） | 3列目（40%） |
|---|---|---|
| 日記TOP（横に2つ分） | ← | 暫定メモ |
| 日記VIEW（縦に2つ分） | 大学業務ページ | メモ |
| ↑ | OS情報 | 工作 |

Markdownのページでは丸括弧を省けないので、`#pagediv(){{ … }}` と書いてください（PukiWiki記法のページでは `#pagediv{{` のままで動きます）。

生成されるHTML（各セルの中身は、差し込んだページの本文です。ここでは省略しています）:

```html
<div class="pagediv" style="--pd-cols: minmax(0, 30fr) minmax(0, 30fr) minmax(0, 40fr);">
<section class="pagediv-cell" style="--pd-area: 1 / 1 / span 1 / span 2;"><div class="pagediv-title"><a href="/日記TOP">日記TOP</a></div>
<div class="pagediv-body">
（日記TOPの本文）
</div>
</section>
<section class="pagediv-cell" style="--pd-area: 1 / 3 / span 1 / span 1;"><div class="pagediv-title"><a href="/暫定メモ">暫定メモ</a></div>
…
<section class="pagediv-cell" style="--pd-area: 2 / 1 / span 2 / span 1;">…（日記VIEW）…
…
</div>
```

見出しはそのページへのリンクです。そのページを編集できる閲覧者には、押すと編集画面が開くボタンになります。

### 見た目を足す

ページ名の後ろに `;` で区切って指定を足せます。

```pukiwiki
#pagediv{{
|メモ;40%;bgcol:#cdf;col:#036|予定;tdcol:#fffbe6;sz:90%|
}}
```

| 指定 | 意味 |
|---|---|
| `30%` / `200px`（`width:30%` とも） | その列の幅。指定の無い列は、残りを等分します |
| `col:色` | 見出しの文字色 |
| `bgcol:色` | 見出しの背景色 |
| `tdcol:色` | セル全体の背景色 |
| `sz:大きさ` | セル全体の文字の大きさ |
| `tdsz:大きさ` | 見出しの文字の大きさ |

`sz:` がセル全体、`tdsz:` が見出し、という割り当てはPukiWikiのときのままです。

### 見出しを付けない・積み直さない

```pukiwiki
#pagediv(notitle){{
|ページA|ページB|
}}
#pagediv(nostack, ページA, ページB)
```

| 単語 | 意味 |
|---|---|
| `notitle` | 各セルの上のページ名（見出し）を付けない |
| `nostack` | 狭い画面でも縦1列に積み直さず、並びをそのまま保つ |

### 行を揃えず、列ごとに詰める（`cols`・`cols=N`）

表の形は行の高さを揃えるので、同じ行に短いページと長いページがあると、短いほうの下が空きます。
`cols` を書くと行の揃えを外し、**表の列ごとにページを上から詰めて**並べます。

```pukiwiki
#pagediv(cols){{
|長い;40%|短い|
|中くらい|メモ|
}}
```

左の列に「長い → 中くらい」、右の列に「短い → メモ」が、それぞれすき間なく並びます。

生成されるHTML（セルの中身は省略しています）:

```html
<div class="pagediv pagediv-cols" style="--pd-cols: minmax(0, 40fr) minmax(0, 60fr);">
<div class="pagediv-col">
<section class="pagediv-cell">…長い…</section>
<section class="pagediv-cell">…中くらい…</section>
</div>
<div class="pagediv-col">
<section class="pagediv-cell">…短い…</section>
<section class="pagediv-cell">…メモ…</section>
</div>
</div>
```

- 列の幅は、表の形と同じく各列のセルの `;40%` などで決まります
- `>` でつないだセルは、つないだ始まりの列に置きます（幅は1列分）。`^` は無視します
- 空のセル（`||`）は飛ばします（列の中に空きを作りません）
- 引数で並べる形（`#pagediv(cols, A, B)`）では、各ページがそれぞれ1列です

`cols=N` を書くと、ページを **N 列へ、書いた順に左から1つずつ**振り分けます
（A→1列目、B→2列目、C→3列目、D→1列目…）。並べるページが多いときに、表の形を考えずに書けます。

```pukiwiki
#pagediv(cols=3){{
|A|B|C|D|E|F|G|
}}
```

1列目に A・D・G、2列目に B・E、3列目に C・F が並びます。列の幅は等分で、`;40%` などの幅の指定は使いません。
`cols` と `cols=N` を両方書いたら `cols=N` が効きます。`cols=N` は `cols=3` の形でしか書けません（`#pagediv(3)` はページ名の `3` です）。

狭い画面では、列を順に縦1列へ積み直します（`nostack` で止められます）。

## 差し込めないとき

次のセルには、ページの中身の代わりに赤字の案内を出します（ページのほかの部分は普通に表示されます）。

| 場合 | 案内 |
|---|---|
| ページが無い | このページはまだありません: ページ名 |
| 閲覧する権限が無い（[ページごとの権限](/Tech/PagePermissions)） | このページを閲覧する権限がありません: ページ名 |
| 自分自身や、自分を差し込んでいるページ（無限ループになるため） | 自分自身や、自分を差し込んでいるページは差し込めません: ページ名 |
| `#pagediv` の入れ子が3段を超えた | #pagediv の入れ子が3段を超えました。 |

同じページを2つのセルに置くことはできます（PukiWikiのときと同じ）。差し込むページの数に上限はありません
（[include](/Syntax/Plugin/include) の12件の上限とは別です）。

ページ名は本文のリンク `[[ページ名]]` と同じ決まりです（裸の名前はWikiの先頭から、`./` はこのページの下）。

## エラーについて

このプラグイン固有のエラーです。

| 書きかた | エラーの内容 |
|---|---|
| `#pagediv()` | 差し込むページを指定してください |
| `#pagediv(ページA){{ … }}` | ページの並びは、引数と {{ }} のどちらか一方に書いてください（`notitle`・`nostack`・`cols`・`cols=N` は `{{ }}` と一緒に書けます） |
| `{{ }}` の中に `\|ページA` のような行 | {{ }} の中の行は `\|` で始めて `\|` で終えてください |
| `ページA;foo:1` | 知らない指定です（PukiWikiでは黙って無視されていました） |
| `ページA;col:red"x` | 値に使えない文字が含まれています |
| `#pagediv(cols=0){{ … }}` | 列の数（cols=N）の指定が正しくありません（1以上の数を書きます） |

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
