# 平文ファイルの取り込みをHTTPから実行する仕組み

`/.plugin/updateDB` を開くと、平文ファイルの直接編集（エディタでの編集・
`git pull`・別のスクリプトの書き出しなど）をDBへ取り込みます。

## 使いかた

| URL | 動き |
|---|---|
| `/.plugin/updateDB` | そのWiki全体を取り込む |
| `/.plugin/updateDB?page=Tech/dev_plugin` | そのページだけを取り込む |
| `/.plugin/updateDB?force=1` | 平文とDBの食い違いを見ずに、全ページを取り込み直す（[使える人に制限あり](#誰が使えるか)） |

`page` と `force` は組み合わせられます。結果は `./wiki.py updatepage` と同じ形式の
1行のテキストです（例: `ページの取り込み: 更新1 (1 Wiki, 0.02秒)`）。

既定以外のWikiは `/=Wiki名/.plugin/updateDB` で指定します
（[共通の書きかた](/Syntax/Common#プラグインの呼びかた)）。

## 自動の取り込みとの違い

取り込み（`wikilib.pagesync`）は次のときにも自動で動きます。

- サービスの起動時（全Wiki）
- 1時間おき（全Wiki）
- ページを開いたとき（平文はあるがDBに無いページだけ）

`/.plugin/updateDB` は、これを待たずにすぐ取り込ませたいときに使います。
シェルを使えない外部（スクリプト・webhook・cron）から呼べます。取り込みの中身は
自動の取り込みや `updatepage` と同じです。

## 誰が使えるか

取り込み（`force` なし）は**誰でも実行できます**。平文の内容をDBへ映すだけなので、
外から内容を差し込まれることはありません。

`force=1` は全ページを読み直して描き直すので重く、繰り返されると負荷になります。
そのため、次のように絞っています（Wiki設計者の指示）。

| 実行する人 | `force=1` |
|---|---|
| ログインしていない | 使えない（403） |
| ログインしている | 同じ人が**15分に1回、1日（0時から）20回まで**。超えると429で、次に使える時刻を返す |
| そのWikiの管理者と助手 | 制限なし |

実行の記録は、一時フォルダ（`/tmp` など）の `wikisystem-updatedb-force-<設置場所の要約>.json`
に置きます。重要な記録ではないのでシステムのフォルダには置きません。一時フォルダが
消えると数え直しになります。

[`/.restart`](/Tech/Restart) と違って確認画面は挟みません。取り込みは何度行っても
結果が変わらないので、先読みや誤クリックで困ることがないためです。
