# 同じ名前の .txt と .md があるとき

ページのタイトルの右端に、橙色の三角（⚠）のアイコンが出ていたら、そのページは
同じ名前の `.txt` と `.md` の両方のファイルを持っています。アイコンにマウスを重ねると、
見つかったファイル名と、いま画面に出ているファイルが分かります。

#img(タイトルの右端の ⚠>/UsageGuide/Edit/Duplicate/icon.png)

アイコンは、そのページを閲覧できる人全員に出ます。押すと、そのWikiの**整理の画面**
（`/.solveDupPage/<ページ名>`）が開きます。

## 何が起きているか

- ページとして読まれるのは **`.txt` だけ**です。取り込みも編集画面も `.txt` を読み、`.md` は読まれません
- **画面に出るのは、取り込んだ内容です。** `.md` を公開したあとで `.txt` を置いたときは、取り込むまで
  `.md` の内容が画面に出ます（編集画面は、すぐ `.txt` の内容を開きます）。取り込みは、サービスを起動したとき・
  1時間ごと・`updatepage` を実行したときに行われ、取り込むと `.txt` の内容に替わります
- 取り込んだあとは、`.md` に書いた内容は画面のどこにも出ません。ファイルが残っているだけなので、気づきにくい状態です
- 同じ名前の `.txt` と `.md` は、**同時に置かない**決まりです。ブラウザの編集画面で書きかた
  （PukiWiki記法・Markdown）を変えて保存したときは、前の拡張子のファイルが自動で消えます。
  重複は、手でファイルを置いたとき（エディタで書き足した、別の場所から複製した、`git pull` で入ってきた）に起きます

## ブラウザで整理する

アイコンを押して開く整理の画面で、どちらを採用するかを選びます。**そのページの編集の権限（`W`）が必要**です。
権限が無い人には、状況の説明だけが出ます（取り込み前の内容を、読むだけの人に見せないためです）。

#img(整理の画面>/UsageGuide/Edit/Duplicate/solve.png)

画面は、上から次の順に並んでいます。

1. **状況の説明**: 見つかったファイル名と、読まれるほう・いま画面に出ているほう。この説明ページへのリンクもここにあります
2. **2つのプレビュー**: 左が `.txt`、右が `.md`。それぞれの書きかたのまま描きます。ファイルの大きさと更新日時も出ます。縦幅は 720px までで、超えた分はプレビューの中でスクロールします
3. **添付ファイル**: このページの添付の一覧と、ファイルごとの移動先
4. **アクセス制限**: このページと、整理でできるページに当たっている閲覧（R）・編集（W）の指定。**案内だけで、ここでは修正しません**
5. **採用のボタン**: `.txt` か `.md` のどちらかを採用します。押すと確認が出ます

採用すると、選ばなかったほうは、**名前に `_bak` を付けたページ**になります。
閲覧も編集もできます。

| 採用したほう | 選ばなかったほうの行き先 |
|---|---|
| `A.txt` | `A.md` → `A_bak.md` |
| `A.md` | `A.txt` → `A_bak.txt` |

- `A_bak` がすでにあるときは、上書きせず `A_bak2`・`A_bak3` … と空いている名前にします。ページのほか、同じ名前のフォルダ・添付・書きかけ・履歴・アクセス制限の行があるときも、その名前は使いません
- 下位のページを持つページ（`Tech`）は、入口の `Tech/index` を整理します。行き先は `Tech/index_bak` です
- 採用したページの履歴（変更履歴）は、そのまま続きます。`_bak` のページは、新しいページとして始まります。書きかけは、採用したページに残ります

### 添付ファイルをどちらに持たせるか

重複している2つのファイルは、同じ添付を使っています。整理すると別のページになるので、
**添付ファイルごとに、どちらのページに持たせるか**を「移動先」の欄で選びます。

#img(添付ファイルの移動先と、画像のプレビュー>/UsageGuide/Edit/Duplicate/attach.png)

| 移動先 | 結果 |
|---|---|
| 両方（既定） | 採用したページに残したまま、`_bak` のページへも写します。どちらも画像などが表示されます。容量は増えます |
| .txt 側 | `.txt` のファイルのページだけに持たせます |
| .md 側 | `.md` のファイルのページだけに持たせます |

- **「.txt 側」「.md 側」は、そのファイルのページ**です。採用したファイルのページが元の名前（`A`）、採用しなかったほうが `A_bak` になります。たとえば `A.md` を採用して「.txt 側」を選んだ添付は、`A_bak` へ移ります
- 持たせなかったほうの本文は、添付の画像などが表示されなくなります
- 表の「すべて（一括）」の行のボタンを押すと、その内容がすべてのファイルへコピーされます。ファイルごとに変えることもできます。変えて揃わなくなったときは、一括のボタンは選んでいない状態に戻ります
- **画像ファイルは、ファイル名にマウスを重ねるとプレビューが出ます。** 画像以外のファイルには出ません
- 下位のページの添付は、どれを選んでも動きません

### アクセス制限は案内だけ

`_bak` は新しい名前のページなので、そのままでは元のページのアクセス制限が当たらず、**整理した直後から、制限が緩い（または制限が無い）状態になることがあります**。
完全一致の指定（`A`）だけでなく、後方一致の指定（`*Secret` は `MySecret` に当たりますが、`MySecret_bak` には当たりません）でも起きます。

この画面は、アクセス制限を**修正しません**。次の案内だけを出します。

- 元のページと、整理でできる `_bak` のページに、いま当たっている指定を並べて見せます
- 2つで許可者が違うときは、赤い枠で知らせます。採用のボタンを押したときの確認にも、同じ注意が出ます
- 「アクセス制限」の文字は、**アクセス制限の画面へのリンク**です。**別ウィンドウで開く**ので、この画面を残したまま設定できます。整理の前でも後でも設定できます。整理した後の画面にも、同じリンクが出ます。管理は、開いた先の画面で行います
- 本文のプラグイン（`#readauth`・`#writeauth`）によるアクセス制限は、**`.txt` と `.md` のどちらのファイルに何が設定されているか**だけを表で示します（閲覧は `#readauth`、編集は `#writeauth`。許可者は書きません）。2つのファイルの本文は別なので、採用するほうで整理後の制限が変わります。プラグインの記録は `_bak` へ写しません
- 許可者（ログインID・グループ名）の一覧は、**管理者と助手だけ**に出ます。それ以外の人には、指定の件数だけが出ます
- `_bak` のページを、操作した人が編集できなくなるときは、整理を断ります

### 整理できないとき

- 画面を開いてから採用を押すまでの間に、ファイルが書き換えられていたときは、断ります。内容を確かめ直してください
- どこかで失敗したときは、ファイルと添付を、整理の前の状態へ戻します
- ページの記録の取り込みだけ失敗したときは、整理は済んでいます。1時間以内に自動で取り込まれます（すぐ直すときは `./wiki.py updatepage =<Wiki名>`）
- 助手が行った整理は、[助手の操作の記録](/Tech/StaffLog)に残ります（記録だけで、戻すボタンはありません）

## 同じ名前のファイルとフォルダがあるとき

ページ `X` のファイル `X.md` と、同じ名前のフォルダ `X/` が並んでいるときも、同じ ⚠ のアイコンが出ます。
フォルダがあると、ページ `X` として読まれるのはフォルダの入口 `X/index.md`（`.txt`）で、**`X.md` は読まれません**。
フォルダに入口が無いときは、ページ `X` は「このページはまだありません」と出ます。その画面にもアイコンが出ます。

アイコンを押すと、同じ整理の画面が開きます。並ぶのは、ファイル `X.md` とフォルダの入口 `X/index.txt` です。

| 採用したほう | 動き |
|---|---|
| フォルダの入口 `X/index.txt` | `X.md` → `X_bak.md` |
| ファイル `X.md` | `X/index.txt` → `X_bak.txt`、`X.md` → `X/index.md`（ページ名 `X` は変わりません） |
| （入口が無いとき） | `X.md` → `X/index.md`。`_bak` は作りません |

- 2つのファイルは、もともと別々に添付ファイル・履歴・書きかけを持っています。**どれも、それぞれのファイルに付いたまま動きます。** 添付ファイルの移動先は選びません
- 下位のページ（`X/kid`）と、その添付ファイルは動きません
- `_bak` の名前の決めかた、アクセス制限の案内、整理できないときの扱いは、`.txt` と `.md` の整理と同じです

### 重複が重なっているとき

`X/index.txt` と `X/index.md`、`X.txt` と `X.md` のように重複が重なっているときは、**1段ずつ**整理します。
アイコンを押すたびに、次の順で残っている重複が出ます。整理を終えた画面に「続けて整理する」が出ていれば、まだ残っています。

1. フォルダの入口の `.txt` と `.md`（`X/index.txt` と `X/index.md`）
2. フォルダに隠れたファイルの `.txt` と `.md`（`X.txt` と `X.md`）。どちらも読まれていないので、まず1つに絞ります
3. ファイルとフォルダの入口（`X.md` と `X/index.txt`）

## ファイルを直接直す

ブラウザを使わずに直すときは、どちらを残すかを決めて、もう一方のファイルを消し、取り込みます。
ファイルは、サーバーを動かしているパソコンの `wikidata/<Wiki名>/wiki/` の下にあります
（[ページのファイルの決まり](/UsageGuide/Edit/LocalFile#ページのファイルの決まり)）。

1. 2つのファイルの中身を見比べて、残すほうを決めます。画面に出ているのは、`.txt` の内容とは限りません（上のとおり、取り込むまでは前に公開した内容です）
2. 残さないほうのファイルを消します（残したいなら、名前を替えます）
3. 取り込みを実行します。画面の内容が、残したファイルのものに揃います（[書き換えたあとの反映](/UsageGuide/Edit/LocalFile#書き換えたあとの反映)）

```bash
./wiki.py updatepage =<Wiki名>/ページ名
```

アイコンは、ファイルを消した次にページを開いたときから出なくなります。
