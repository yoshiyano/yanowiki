# マーカーシステム

複数の用語を色分けして、ページをまたいで追跡する仕組みの実装です。使いかたは
[検索・マーカー](/SearchMarkerGuide) にあります。

ヘッダの検索とは別物です。検索は1つのクエリを一時的に探すもの、マーカーは複数の用語を
ページをまたいで期限つきで保持するもので、生存期間もデータの持ちかたも違います。

## 状態はブラウザだけに持つ

状態（用語・色・用語セット・最終使用時刻）はブラウザのlocalStorageだけに持ち、サーバーは関与しません
（ログインしていない閲覧者も同じように使えます）。

```
localStorageキー: wikisys.markers.v1

{
  "activeSet": "既定",
  "activeTerm": 0,
  "sets": {
    "既定": {
      "terms": [
        { "term": "課題", "color": "#ffd54a", "lastUsed": 1755840000000 }
      ]
    }
  }
}
```

別の端末やブラウザとは共有されません。localStorageが使えない環境では保存できませんが、閲覧は妨げません。

## マークする範囲

ハイライトの対象は本文（`<main>`）とフッター（`<footer>`）だけで、ヘッダ・検索フォーム・メニュー・
タイトル・パンくずは対象外です。テーマのクラス名ではなく `<main>`・`<footer>` で判断するので、
テーマが変わっても同じ範囲になります（どちらも無いテーマではページ全体）。

## 全ページへの差し込みかた（テーマ非依存）

本体（`_sys/markers/markers.js`・`markers.css`）は、テーマを変えずに全ページへ差し込まれます
（`render_theme` が本文の末尾へ `<link>`/`<script>` を足す。`themes.marker_asset_tags`）。

## ホットキー

| キー | 動き |
|---|---|
| `Alt+M` | 操作用の別ウィンドウ（`/.markers-panel`）を開く/前面に出す |
| `1`〜`9`・`0` | アクティブな用語を切り替える（1番目〜10番目） |
| `←` / `→` | アクティブな用語の、隣の一致へ移動 |
| `↑` / `↓` | アクティブな用語の、**今の画面（ビューポート）の外にある**次/前の一致へ大きくジャンプ（全部の一致が画面内に収まっていれば、隣の一致への移動にフォールバックする） |

用語が1つも無いとき、入力欄・`contenteditable` にフォーカスがあるときは、これらのキーは何もしません。

最終使用時刻（`lastUsed`）は、矢印キーで一致へ実際に移動したときだけ更新します。

### 用語を切り替えても、文書内の位置は引き継ぐ

数字キーで別の用語に切り替えても、先頭には戻りません。直前の用語で矢印キーで動いていれば、
その位置と同じか後ろにある最初の一致へ移ります。動いていなければ先頭から始まります。

## 操作用の別ウィンドウ（`/.markers-panel`）

用語の追加・削除・色の変更、用語セットの作成・名前変更・削除・切り替えは、`Alt+M` で開く別ウィンドウで
行います（本文の中に置くとテーマのレイアウトと衝突しかねないため）。状態はWikiによらずオリジン全体で共有します。
1つの用語セットにつき最大10個です（数字キー `1`〜`9`・`0` に対応）。

ページ側と操作用ウィンドウは、`BroadcastChannel`（`wikisys-markers`）で状態の変化と一致数だけを伝え合い、
値はどちらも同じlocalStorageを読み直します。

## 1日以上使っていない用語は自動で捨てる

`lastUsed` から24時間経った用語は、次にページを開いたときに破棄されます（全用語セットをまとめて見ます）。

## 用語の色は32色パレットから選ぶ

自由な色選択だと本文が読みにくい濃い色も選べるので、淡いトーンのパレットから選びます。

- **プリセット20色**（編集不可）: 色相を18度刻みに割り、彩度45%・明度90%に揃えた色
- **カスタム12色**: HSVエディタで決める12個のスロット。`wikisys.markers.palette.v1` に保存し、用語セットをまたいで共通

色ボタンを押すとパレットが画面中央に開きます（ボタンの近くに出すと、一覧の下のほうではみ出すため）。
カスタムのスロットは右下の✎から編集します。用語一覧（`.mp-terms`）は高さを制限せず、全部を表示します。

「新しい用語」の色は、用語を追加するたびに、その用語セットでまだ使っていない色（無ければパレット全体）から
ランダムに選び直します。

## テーマ側（メニュー等）から使う公開API

テーマ側のJSからマーカーの状態を扱うときは、localStorageやBroadcastChannelを直接触らず、
`markers.js` が用意する `window.WikisysMarkers` だけを使います。

```js
window.WikisysMarkers.getSummary()
  // => { enabled: true, activeSet: "既定", setNames: ["既定", "作業用"] }
window.WikisysMarkers.setEnabled(false)   // ハイライト・ホットキーをオフ（Alt+Mだけは効いたまま）
window.WikisysMarkers.setActiveSet("作業用")  // アクティブな用語セットを切り替える。無い名前ならfalseを返す
window.WikisysMarkers.openPanel()         // 操作用の別ウィンドウを開く（Alt+Mと同じ）
window.WikisysMarkers.togglePanel()       // 開いていれば閉じる、閉じていれば開く（ヘッダーのリンク向け）
```

`markers.js` は `defer` で差し込まれるので、テーマ側のJSが先に動くことがあります。
`window.WikisysMarkers` が無ければ `wikisys-markers:ready` を待ちます。

```js
function setup(summary) { /* メニューのUIを組み立てる */ }
if (window.WikisysMarkers) {
  setup(window.WikisysMarkers.getSummary());
} else {
  window.addEventListener("wikisys-markers:ready", function (e) { setup(e.detail); }, { once: true });
}
// 他のタブ・パネル操作・API呼び出しで状態が変わるたびに、最新のsummaryがdetailに載って飛ぶ
window.addEventListener("wikisys-markers:change", function (e) { /* UIを最新の状態に合わせる */ });
```

`enabled` が `false` のときはホットキーも止まりますが、`Alt+M` だけは解除の手段として効きます。

## 複数タブを開いているときの注意

ほかのタブへ伝えるのは、用語の追加・削除・色の変更・用語セットの切り替えのように見えかたが変わる操作だけです。
矢印キーでの移動（`lastUsed` の更新）は、全タブでハイライトを作り直すことになるので伝えません。
