# Wikiを消す仕組み

`/.delwiki` から、いまあるWiki（個別Wiki）を1つ消せます。[新しいWikiを作る
仕組み](/Tech/NewWiki) の裏返しですが、取り返しが付かないので確かめる段を4つに
分けてあります。

消す前に必ず `wikidata/<Wiki名>.<yymmdd_hhmmss>.7z` へ固め、そのあとで実体を消します。
書庫には `<Wiki名>/…` の形でフォルダの中身（ページ・添付・`config/users.db`・
`pageinfo/`・`log/`）がまるごと入っているので、`wikidata/` で展開すれば元どおりです。

```
cd wikidata && 7z x sandbox.260918_143012.7z
```

## 誰が消せるか

既定Wiki（`config/server.yaml` の `farm.default`）の管理者と助手だけです。
判定は [再起動](/Tech/Restart)・[新しいWikiを作る](/Tech/NewWiki)・
[Wikiの一覧](/Tech/Reference/Views#wikiの一覧) と同じ `wikilib.sysui.require_on_default_farm`
で、Wiki名を含むURL（`/=<Wiki名>/.delwiki`）は既定Wikiのものでも403です。

そのうえで、**消される側のWikiの管理者のパスワード**も確かめます（2段目）。
既定Wikiの管理者・助手であることは「この画面を開いてよい」ことの証しで、
「隣のWikiを消してよい」ことの証しではないためです。既定Wikiが持つ役割のまとめは
[設計方針](/Tech/DesignPolicy/Farm#デフォルトのwikiの役割) にあります。

## 4つの段

| 段 | 何を入れる | 何を確かめている |
|---|---|---|
| 1 | 消すWikiの名前 | どれを消すのか（押し間違いを防ぐため、一覧から選ばせず書かせる） |
| 2 | そのWikiの `admin` のパスワード | そのWikiを預かっている人であること |
| 3 | ディスク使用量とトップページの最終更新日 | いまそのWikiを実際に見ていること |
| 4 | 最後の確認 | ここで初めて消える |

どんなWikiがあるかは `/.allwiki` で見られます。既定のWikiは消せません
（別のWikiを既定にしてから消します）。

### 3段目は「見ていること」を確かめる段

名前だけなら、写し間違いでも通ってしまいます。ディスク使用量とトップページの
最終更新日は、そのWikiのトップページを開かないと分からず、Wikiごとに違う値です。
どちらもテーマのフッターに出ています。

```
Last-modified: 2026-09-18 14:33          → 「2026-09-18」と書く
DiskUsage: Page/Attached 1.2MB/349KB     → 「1.2MB/349KB」と書く
```

- フッターの行をまるごと貼っても、日付を `2026/09/18`・`20260918` と書いても通ります
- 最終更新日は、平文ファイルの更新時刻とDBの更新日時のどちらでも通ります
- **どちらが違ったかは伝えません**（片方ずつ当てられないように）

値の作りかたと突き合わせは `./wiki.py resetpw` の取り違え防止と共通で、
`wikilib.wikimark` にあります。

## 書庫はいつ作られるか

2段目が通った時点から裏で作り始め、3・4段目を書いているあいだに進めます。

- 作成中は `.7z.part`、完成したら `.7z`、失敗したら `.7z.error`（理由を書く）。
  状態をファイルで表すので、ワーカーが複数ある構成でも同じ答えになります
- 書庫が出来上がるまで実体は消しません。4段目で押したときに作成中なら、押し直してもらいます
- 最後にやめたときは書庫も消し、`wikidata/` には何も残しません

書庫を作り始めてから実体を消すまでの間に書き込まれた分は、書庫に入りません
（消そうとしているWikiで起きることは考えにくいため、手当てしていません）。

## 段と段は署名付きの合札でつなぐ

「前の段を通った」ことは、プロセスの中ではなく、署名した合札をフォームに埋めて
持ち回ります（ワーカーが複数あると、プロセスの中の記憶は別のワーカーに届きません）。

- 署名の鍵は `config/secret.txt`（`auth.site_secret`）。ログイン中のuidも混ぜるので、
  他人の画面から取り出した札は使えません
- 合札は2段目と3段目で別なので、3段目を飛ばして最後のPOSTだけを組み立てることはできません

## 置き場所

| もの | 場所 |
|---|---|
| 画面と処理 | `_sys/wikilib/delwiki.py`（外枠は管理ページ共通の `sysui.page`） |
| 見た目 | `_sys/delwiki/delwiki.css`（`/.delwiki.css`） |
| 目印の作りかた | `_sys/wikilib/wikimark.py` |
| 書庫 | `wikidata/<Wiki名>.<yymmdd_hhmmss>.7z` |
| テスト | `tests/test_delwiki.py`・`tests/test_wikimark.py` |

書庫を作るには `7z`（`7za` / `7zz` でも可）が要り、見つからないときは消す手続きに
入る前に止めます。

## 消したあと

書庫は `wikidata/` に残ります。要らなければ手で消してください（消すと戻せません）。
`wikidata/` の中身は `_system` を除いてGit管理の対象外なので、書庫がコミットに
混ざることはありません。
