# Markdown記法：文字の飾り・リンク・画像

文の中に置く飾りと、リンク・画像の書きかたです。

## 文字を飾る

| 書きかた | 表示 |
|---|---|
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `***太字の斜体***` | ***太字の斜体*** |
| `~~打ち消し線~~` | ~~打ち消し線~~ |
| `` `コード` `` | `コード` |
| `**太字の中の*斜体***` | **太字の中の*斜体*** |

`_` も使えます（`__太字__`、`_斜体_`）が、単語の途中では効かないので `*` が確実です。

### かっこや句読点をまたいでも太字になります

`**` の外側が全角の文字や約物（かっこ・句読点など）なら、空白を入れずにそのまま書けます。

| 書きかた | 表示 |
|---|---|
| `**見出し一覧（目次）**を差し込む` | **見出し一覧（目次）**を差し込む |
| `**「かぎかっこ」**のあと` | **「かぎかっこ」**のあと |
| `**そこは触らない。**WDT の話` | **そこは触らない。**WDT の話 |

`*`（斜体）や `~~`（取り消し線）も同じです。

この扱いは日本語まわりだけです。`2 * 3 * 4` や `snake_case_word` は飾りになりません
（[仕組み](/Tech/Emphasis)）。

### 記号をそのまま書きたいとき

`*` や `_` を文字として使うときは、直前に `\` を付けます。

| 書きかた | 表示 |
|---|---|
| `\*星で囲む\*` | \*星で囲む\* |
| `1\*2\*3` | 1\*2\*3 |

## リンク

```markdown
[使ってみよう](/UsageGuide)
```

↓ こう表示されます → [使ってみよう](/UsageGuide)

| 書きかた | 意味 |
|---|---|
| `[文字](/UsageGuide)` | このWikiの `UsageGuide` ページへ |
| `[文字](/Tech/Reference)` | 階層の下のページへ |
| `[文字](/)` | トップページへ |
| `[文字](#見出し名)` | 同じページの見出しへ |
| `[文字](https://example.com/)` | 外部サイトへ |
| `[文字](/UsageGuide "説明")` | カーソルを合わせると「説明」が出る |

ページへのリンクは **`/` から始めます**。拡張子の付いたファイル名だけなら、**そのページの添付ファイル**です
（[共通の書きかた](/Syntax/Common#リンクとファイルの指しかた)）。

### URLをそのまま書く

URLはそのまま書くだけでリンクになります。

↓ こう表示されます → https://example.com/

### 同じページの見出しへ飛ぶ

`#` のあとに見出しの文字を書きます（英字は小文字、空白は `-` に。日本語はそのまま）。

| 見出し | リンクの書きかた |
|---|---|
| `## 画像` | `[画像の話](#画像)` |
| `## Hello World` | `[hello](#hello-world)` |

↓ こう表示されます → [画像の話](#画像)

## 画像

```markdown
![説明の文字](/logo.png)
```

リンクの前に `!` を付けます。`説明の文字` は、画像が表示できないときに出ます。

### そのページに添付した画像

**ファイル名だけ書くと、そのページの添付ファイルです。**

```markdown
![ロゴ](logo.png)
```
