# 助手の操作の記録

助手（staff）が行った操作を記録し、管理者が **`/.admin/stafflog`** で確かめて、間違った操作を
元に戻せるようにする仕組みです（`wikilib.stafflog`・`staffundo`・`stafflogui`）。

- 記録するのは**助手だけ**です。管理者の操作は記録しません
- 記録は Wiki ごとに `wikidata/<Wiki名>/log/staff.log.db` へ積みます。上書き・削除された
  添付ファイルの中身は `log/staff/<記録の番号>/` に控えます
- `/.admin/stafflog` は**管理者だけ**が開けます（記録に操作の前後の中身が入るため）。
  [管理の画面](/Tech/AdminPages)の一覧からも開けます

## 記録するもの

| 操作 | 元に戻す |
|---|---|
| ページの保存（新しく作る・書き換える。節の編集・競合の統合・履歴からの復元を含む） | 保存する前の本文に戻す。新しく作ったページは消す |
| ページの削除 | 消す前の本文で作り直す |
| ページの改名・移動 | 元の名前・場所へ改名し直す（リンクの書き換えも改名し直しで戻る） |
| 添付の追加・上書き・削除・名前の変更・別のページへの移動 | 控えた中身・元の名前と場所に戻す |
| 設定（`default.yaml`・定義ルール） | 変える前のファイルに戻す |
| アクセス制限（`/.admin/privileges`） | そのページの行を操作の前に戻す |
| グループの作成・メンバーの出し入れ | メンバーを操作の前に戻す |
| アカウントの承認・断り | 承認待ちに戻す。断って消したアカウントは、同じ番号・ID・パスワードで入れ直す |
| `/.garbagecollect` | trashbox へ移した添付を元の場所へ戻す |
| Wikiの削除（`/.delwiki`） | 書庫（7z）から展開して戻す |
| Wikiの作成・Wiki名の変更・再起動 | 記録だけ（戻すボタンは出さない） |

`/.newwiki`・`/.delwiki`・`/.restart` の記録は、その画面を開いた既定のWikiに残ります。

## 記録するところ

画面ごとではなく、実際に書き込む関数の側で記録します（ページなら `pagesave.save_page`、
添付なら `attach` の各関数）。入口が増えても記録が漏れないようにするためです。記録するのは、
HTTPの要求の中で、システムとして動いておらず（`auth.act_as` の外）、ログインしている人が
助手で管理者ではないときだけです（`stafflog.actor`）。取り込み・1時間ごとの後始末は記録しません。

改名はリンクを直すために他のページも保存し、`/.garbagecollect` は trashbox のページを作ります。
こうした中の書き込みは `stafflog.quiet()` で記録せず、外側の操作1件にまとめます。

## 元に戻す

記録を開くと操作の前後を見比べられ、戻せるものには「元に戻す」が出ます。

#img(記録の詳細（/.admin/stafflog?id=番号）>stafflog-detail.png)

- **いまの状態が操作の直後のままのときだけ戻します。** 後から誰かが書き換えていれば断ります
  （後の変更を消さないため）。その場合は前後の内容を見て、手で直します
- 戻したことは記録に書き添えます（戻した人・日時・結果）。同じ記録は二度戻せません
- 戻す操作は管理者が行うので、それ自体は新しい記録になりません
