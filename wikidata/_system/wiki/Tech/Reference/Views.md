# 検索・一覧の画面

検索・Wikiの一覧・ページ一覧・更新順の一覧の決まりです。

## 検索

当たったページを数える段階と見せる段階を分けてある（`_sys/wikilib/search.py`）。

| 段階 | すること | 何に比例するか |
|---|---|---|
| 1段階目 | 当たったページを数える（`search_matches`）。返すのは実体パスと一致語数だけ | 候補の数 |
| 2段階目 | そのページに出す分だけ抜粋と強調を作る（`build_results`） | **出す件数（20件）** |

1段階目は本文を1件ずつ流して当たり外れだけを見る（`pagedb.iter_page_texts_of`）ので、
当たりが何千件あってもメモリに載るのは実体パスと一致語数だけになる。件数とページ送りは
1段階目で決まる（3,000ページが全部当たる語で、1画面を出すまで 363ms → 198ms、
ピークメモリ 26.6MB → 0.7MB）。

### ページ送り

1ページ20件（`SEARCH_PER_PAGE`）。`?page=2` で2ページ目を開く。番号は先頭・末尾と
現在ページの前後だけを出す（`pager_numbers`）。`?page=` に何が来ても在るページに収める
（`clamp_page`）。

`/.search.js` は `?fragment=1` を付けて同じURLを読み、結果の部分（`.search-block`）だけを
差し替える。返すHTMLはページ全体と同じ組み立て（`render_results_block`）。ページ送りは
ふつうのリンクなので、JavaScriptが無くても使える。

### 見た目は検索自身が持つ

結果の一覧とページ送りのHTMLは `search.py` が組み立て、CSS/JSも `_sys/search/` が持つ
（`/.search.css`, `/.search.js`）。テーマ（`theme/search.html`）が受け持つのは検索フォームの
体裁だけ。色はテーマのカスタムプロパティ（`--accent`・`--border`・`--muted`）を使う。

## Wikiの一覧

このサーバーの全Wikiを1枚で見渡す画面（`allwiki.py`）。名前・トップページの見出し・
ページ数を並べ、既定のWikiといま見ているWikiに印を付ける。見出しとページ数は各WikiのDBから
引く。DBがまだ無いWikiも、名前とリンクだけで一覧に出す。

### 誰が見られるか（2026-09-16）

**既定Wiki（`config/server.yaml` の `farm.default`）の管理者と助手だけ**です
（Wiki設計者の指示、2026-09-16）。並ぶ名前はそのままURLなので、非公開のWikiの在り処を
明かすことになるためです。判定は [再起動](/Tech/Restart)・[新しいWikiを作る](/Tech/NewWiki) と
同じ `wikilib.sysui.require_on_default_farm` です。

- 判定は、いま開いているWikiではなく既定Wikiのアカウントで行う
- Wiki名を含むURL（`/=<Wiki名>/.allwiki`）は、既定Wikiのものでも403。通るのは `/.allwiki` だけ
- 一覧を組み立てる前に断る
- 既定Wikiが持つ役割のまとめは [設計方針](/Tech/DesignPolicy/Farm#デフォルトのwikiの役割)

URL名は `server.yaml` の `farm.allwiki` で決まる（既定 `allwiki` ＝ `/.allwiki`）。

| 設定 | どうなるか |
|---|---|
| `allwiki: allwiki`（既定） | `/.allwiki` で開ける |
| `allwiki: wikilist` | `/.wikilist` で開ける（`/.allwiki` は無いページ） |
| `allwiki: ""` | 一覧を出さない（権限のある人にも） |

使えるのは英数字と `-` `_` で、先頭は英数字（それ以外を書くと既定に戻す）。

## ページ一覧のTreeView

ページ選択ダイアログ（編集画面の添付の移動先）・[編集画面のサイドバーのページ一覧](/Tech/EditGuide/Sidebar)は、
同じTreeViewを使う（`_sys/treeview/`、
`/.treeview.css` `/.treeview.js`）。TreeViewは並べかた・開閉・キーボード操作だけを受け持ち、
何を出すか・選ぶと何が起きるかは使う側が決める。

### 使う側が足せるところ

| 渡すもの | すること |
|---|---|
| `onSelect` | 行が選ばれたときに呼ばれる |
| `decorate` | その行に独自の目印を足す（編集画面のページ一覧の「書きかけ」） |
| `selectable` | 選べない行を作る（履歴の無い行など）。キーボードで動かしたときも飛ばす |

木のJSONが `has_file` を持たない場合は、実体の有無を見ない（全部が「まだありません」の
見た目にならないように）。

要素には、場所ごとの名前（`rp-row` など）と共通の名前（`tv-row`）が並べて付く。共通のCSSは
`tv-` だけを見る。

#note(type=warn){{
**接頭辞を `[class$="-row"]` のような属性セレクタで拾ってはいけない。**
class 属性の**文字列全体**の末尾を見るので、クラスを2つ以上持つ要素
（`rp-node rp-dir`）には当たらない。
}}

### index は出さない

フォルダの行が `index` を兼ねる（フォルダを選ぶ＝その入口ページを選ぶ）。`index` を別の行と
して並べたいときは `theme.show_index` を真にする（既定は偽）。

### 選ぶのと開閉は場所を分ける

行を押すと選ばれる（フォルダも同じ）。開閉は左の三角で行う（三角は文字の1.7倍）。

### キーボードでも動かせる

| キー | すること |
|---|---|
| ↑ ↓ | 選んでいる行を上下に動かす |
| → | フォルダを開く（開いていれば中の先頭へ） |
| ← | フォルダを閉じる（閉じていれば親へ） |
| Enter | 決定（使う側が決める） |

見えている行だけを順に辿る（畳んだ中の行は飛ばす）。

## 更新順の一覧（recent）

`recent` プラグインが `pagelist.walk()`（閲覧の権限で絞った一覧。[ページの一覧を作る](/Tech/PageList)）を
受け取り、DBの `updated`（最終更新日時）の新しい順に並べ直して出す。専用の記録ページは
持たず、件数の上限も無い。
