# size — 文字の大きさを指定する

| 使える記法 | |
|---|---|
| ブロック `#size()` | × |
| インライン `&size();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

文中の一部の文字を大きく・小さくします。PukiWikiの `&size()` と同じ使い勝手です。

### 書きかた

```pukiwiki
&size(px){文字};
&size(割合%){文字};
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `size` | 数字（ピクセル）か、数字に `%` を付けたもの（割合） | なし（**省略不可**） | 文字の大きさ |

- ピクセルは **8〜60** に丸められます（`&size(100){…};` なら60）
- 割合は **10〜500** に丸められます。`&size(150%){…};` で周りの文字の1.5倍です（割合は本家PukiWikiに無い拡張）
- 中身にはインライン記法（太字・リンクなど）とインラインのプラグイン（`&color(red){…};` など）が使えます

### 表示例

```pukiwiki
通常の文字の中に &size(24){大きな文字}; を混ぜられます。
&size(10){小さな文字}; も、&size(24){**重要**な[リンク](/)}; も書けます。
```

通常の文字の中に &size(24){大きな文字}; を混ぜられます。
&size(10){小さな文字}; も、&size(24){**重要**な[リンク](/)}; も書けます。

出力は `<span style="font-size:24px;display:inline-block;line-height:130%;text-indent:0">…</span>` です。

### エラーになる書きかた

| 書きかた | 理由 |
|---|---|
| `&size(){文字};` | 大きさを省略した |
| `&size(abc){文字};` / `&size(1.5){文字};` | 大きさが数字（と `%`）の形でない |
| `&size(20){};` | 中身が無い |

範囲外の数字はエラーにならず、範囲の端に丸められます（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
