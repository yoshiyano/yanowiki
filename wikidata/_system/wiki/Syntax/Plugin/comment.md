# comment — コメント投稿フォーム

| 使える書きかた | |
|---|---|
| ブロック `#comment()` | ○ |
| インライン `&comment();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

コメント投稿フォームと、投稿済みコメントの一覧を置きます。
投稿すると、このページの本文（`#comment()` の中身）に1行書き足して保存し直します。

### 書きかた

```pukiwiki
#comment()
#comment(見出し, noname, nodate, newbottom)
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `legend` | 文字列 | `コメント`（**常に1番目**） | 枠の左上（`<legend>`）に出す見出し |
| `noname` | 単語を書くだけ | 出す | 名前欄を隠し、コメント行にも名前を残さない（`msg 日時` の形になる） |
| `nodate` | 単語を書くだけ | 付ける | 投稿日時を付けない |
| `newtop` | 単語を書くだけ | （既定の動き） | 新しいコメントを上（フォームの直下）に追加する |
| `newbottom` | 単語を書くだけ | 書かない | 新しいコメントを一覧の末尾に追加する（本家PukiWikiと同じ並び） |
| `id` | `id="cmtaB3xY"`（名前付きでだけ書ける） | 表示したときに書き足す | このコメント欄を見分ける ID（下記） |

`legend` 以外は好きな順で書けます。候補に無い単語（`#comment(たいとる, xyz)` の `xyz`）はエラーです。

### 中身（`{{ }}`）

中身は書かなくてかまいません。最初の投稿のときに書き足されます。

```pukiwiki
#comment(){{
- 最初のコメント -- 名無しさん &new{2026-08-28 (金) 09:00:00};
}}
```

- 投稿日時は [new](/Syntax/Plugin/new) で囲んで書き足されるので、新しいコメントには ` New!` の印が付きます。
  5日を過ぎると `&new` が外れて日時の文字だけになります（Markdownのページでは `&new(){…};` の形で書き足されます）

- フォームと一覧は1つの `<fieldset class="comment-fieldset">` の枠に入り、間は `<hr>` で区切られます
- 名前はただの文字列として書き足されます（リンクにはなりません）。空欄なら「名無しさん」です
- 名前欄には前回の名前が入っています（そのブラウザの localStorage に覚えるだけで、サーバには送りません）。空にして投稿すると忘れます
- PukiWiki記法のページでは、コメントの先頭に `-` や `--` を書くと、そのぶん深い返信になります。Markdownのページでは階層にならず、ふつうの文になります
- 1つのページに複数置くと、それぞれ別にコメントを溜めます（書き込み先は `id` で見分けます。下記）

### 投稿のしかた・表示の更新

- 投稿には JavaScript が必要です。使えない環境では、ボタンが押せない形で表示され、
  「この環境では投稿ができません（JavaScript が必要です）。」と出ます
- 投稿するとページは移動せず、コメント欄だけが新しい内容に入れ替わります（同じページの別のフォームに入力中の文字は消えません）
- ページを開いている間は、5分ごとにコメント欄を新しい内容に入れ替えます。別のタブを見ている間は確かめず、戻ってきたときに5分以上経っていれば、すぐに確かめます。書きかけの名前・コメントはそのまま残ります
- include した先のページの `#comment` に投稿すると、コメントは `#comment` が書かれているページ（差し込まれた側）に入ります。画面は取り込み元のページのままです

### 書き込み先の ID

投稿がどの `#comment` に入るかは、`id` で見分けます。`id` を書いていない `#comment` は、
ページを表示したときに、プラグイン自身が書き足して保存し直します。

```pukiwiki
#comment(見出し)
```

を表示すると、本文が次のように変わります（`aB3xY` の部分はページごとにばらばら）。

```pukiwiki
#comment(見出し, id="cmtaB3xY")
```

- 書き足すのは、実際にフォームとして表示されるものだけです。`#code` の中や `#table` のセルに書いた
  `#comment()` のような「書きかたの例」は変えません
- ID は `cmt` とランダムな5文字の形です（以前の `cmt0aB3x` の形もそのまま使えます）。すでに書いてある `id` は変えません
- [include](/Syntax/Plugin/include) などで、別のページの `#comment` と ID が重なっても、付け直しません
  （投稿の書き込み先は、ページと ID の組で決まるため、取り違えません）
- `#comment(...)` を写して増やし、**同じページの中**で ID が重なったときは、表示したときに後のほうへ新しい ID を振ります
- 表示する前に（ファイルを直接直したときなど）同じ ID が重なっていれば、投稿は上にあるほうに入ります
- 部分プレビューでは書き足しません
- [table](/Syntax/Plugin/table) のセルの中にも置けます。コメントは、セルの中に次の形で書き足されます（閉じの `}}` の後ろに、セルの区切りが続きます）

```pukiwiki
#table(){{
|#comment(id="cmtaB3xY"){{
- 最初のコメント -- 名無しさん &new{2026-10-23 (金) 09:00:00};
}}|\\
}}
```


`id` はプラグインが書くものなので、手で書く必要はありません。

### 投稿できないフォームになるとき

コメント欄の投稿先を決められないと、入力欄とボタンが押せない形で表示されます
（エラーにはしません）。

- ページのファイルを直接書き換え、まだ取り込んでいない（`./wiki.py updatepage` の前）

取り込めば投稿できます。

メニュー（`mainmenu` など）の中に書いた `#comment` も、どのページを見ていても投稿できます。
コメントは**メニューのページ自身**に書き込まれるので、メニューのページに書く権限のある人だけが
投稿できます。

### 投稿を断られるとき

閲覧できるページなら、編集の権限が無くても、ログインしていなくても投稿できます（[ページごとの権限](/Tech/PagePermissions)）。
次の場合は、ページを変えずに断り、理由をフォームのそばに出します。入力した内容は消えません。

| 状況 | 応答 |
|---|---|
| コメント欄が空 | 何もしない |
| 送られた ID の `#comment` が無い（ページが編集されて消えた、など） | 409。「該当フォームがなくなりました」 |
| JavaScript を使わない送信 | 400。「この環境では投稿ができません」 |
| `#comment(...)` の本体の書きかたが壊れていて、書き足す場所が見つからない | 409 |
| 閲覧する権限が無い | 403 |
| ページがもう無い | 404 |

表示している間にコメント欄がページから消されると、5分以内の確認のときに「該当フォームがなくなりました」と出て、ボタンが押せなくなります。

[セクション編集](/Tech/SectionEditing)の部分プレビューでは投稿できません。
