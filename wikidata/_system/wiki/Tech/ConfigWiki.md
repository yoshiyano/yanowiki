# Wikiの設定を画面から変える（`/.admin/configwiki`）

そのWikiの設定ファイル（`wikidata/<Wiki名>/config/default.yaml`）を、項目の説明を
読みながら書き換える画面です。

- 開けるのは管理者と助手です（ほかは403）。設定を変えても管理者にはなれないので、
  「管理者だけ」にはしていません（[管理の画面](/Tech/AdminPages)）
- 画面は管理ページ共通の外枠で出ます
- 共通の設定（`config/default.example.yaml`）はこの画面では変えられません。ファイルを直接編集します

## 項目はタブで分かれ、直したその場で保存されます

#img(Wikiの設定の画面>configwiki.png)

**「保存する」のボタンはありません**（Wiki設計者の指示、2026-09-18）。入力欄を直した
時点で、直した項目1つだけを書き込みます。

- 文字を打つ欄は、打ち終わりを0.7秒待ってから送ります
- 画面の値をまとめて送り直すことはしません（開いたまま放っておいた画面の古い値で、
  他の人の書き換えを上書きしないため）
- JavaScriptが無いと書き込めません（読むことはできます）

タブは、編集／アカウント／添付ファイル／プラグイン／Markdown／PukiWiki記法／
テーマと画面／定義ルール／Wiki名 です（作りは [グループ管理](/Tech/Groups) と同じ）。

## 「このWikiで指定する」に印を付けたものだけ書きます

設定は、共通の値の上にそのWikiの値を重ねて決まります
（[設定の重なりかた](/Tech/Reference/Config)）。この画面は印を付けた項目だけを
書き出し、書いていない項目には共通の値が効きます。全部を書き出すと、共通の設定を
あとから直してもこのWikiに届かなくなるためです（`wikilib.wikiconfig.load_config`）。

印を外すと、その項目はファイルから消え、入力欄には共通の値が戻ります。入力欄の下には
いつも「共通の設定: …」を出しています。

## 取り返しが付かない項目は「理解して編集」を入れたときだけ書けます（2026-09-21）

項目に `guard`（警告の文言）を持たせると、赤い警告と「理解して編集」のチェックが付き、
チェックを入れるまで印も入力欄も触れません。いまは `account.pw_salt`（パスワードの塩）
だけです。変えると全アカウントのパスワードが通らなくなり、作り直せないためです
（[アカウントの仕組み](/Tech/Accounts) の「パスワードの持ちかたと、その弱さ」）。

- チェックは画面だけの状態で、開き直すと外れています
- API（`/.admin/configwiki/api`）も、確認済みの印（`ack`）の無い書き込みと印の取り外しを断ります
- 画面には、いま効いている塩（空のときは Wiki名）を添えます

## 保存すると失われるもの、残るもの

| | |
|---|---|
| コメント | **失われます**（Wiki設計者の指示）。書き出すのは目印の1行と、コメントの無いYAMLだけ |
| この画面が知らない項目 | 残します（手で書き足した設定を消さないため） |
| 直前のファイル | 人が直したものなら、控えに残ります（下記） |

## 1行目の目印

書き出したファイルの1行目には、1行目を除いた中身のSHA-1が入ります。

```yaml
# wikiconfig 893f023e370ddec00524df5604a4dc5fdebaceb4
edit:
  title_length: 30
```

開いたときに計算し直して、一致すれば「この画面が書いたまま」、合わなければ
「人が直した」と判断します。秘密ではなく、見分けるためだけの値です。

## 控え（`default.yaml.YYMMDD_HHMMSS`）

人が直したファイルを書き換えるときだけ、直前のものを同じフォルダに控えます。

- 10世代まで。古いものから消えます
- 戻すときは、ファイルを置き換えます（画面からは戻せません）
- 画面の下に、いまある控えの一覧が出ます

## 定義ルール（`COLOR()`・`&smile;` などの置き換え）

「定義ルール」のタブで、PukiWiki記法の置き換えルール（`pukiwiki.extrarules.yaml`。
`COLOR(red){…}`・`SIZE()`・`BOLD`・`&smile;` など）を編集できます。`default.yaml`
とは別のファイルで、中身がルールの配列なので専用のタブにしてあります。

- 印は「このWikiで独自の定義を持つ」の1つだけです。付けると共通の定義をコピーして
  このWiki専用のファイルを作り、外すと共通に戻ります（直前のファイルは必ず控えに残る）。
  印が無いあいだは、共通の定義を読み取り専用で見せます
- ルールごとに直す・削除・上下に動かす、末尾に追加ができ、その場で保存されます。
  上にあるものが優先されます
- 送るときに「直す前の中身」を添え、先に誰かが並びを変えていたら断ります
- 保存させないもの: 正規表現として読めないもの／空の文字列に当たるパターン（`a*` など）／
  置換文字列の `\1` などがグループの数を超えているもの

上の**試験欄**に文章を入れると、いま効いている定義を掛けた描画結果・出力HTML・
ルールごとの当たり箇所が出ます。追加欄の「試す」で、保存前のルールも試せます。
当たり箇所の探索は別のプロセスで3秒に切って行うので、重い正規表現（`(a+)+$` など）でも
サーバーは固まりません。

#note{{
**置換文字列はHTMLとしてそのまま出力されます**（`<span>` などを書けます）。書けるのは
管理者と助手だけで、`allow_html` を変えられるのと同じ信頼です。`\1` などで差し込まれる
捕捉した部分は、通常のインライン記法として解釈し直され、生HTMLとしては出ません。
}}

## Wiki名を変える

いちばん右のタブで、このWikiの名前を変えられます。名前は置き場所（`wikidata/<名前>/`）で
あり、URL（`/=<名前>/`）そのものです。フォルダを移すだけで中身は書き換えないので、
[Wikiを消す](/Tech/DelWiki)と違って書庫は取りません。

| 変えると | どうなるか |
|---|---|
| 外からのリンク・ブックマーク | `/=<旧名>/…` は無いページになります |
| このWikiに入っている人 | 全員が入り直しです（合言葉にWiki名が混ざるため）。パスワードはそのまま通ります（移す前に旧名を `account.pw_salt` へ書いて固定するため。[アカウントの仕組み](/Tech/Accounts) の「パスワードの持ちかたと、その弱さ」） |
| 名前を変えたその人 | そのまま続けられます（新しいURL向けにcookieを置き直す） |
| テーマを選ぶセレクタの選択 | 消えます（cookieがWikiごとのため） |
| 既定のWiki（`farm.default`）だった場合 | 指定も新しい名前に付け替えます |

- この項目だけは直したそばから保存せず、いまの名前を書き写してからボタンで実行します
- `_system` のように新規作成では作れない名前（先頭が英数字でない等）のWikiは、名前を
  変えられません（一度変えると戻せないため）
- 既定のWikiは、実体を移してから `farm.default` を書き換え、書き換えに失敗したら移動を
  戻します（名前を付けずに開いたときの行き先が無くならないように）

## 出している項目

`edit` / `account` / `attach` / `plugin` / `markdown` / `pukiwiki` / `theme` の主な項目です。
ここに出ていない項目も、ファイルに書けば効きます（この画面は消しません）。
`server` / `farm` / `debug` は `config/server.yaml` の項目で、Wikiごとには変えられません。

## 項目の説明の書きかた（作る人向け）

説明（`SECTIONS` の `help`）は、HTMLとしてそのまま出します。強調は `<strong>`、記号は
`&amp;` `&lt;` と書きます。Markdownは通りません（`**…**` は星がそのまま出ます）。
`tests/test_configui.py` で、`help` に `**` と `` ` `` が無いことを見ています。
