# ローカルファイルの編集

Wiki のページは、サーバーを動かしているパソコンの `wikidata/<Wiki名>/wiki/` にある
テキストファイル（`.md`・`.txt`）です。ブラウザの編集画面を使わずに、手元のエディタや
スクリプトでこのファイルを書き換えて、そのままページとして使えます。

この方法は、サーバーのフォルダに書き込める人が行います（Wiki のログインとは別に、
OS のファイルの権限で決まります）。ブラウザの編集画面で保存したページは自動で反映されるので、
ここで説明する取り込みは要りません（[ページ編集](/UsageGuide/Edit/Page)）。

- エディタの画面をブラウザの編集画面とつなぎたいときは [外部エディタ連動の編集](/PageEdit/EditorSyncGuide)
- AIエージェントにファイルを書かせるときは [AIとの共同作業](/PageEdit/AI_Collabo)

## ファイルの置き場所

```
wikidata/<Wiki名>/
  wiki/      ページ本体（テキストファイル）
  attach/    添付ファイル
  config/    そのWikiだけの設定
  pageinfo/  変更の記録・検索用のデータベース（システムが書きます。手では触りません）
```

Wiki 名は `ls wikidata/` で確かめられます（この Wiki は `_system` です）。

## ページのファイルの決まり

| ページ（URL） | ファイル（`wiki/` の下） |
|---|---|
| `/`（トップ） | `index.md` |
| `/Tech/ThemeGuide` | `Tech/ThemeGuide.md` |
| `/Tech`（下位のページを持つ） | `Tech/index.md` |

- フォルダの構成が、そのままページの階層（URL）になります。フォルダを URL で開くと、その中の `index` が開きます
- 拡張子 `.md` は Markdown、`.txt` は PukiWiki記法のページです。文字コードは UTF-8 です（[書きかた](/Syntax)）
- `=` や `.` で始まる名前は使えません（[ページの名前のルール](/Syntax/Common#ページの名前のルール)）
- **同じ場所に次のものを両方置くと、片方が読めなくなります。**
  - 同じ名前の `.txt` と `.md` — `.txt` が優先され、`.md` は読まれません（画面は、取り込むまで前に公開した内容のままです）。タイトルの右端に ⚠ が出ます（[直しかた](/UsageGuide/Edit/Duplicate)）
  - 同じ名前のファイルとフォルダ（`Tech.md` と `Tech/`）— `Tech.md` は読めません。下位のページを持たせるときは `Tech/index.md` に置きます。取り込みの結果に「同名のフォルダに隠れて読めないページ」と出ます

## 添付ファイル

`attach/` の下に、ページと同じ階層で置きます。置くだけで使えます（取り込みは要りません）。

| ページ | 添付の置き場所 |
|---|---|
| `/Tech/ThemeGuide` | `attach/Tech/ThemeGuide/` |
| `/Tech`（`Tech/index.md`） | `attach/Tech/index/` |
| `/`（トップ） | `attach/index/` |

下位のページを持つページ（入口の `index`）の添付は、`index/` の下に置きます。
本文からは `::` を付けて指します（[共通の書きかた](/Syntax/Common#-を付ければ添付ファイル)）。

## 書き換えたあとの反映

画面に出るのは、システムが取り込んだ内容です。ファイルを書き換えただけでは、すぐには変わりません。

| したこと | 画面での見え方 |
|---|---|
| 新しいページのファイルを置いた | そのページを開いたとき、自動で取り込まれて表示されます |
| 書いてあるページを書き換えた | 取り込むまで、前の内容のままです |
| ファイルを消した | 取り込むまで、ページが残ります |

書き換え・削除を反映するには、サーバーを動かしているパソコンで、wikiSystem のフォルダに移動して
`updatepage` を実行します。サーバーを止める必要はありません。

```bash
./wiki.py updatepage =<Wiki名>              # そのWiki全体の変更を取り込む
./wiki.py updatepage =<Wiki名>/ページ名     # 1ページだけ取り込む
```

```
  [team] 更新: Meeting/2026-10-07
ページの取り込み: 更新1 (1 Wiki, 0.05秒)
```

Windows では `_venv\Scripts\python.exe wiki.py updatepage =<Wiki名>` と実行します
（[Windowsで動かす](/InstallGuide/Windows)）。

取り込むと、次のことが行われます。

- 取り込む前の内容からの差分が、変更の記録に残ります（[変更履歴](/BackupGuide)）
- 一覧・検索・目次・リンクに反映されます。まだ開いていない新しいページは、取り込むまで一覧や検索に出ません

自分で実行しなくても、**サーバーの起動時と、動かしている間は1時間ごと**に、全 Wiki の変更が取り込まれます。
記録との食い違いを見ずに全ページを読み直したいときだけ `--force` を付けます
（`./wiki.py updatepage --force =<Wiki名>`）。

## 取り込む前にブラウザで編集したとき

取り込む前に書き換えたページを編集画面で開くと、書き換えたファイルの内容が出ます。
そのまま保存でき、ファイルの書き換えとブラウザでの編集は、まとめて1つの変更として記録されます。

## 別のパソコンで書いたファイルを使う

サーバーとは別のパソコンで書いたファイルは、サーバーのフォルダへ置いてから取り込みます
（`git pull`・rsync・Syncthing など）。`git pull` や `git reset --hard` で入れ替わったページも、
同じ取り込みで反映されます。

サーバーのコマンドを使えない場所（スクリプト・webhook・cron）からは、
`/.plugin/updateDB` を開いて取り込めます。権限や使いかたは
[平文ファイルの取り込み](/Tech/UpdateDB) にあります。
