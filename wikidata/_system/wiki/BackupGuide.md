# 変更履歴

ページを保存するたびに自動で記録が残り、あとから見比べたり、前の状態に戻したりできます。
他のツールでいう**変更履歴**です。準備は要りません。

## 開きかた

**編集画面の「履歴」タブ**で開きます。見られるのは、そのページを編集できる人だけです。

左のページ一覧の下に、編集しているページの変更履歴が並びます。右には、選んだ時点の内容と、
いまの内容の比較が出ます。

- 開いたときは、**いちばん新しい時点**が選ばれています
- 別の時点を選ぶと、右がその時点の比較に入れ替わります
- 別のページの履歴を見るときは、左のページ一覧でそのページを選びます

## 画面の見かた

#img(履歴タブ（すべて戻す）>demo-all.png)

| 番号 | 何か |
|---|---|
| 1 | **変更履歴の一覧。** 日付は保存した時刻、`+4 -4` はその保存で増えた行数・減った行数。選んだ行が青く出る |
| 2 | **戻しかたのタブ。** 「すべて戻す」と「部分的に戻す」 |
| 3 | **左の文書「この保存の前」。** 選んだ保存が行われる前のページの内容 |
| 4 | **右の文書「現在」。** いまのページの内容 |
| 5 | 実行のボタン。「すべて戻す」では「この状態に復元」、「部分的に戻す」では「選んだ内容を保存」 |

### 左右の文書は、どうやってできるか

- **右（現在）**は、いま保存されているページそのものです
- **左（この保存の前）**は、記録を使って作ります。保存のたびには差分（増減）だけを記録しているので、
  いまの内容から、新しい保存の差分を順に巻き戻して、選んだ保存より前の姿を作ります
- 一覧の日付を選ぶと出るのは、**その保存の前**の内容です。つまり「この保存を取り消したらどうなるか」を見ています。
  `+4 -4` の行なら、右へ戻すと、その4行の追加と4行の削除が打ち消されます

比べた結果は、色で出ます。

| 表示 | 意味 |
|---|---|
| 左が赤い行 | 保存の前にあって、保存で消えた（変わった）行。戻すと**復活**する |
| 右が緑の行 | 保存で足された（変わった）行。戻すと**消える** |
| 斜線の行 | 相手側に対応する行が無い（埋め合わせ） |
| 行の中の濃い色 | 変わった語（「調整」→「再調整」の「再」など） |
| 右上の `+4 -4` | 左から右への、増えた行数・減った行数 |

上の図は、次のような保存の例です。「週次ミーティング」のページを書いたあと、次のように直して保存しました。

- 6行目の「日程の調整」を「日程の再調整」にした
- 「次年度の計画」の行を足した（右の8行目）
- 「決まったこと」の3行（金曜10時・第2会議室・資料は前日までに共有）を、2行（水曜14時・オンライン）にした

履歴の見かたの決まり:

- ページが作られたときの記録は出ません（その前はページが無いため）
- 同じ名前で消して作り直したページは、その前の履歴も続けて出ます（境目に「これより前は作り直す前」と出ます）

## 前の状態に戻す

戻しかたは3通りです。どれも、**いまのページの内容として保存されます**。

| 戻しかた | 使う場所 | 向いている場面 |
|---|---|---|
| すべて戻す | 「すべて戻す」タブ | その保存で入った変更を、まるごと取り消したい |
| 部分的に戻す（まとめて） | 「部分的に戻す」タブ＋「まとめて」 | 変更のかたまり（ブロック）ごとに、戻すか決めたい |
| 部分的に戻す（1行ごと） | 「部分的に戻す」タブ＋「1行ごと」 | かたまりの中の、特定の1行だけ戻したい |

### すべて戻す

1. 左の一覧で、戻したい保存の日付を選ぶ（その**前**の状態に戻ります）
2. 「すべて戻す」のタブで、赤（戻ると復活する）と緑（戻ると消える）を確かめる
3. 右下の**「この状態に復元」**を押す。確認が出るので、よければ進む

ページが、左の内容（この保存の前）そのままになります。図の例では、上の3つの変更がすべて元に戻ります。

### 部分的に戻す

#img(部分的に戻す（まとめて）>demo-block.png)

「部分的に戻す」のタブでは、**右の文書（現在）だけを直します**。左の文書は変わりません。
左と右のあいだに出るボタンで、相違点を左から右へ取り込みます。

| 番号 | 何か |
|---|---|
| 1 | **編集の単位。** 「まとめて」（初期値）か「1行ごと」。ボタンの数と、一度に取り込む範囲が変わる |
| 2 | 相違点ごとの**取り込みボタン**。1行の相違点（6行目） |
| 3 | 同じく取り込みボタン。複数行のかたまり（左の11〜13行目と、右の12〜13行目） |
| 4 | **取り消し（↶）とやり直し（↷）** |
| 5 | **「選んだ内容を保存」。** ここを押すまで、ページは変わりません |

- ボタンを押すと右の文書が書き換わり、差分が計算し直されます。続けて別の相違点を取り込めます
- 取り込みを全部済ませる必要はありません。戻したいところだけを取り込みます
- 取り消し（Ctrl+Z）・やり直し（Ctrl+Shift+Z）で、取り込みを1手ずつ戻せます
- 取り込んだ結果を、**「選んだ内容を保存」**で保存します。確認が出ます

#### まとめて（ブロック単位）

複数行にまたがる相違点を、**1つのかたまり**として扱います。かたまりごとに3つのボタンが出ます。

| ボタン | 意味 |
|---|---|
| → | **上書き。** かたまりの右の行を、左の内容で置き換える（昔の内容に戻す） |
| ↗ | **上に挿入。** 左の内容を、かたまりの**上**へ足す（右の行も残る） |
| ↘ | **下に挿入。** 左の内容を、かたまりの**下**へ足す（右の行も残る） |

図の3（11〜13行目のかたまり）で → を押すと、右の2行（水曜14時・オンライン）が、左の3行（金曜10時・第2会議室・資料は前日までに共有）に置き換わります。
↗ ↘ なら、左の3行が右の2行の上・下に足され、新旧の両方が残ります。

#img(かたまりの「→」を押したあと>demo-after.png)

上の図は、11〜13行目のかたまりで → を押したあとです。そのかたまりは、左右が同じになって差分が消え、
右上の増減は `+2 -1` に減りました。取り消し（↶）が押せるようになっています。
6行目と8行目は、まだ取り込んでいないので、そのまま残っています。

- 左に対応する行が無い相違点（図の右の8行目「次年度の計画」のように、右にだけある行）では、↗ ↘ は押せません。→ は「右の行を取り除く」意味になります（この保存で足された行を消す）
- 取り込まなかった相違点は、右の（いまの）内容のまま残ります

#### 1行ごと（行単位）

かたまりを**1行ずつに分けて**扱います。**すべての行**に、それぞれ操作ボタンが出ます。ボタンは5つになります。

#img(部分的に戻す（1行ごと）>demo-line.png)

| ボタン | 意味 |
|---|---|
| → ↗ ↘ | 「まとめて」と同じ。ただし、その1行だけが対象 |
| ↓ | **下へ送る。** 右の文書は**変えずに**、左の行を1つ下へずらす。行がずれて、違う行どうしが並んでしまったときに、対応の取り直しに使う |
| × | **削除。** 右のその行を取り除く（左には取り込まない） |

↓ と × は似ていますが、違う操作です。**× は右の文書を書き換えます。↓ は右の文書を変えません。**

図の3（11〜13行目）では、3行それぞれにボタンがあります。例えば、11行目の「次回は金曜の10時から」だけを → で戻すと、次のようになります。

#img(11行目だけ「→」を押したあと>demo-line-after.png)

11行目だけが元の内容（金曜の10時から）になり、12行目（オンライン）と13行目はそのまま残っています。
「まとめて」では、この3行を一度に扱うことしかできませんでした。

#### どれを使うか

| 場面 | 使う |
|---|---|
| その保存を丸ごと取り消したい | すべて戻す |
| 変更のかたまりごとに、戻す・戻さないを選びたい | 部分的に戻す（まとめて） |
| 1つのかたまりの中でも、行ごとに判断したい | 部分的に戻す（1行ごと） |
| 昔の内容を、いまの内容に**足したい**（新旧を両方残したい） | 部分的に戻す（↗ ↘） |

迷ったときは、「部分的に戻す（まとめて）」で、戻したいかたまりだけを取り込むのが目安です。
どの戻しかたでも、保存するまでページは変わりません。

### 戻せないとき・断られるとき

- その保存の前の内容が、いまのページと**同じ**ときは、戻しても何も変わらないので、ボタンが押せません
- その保存の前に、**ページがまだ無かった**ときも、ボタンが押せません。ページを消す（空に戻す）のは、編集画面で本文を空にして保存します（[ページ編集](/UsageGuide/Edit/Page#ページを消す)）
- 画面を開いている間に、**ほかの人がそのページを保存**したときは、戻す操作は断られます。再読み込みしてから、やり直してください

### 戻したあと

- 戻す操作も、**1回の保存として記録されます**。戻しすぎても、その記録から戻し直せます
- 戻すのは本文だけです。ページを消したときに `/trashbox` へ移った添付ファイルは戻りません
- 戻した直後の編集画面は再読み込みされます。書きかけが残っていると、そのまま保存したときに[統合する画面](/UsageGuide/Edit/History#同時に編集されていたとき)に進みます

## 記録のされかた

- 中身は差分（増減）だけです
- **10分以内に続けて保存すると、1回分にまとめられます**。戻す操作だけは、まとめられません
- 記録の合計がWikiごとに50MBに達すると、古いものから消えます。
  **記録が20件に満たないページの記録は消えません**
- **消したページの記録も残ります**（[消したページを戻す](/UsageGuide/Edit/History#消したページを戻す)）

書きかけの預かり・保存前の差分・同時に編集されたときは、[ページの履歴管理](/UsageGuide/Edit/History) にあります。
仕組みは [変更履歴の仕組み](/Tech/BackupUI) にあります。
