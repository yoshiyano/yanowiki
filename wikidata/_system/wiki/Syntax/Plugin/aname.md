# aname — ページ内アンカー（リンクの飛び先）を設置する

| 使える記法 | |
|---|---|
| ブロック `#aname()` | ○ |
| インライン `&aname();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

ページの中に、ほかの場所からリンクできる目印（アンカー）を置きます。本家PukiWikiの `aname` の移植です。

### 書きかた

```pukiwiki
#aname(anchorID)
#aname(anchorID){リンク文字列}
&aname(anchorID){リンク文字列};
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `id` | 英字で始まり英数字/`_`/`-`のみ、40文字まで | （必須。常に1番目） | アンカーの名前 |
| `super` | 単語を書くだけ | 使わない | CSSクラスを `anchor_super` にする（見た目はテーマ次第） |
| `full` | 単語を書くだけ | 書かない | リンク先を `#id` ではなく `/このページのパス#id` にする |
| `noid` | 単語を書くだけ | 付ける | `id` 属性を付けない（リンクの飛び先にならない、見た目だけの要素） |
| `nouserselect` | 単語を書くだけ | 選択できる | リンク文字列をドラッグ選択できなくする |

`id` 以外は好きな順で組み合わせられます（`#aname(id, super, full){...}`）。
`super`・`full`・`noid` は中身（リンク文字列）が無いと書けません。
中身には記法もほかのプラグインも使えず、書いたとおりの文字が出ます。

`full` は、[include](/Syntax/Plugin/include) で別のページに差し込まれても、このページの目印へ飛ばしたいときに使います。

### 表示例

| 書きかた | 出力 |
|---|---|
| `#aname(mark)` | `<a class="anchor" id="mark"></a>`（見た目には何も出ない。`[[この場所へ>#mark]]` の飛び先になる） |
| `&aname(mark){見出しの文字};` | `<a class="anchor" id="mark" href="#mark" title="mark">見出しの文字</a>` |

&aname(mark){見出しの文字}; ・ &aname(note1, super){[1]};

同じ `id` を何度使ってもエラーにはなりませんが、ブラウザがどれへ飛ぶかは決まらないので、重複させないでください。

### エラーについて

`id` の省略、`id` の形の誤り、中身なしで `super`／`full`／`noid` を書くと、エラーになります。

```pukiwiki
#aname()
#aname(不正な!id)
#aname(mark, noid)
```

#aname()

#aname(不正な!id)

#aname(mark, noid)

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
