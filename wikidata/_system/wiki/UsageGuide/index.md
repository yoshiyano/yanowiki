## まず読むページ

初めて使うときは、次の順に読むと迷いません。

1. [閲覧する](/UsageGuide/Read) — ページを開く・検索する
2. [編集する](/UsageGuide/Edit) — ページを書く・直す
3. [アカウント](/AccessGuide) — ログイン、パスワード、読める人・書ける人
4. [管理者権限でできること](/AdminGuide) — 管理者と助手向け

画面上の操作は、各ページにスクリーンショットを添えて説明しています。
使いたい機能が決まっているときは、上の表から直接選んでください。

## 画面の見かた

配置はテーマによって異なります。標準のテーマでは、左にメニュー、中央に本文、右にページ内の目次が表示されます。

#img(標準のテーマで開いたトップページ>layout.png)

- **ヘッダ** … サイト名、拡大率のボタン（＋・−と数値）、マーカーのスイッチ（[検索・マーカー](/SearchMarkerGuide)）、
  「ログイン」「トップ」「編集」「新規」のボタン、検索窓
- **本文** … ページの中身。上にページのタイトルが出ます
- **タイトルの右端** … 本文の幅の上限を外すボタン（下記）。同じ名前の `.txt` と `.md` があるページでは、
  橙色の三角（⚠）のアイコンも出ます（[重複したページ](/UsageGuide/Edit/Duplicate)）
- **サイドバー** … 左側にメニュー、右側にそのページの目次
- **フッタ** … 共通のおしらせと、動いているバージョンの番号

メニューは通常のWikiページ（`mainmenu` と `submenu`）でできており、編集すると表示に反映されます。
見た目は [見た目を変えよう](/ThemeGuide) で変えられます。

### 拡大率と本文の幅

- **拡大率** … ヘッダの＋・−で、画面全体を拡大・縮小します。数値の欄に直接入れることもできます
- **本文の幅** … 標準では、読みやすいように本文の幅に上限があります。タイトルの右端のボタンを押すと上限が外れ、
  本文が画面の幅に合わせて広がります。もう一度押すと元に戻ります

どちらも、選んだ状態はブラウザが覚え、ほかのページを開いたときにも引き継がれます。
最初にどうなっているか（標準の拡大率・標準で幅の上限を外すか）は、管理者がWikiごとに決めます
（[テーマと見た目](/AdminGuide/Themes)）。ボタンの有無や場所はテーマによって違います。
