# Markdown記法：ブロック

見出し・段落・箇条書きなど、行単位のかたまりの書きかたです。

## 見出し

行頭に `#` と半角スペースを書きます。`#` の数で階層が変わります。

```markdown
# 大見出し
## 中見出し
### 小見出し
#### さらに小さい見出し
```

**`#` のあとの半角スペースが無いと、見出しになりません。**
見出しはページの目次に自動で並びます（既定では3階層まで）。

### 1行目の見出しはタイトルになります

**1行目の `# 見出し` はページのタイトルになり**、目次には出ません。

```markdown
# ページのタイトル      ← タイトルになる（目次には出ない）

はじめの文章。

# 第1章                ← ふつうの章見出しになる
## 1.1 節
```

2つ目以降の `#` はふつうの章見出しです（章を `##` から書き始めても、目次の見た目は同じです）。

## 改行と段落

### 段落を分けるには空行

```markdown
1つ目の段落です。

2つ目の段落です。
```

↓ こう表示されます

1つ目の段落です。

2つ目の段落です。

### 単純な改行は「つながります」

**行を変えただけでは改行されず**、前の行につながります。

```markdown
1行目
2行目
```

↓ こう表示されます

1行目
2行目

日本語どうしは空白なしで、英数字が隣り合う境目は空白1つでつながります。

### 途中で改行したいとき

改行したい行の**末尾に `\`（バックスラッシュ）を置きます**。

```markdown
1行目\
2行目
```

↓ こう表示されます

1行目\
2行目

末尾の**半角スペース2つ**でも同じです（見えないので `\` がおすすめです）。

## 箇条書き

### 記号つき

```markdown
- りんご
- みかん
- ぶどう
```

↓ こう表示されます

- りんご
- みかん
- ぶどう

`*` や `+` も使えます。

### 番号つき

```markdown
1. 準備する
2. 実行する
3. 片付ける
```

↓ こう表示されます

1. 準備する
2. 実行する
3. 片付ける

番号は全部 `1.` と書いても 1, 2, 3 になります。`3.` から書き始めると 3, 4, 5... と続きます。

### 入れ子にする

**半角スペース2つ**で字下げすると、内側の項目になります。

```markdown
- 果物
  - りんご
    - ふじ
  - みかん
- 野菜
```

↓ こう表示されます

- 果物
  - りんご
    - ふじ
  - みかん
- 野菜

### チェックリスト

```markdown
- [x] 終わったこと
- [ ] これからやること
```

↓ こう表示されます

- [x] 終わったこと
- [ ] これからやること

`x` は半角小文字です（[`tasklist` プラグイン](/Syntax/Plugin/tasklist)の機能です）。

### 項目の中に段落を入れる

項目の下に空行を置き、**半角スペース2つ**で字下げして続けます。

```markdown
- 1つ目の項目

  項目の説明です。同じ項目の中に入ります。

- 2つ目の項目
```

↓ こう表示されます

- 1つ目の項目

  項目の説明です。同じ項目の中に入ります。

- 2つ目の項目

## 定義リスト

項目名の次の行に、`:` と半角空白に続けて説明を書きます。

```markdown
PukiWiki
: 1996年に生まれた日本製のWikiクローン。ここでの記法のもとになっている

Markdown
: John Gruberが考案した軽量マークアップ言語。このWikiのもう一つの記法
```

↓ こう表示されます

PukiWiki
: 1996年に生まれた日本製のWikiクローン。ここでの記法のもとになっている

Markdown
: John Gruberが考案した軽量マークアップ言語。このWikiのもう一つの記法

見た目は [PukiWiki記法の定義リスト](/Syntax/PukiWiki/Block#deflist) と同じです。

## 引用

行頭に `>` を置きます。

```markdown
> 引用したい文章です。
> 続きの行も `>` を付けます。
```

↓ こう表示されます

> 引用したい文章です。
> 続きの行も `>` を付けます。

`>` を重ねると入れ子になります。

```markdown
> 外側の引用
>
> > 内側の引用
```

↓ こう表示されます

> 外側の引用
>
> > 内側の引用

## 区切り線

`-` を3つ以上並べます。

```markdown
---
```

↓ こう表示されます

---

前後に空行を置きます（すぐ上に文字があると、その行が見出しになります）。
