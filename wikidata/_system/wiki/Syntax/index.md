## 書きかたとプラグインの使い分け

**文章の形（見出し・箇条書き・表・リンク・画像）は書きかた**で書きます。
目次を差し込む、枠で囲む、更新されたページを並べる、といった**機能はプラグイン**で呼び出します。

```pukiwiki
* 見出し              ← 書きかた（PukiWiki記法の場合）
''強調'' です。        ← 書きかた（PukiWiki記法の場合）

#contents             ← プラグイン（目次を差し込む）
```

この部分は、ページの書きかたによって変わります（Markdownなら `## 見出し`、`**強調**`）。
**プラグインの呼びかたとリンクの指しかたは、どちらの書きかたでも同じ**です。

## 書きかたは切り替えられます

書きかたはページごとに選べ、**ページの拡張子で決まります。**

| 書きかた | 拡張子 |
|---|---|
| PukiWiki記法 | `.txt` |
| Markdown（GitHub Flavored Markdown） | `.md` |

- **新しく作るページは、既定ではPukiWiki記法です**（管理者が設定 `edit.defaultwiki` で変えられます）
- 編集画面のツールバーの右端で切り替えられます。ツールバーとプレビューはその場で入れ替わり、
  保存するとファイルの拡張子も変わります（本文はそのまま）
