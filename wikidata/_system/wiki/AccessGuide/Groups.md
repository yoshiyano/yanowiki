# グループ

ログインしていれば、だれでもグループを作れます。グループは、[ページのアクセス制限](/AccessGuide/Privileges) で「このグループの人だけ」と
書くときに使います。グループの画面は、アドレス欄に `/.groups` と入力して開きます。管理者と助手は、管理者メニューの「グループ」からも開けます。

#img(グループ作成のタブ>/Tech/Groups/groups-create.png)

- 「グループ作成」のタブで名前を入れて作ります。名前は半角の小文字・数字・`-`・`_` だけです（`all`・`any` は使えません）。作った人が最初のメンバーになります
- メンバーを足す・外すには「グループ編集」のタブで、グループの名前を入れて開きます。足すときは、ユーザー名をスペースかカンマで区切って入れます。外すときは、左のチェックボックスで選んで「削除」を押します
- 編集できるのは、そのグループのメンバーと、管理者・助手です
- メンバーが全員抜けると、グループは無くなります

仕組みは [グループ管理](/Tech/Groups) にあります。
