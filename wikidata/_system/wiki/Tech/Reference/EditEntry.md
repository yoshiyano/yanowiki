# テーマと編集画面への受け渡し

テーマに渡すURL、編集の入口の出し分け、ホットキー、添付の大きさの上限です。

## テーマに渡すURL

機能ごとの基準URLを context に入れてある（`themes.render_theme`）。どれも末尾にページを
付けない形で、テーマ側が `{{ …_url }}/{{ page }}` と書き足す。

| 変数 | 指す先 |
|---|---|
| `edit_url` | そのWikiのトップ（`base_url`）。編集は `{{ edit_url }}/{{ page }}` へ `cmd=edit` をPOSTする |
| `login_url` | `/.login`（いま開いているページを戻り先として添えた形） |
| `search_url` | `/.search` |
| `theme_url` | `/.theme` |

`base_url` を通しているので、`/=sandbox/` を見ているときや `server.prefix` でサブパスに
設置しているときも、その状態を保ったURLになる。

ログイン・トップ・編集・新規の4項目は、本体が組み立てて `{{ common_menu }}` で渡す
（`themes.common_menu_html`）。出し分け（編集・新規は `editable` のときだけ）もホットキーの
目印も本体が持つ（[編集の入口は権限で出し分ける](#編集の入口は権限で出し分ける)）。名前を変える画面の変数
（`rename_url`）は、画面を外したので渡さない（2026-09-29）。変更の記録は編集画面の「履歴」タブだけに
したので、それを指す変数も渡さない。

## 編集の入口は権限で出し分ける

編集の入口は、**見ている人がそのページの編集の権限（`W`）を持つときだけ**出します
（[ページごとの権限](/Tech/PagePermissions)）。

| 入口 | どこ |
|---|---|
| ヘッダの「編集」「新規」 | 本体が組み立てる共通メニュー（`{{ common_menu }}`。`themes.common_menu_html`） |
| 404の「このページを作る」 | `render_no_page`（作ろうとしているページの権限で見る） |
| セクション編集（Ctrl+Alt+ダブルクリック） | `.content` の `data-editable` |
| `#include`・`#pagediv` の見出しの編集ボタン | 差し込まれるページの権限で見る（`_embedpage.title_html`） |
| `#calendar` 系の新規編集のボタン・`#newpage` の入力欄 | 各プラグイン |

ページの表示では、出し分けを `editable` という1つの値に集約しています。自前で編集リンクを
書くテーマ（`pkwk` など）も、`editable` を見ていれば従います。ヘッダの「編集」には
いつも `data-hotkey="edit"` が付き、`common.js` が Alt+E を拾います。

入口を出さないのは使い勝手のためで、編集できるかの判断は編集画面の側（`editor.render_edit`）が
行います。以前あった入口を一律に伏せる設定 `theme.show_edit`・`theme.edit_hotkey` は、
Wiki設計者の「show_edit, theme.edit_hotkey は廃止、入口も権限で出し分けて」（2026-09-29）で
廃止しました。設定ファイルに残っていても効きません。

## 添付ファイルの大きさの上限

`attach.max_size` で決めます。既定は `20MB` です（bottle の `MEMFILE_MAX` はメモリか一時
ファイルかの分かれ目で、上限ではありません）。

| 書きかた | 意味 |
|---|---|
| `20MB` `512KB` `1.5GB` | 単位つき（1024刻み。`B` `K`/`KB` `M`/`MB` `G`/`GB`、大小文字は問わない） |
| `1048576` | 単位なしの数（byte） |

読めない書きかたのときは既定（20MB）として扱います。

判定は、画面では送る前に（`File.size` を見て、超えるものは送らない）、サーバーでは書き出す
前に（実際の長さを測る。`Content-Length` は信用しない）行います
（[編集機能の仕組み](/Tech/EditGuide/Attach#送る前に大きさを見る)）。上限は添付タブにも表示されます。

受け付ける側（nginx・Apache など）にも上限があります。大きな値にする場合はそちら
（nginx なら `client_max_body_size`）も合わせてください。
