# readauth — ページを閲覧できるユーザを指定する

| 使える記法 | |
|---|---|
| ブロック `#readauth()` | ○ |
| インライン `&readauth();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

ページを閲覧できるユーザを、ページの中に書いて指定します。書き込みを制限したいときは [writeauth](/Syntax/Plugin/writeauth) を使います。

書いた内容は `config/privileges.plugin` に権限として記録され、管理画面 `/.admin/privileges` で登録する権限と同じように効きます。ページには何も表示されません。

旧名の `#viewaccess(...)` は使えません（プラグインが見つからないエラーになります）。`#readauth(...)` に書き換えてください。

### 書きかた

```pukiwiki
#readauth(id1,id2,...)
```

| 引数 | 書式 | 既定 | 意味 |
|---|---|---|---|
| `users` | ログインIDか `g:グループ名` を `,` 区切りで列挙 | （省略すると、記録を削除） | 閲覧を許可するユーザ |

- 実在しないユーザ・グループを書くとエラーになります（あとから同じ名前で作られた人に権限が渡らないように）
- 中身（`{…}`）を書いても使われません（エラーにもなりません）

### 注意

- **秘密を守る用途には使えません。** 見せかたを制御するためのものです。本当に読ませたくないものは置かないか、前段のWebサーバーなどで止めてください
- ページを編集できる人なら誰でも、そのページの閲覧権限を書けます。編集の権限を [writeauth](/Syntax/Plugin/writeauth) で先に絞っておいてください
- 手で書く `config/privileges` より優先されますが、緩める方向には働きません。`#readauth` で絞ったページを `config/privileges` で開放することはできません（[ページごとの権限](/Tech/PagePermissions/Evaluate#configprivilegesplugin-との優先順位)）

### 記録される内容

`Tech/Secret` に `#readauth(alice,bob)` と書くと、次の1行が記録されます（行の形は手で書く `config/privileges` と同じ）。

```text
Tech/Secret:R:alice,bob:260921_103000
```

「ページ名:種類:許可者:登録日」の並びで、`R` は閲覧（`#writeauth` は `W`）です。ページ名はいつも書いたページ自身です。
許可者を書き換えると記録も書き直されます。

### 権限を消す

1. `#readauth()`（空の呼び出し）にして、ページを開きます。記録の該当行が削除されます
2. そのあと、`#readauth()` の行をページから消します

行だけを消した場合も、記録は1時間以内に自動で消えます。すぐに消したいときは `/.updatePageAuth` を
開きます（誰でも実行できます。1時間に10回まで）。ページを削除したときの記録も同じく消えます。

### 置ける場所は、ページの一番上だけ

途中に書くと、ページを開いたときに、保存済みの本文からその行が消えて先頭へ移ります。

```pukiwiki
本文1
#writeauth(carol)
本文2
#readauth(alice,bob)
本文3
```

↓ ページを開くと

```pukiwiki
#readauth(alice,bob)
#writeauth(carol)
本文1
本文2
本文3
```

- `#writeauth` と両方あれば、`readauth`、`writeauth` の順に並びます
- 同じプラグインが複数行あれば、最初の1行だけが残り、あとの行は消えます
- Markdownのページで、本文の最初の空でない行がタイトル行（`# 見出し`、または次の行が `===` だけの見出し）なら、そのすぐ下へ移ります（先頭に置くと、見出しがタイトルとして取り出されなくなるため）。PukiWiki記法のページとタイトル行の無いページでは先頭行です
- コードブロックの中・ほかのプラグインの複数行の中身・字下げした行（リストや引用の中）は、書きかたの例とみなして動かしません
- 編集中のプレビューでは、移動も記録の書き換え・削除もしません（エラーは確かめられます）

### エラーについて

| 書きかたの例 | エラーになる理由 |
|---|---|
| `#readauth(nobody)` | 実在しないユーザ（`g:` のグループも同じ） |
| `#readauth(alice)`（記録が書けないとき） | `config/privileges.plugin` に書き込めない。**このままでは制限が効きません** |
| 名前に `*` を含むページに書いた | ワイルドカードと区別が付かず、記録できない |

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
