# 見た目を変えよう

見た目のひとそろいを「テーマ」と呼びます。このページは、管理者・助手でない人（ログインしていない人も）ができることの案内です。

- テーマを選ぶ欄で、自分のブラウザでの見た目を切り替える
- 端末のダークモードに合わせて、暗い配色で見る
- メニューのページを書き換える（そのページを編集できる人）

Wiki全体の既定のテーマや、テーマのファイルを変えるのは、そのWikiの管理者と助手です（[テーマと見た目](/AdminGuide/Themes)）。

## テーマを選ぶ

メニューの先頭に「テーマ:」の欄が出ているWikiでは、読む人が自分で見た目を選べます。

- 欄でテーマを選ぶと、すぐに切り替わります（切り替わらないときは「切替」を押します）
- 選んだテーマは、**そのブラウザで、そのWikiだけ**に、1日のあいだ効きます。ほかの人の見た目は変わりません
- 「既定に戻す」を押すと、Wikiの既定のテーマに戻ります

欄が出ていないWikiでは、管理者が欄を出していません。

## ダークモード

`base`・`fresh`・`bloom` は、端末がダークモードのとき自動で暗い配色になります。
`pukiwiki_default`・`post_it_1`・`pkwk` は、いつも明るい配色です。

## メニューを編集する

サイドバーのメニューは普通のWikiページで、そのページを編集できる人が書き換えられます。

| メニュー | ページ名 |
|---|---|
| 上のメニュー | `mainmenu` |
| 下のメニュー | `submenu` |

たとえば `mainmenu` をこう書けば、そのままメニューになります。

```markdown
## メニュー

- [ようこそ](/)
- [使ってみよう](/UsageGuide)
```

- リンクは `/` から始まる形で書くと、どのページから見ても正しく飛べます
- メニューのページが無いときは、その枠ごと表示されません

下の階層を持つ項目は、三角を押して開け閉めできます。項目の頭の記号で、最初に開いておくか閉じておくかを決めます。

```markdown
- [書きかた](/Syntax)            最初から開いておく
  - [共通の書きかた](/Syntax/Common)
+ [プラグイン](/Syntax/Plugin)    最初は閉じておく
  - [br](/Syntax/Plugin/br)
* [技術ドキュメント](/Tech)       開け閉めしない（下の階層を常に見せる）
  - [設計方針](/Tech/DesignPolicy)
```

- `-` と `+` を混ぜて並べても、1つの箇条書きとしてつながります
- この決まりは Markdown で書いたメニューだけで効きます（PukiWiki記法の `+` は番号付きの箇条書きです）
- 読む人が開け閉めした状態は、そのブラウザが覚えます。別のページへ移っても、開けた項目は開いたまま、閉じた項目は閉じたままです。覚えるのは、頭の記号が決めた最初の状態から変えた項目だけなので、記号を書き換えたときは、読む人が触っていない項目から新しい最初の状態になります
- メニューを書き換えて、無くなった項目・リンク先を変えた項目の記録は、そのメニューを次に開いたときに自動で捨てられます

どのページをメニューにするかは、管理者が設定で変えられます（[テーマと見た目](/AdminGuide/Themes#設定で変える)）。

## 用意されているテーマ


| 名前 | 雰囲気 |
|---|---|
| `base` | 標準。青系で、機能がひととおり見える形。menu1が左・本文が中央・目次とmenu2が右の3コラム（画面が狭いときは自動で2コラム→1コラムに詰まる） |
| `fresh` | 薄緑系。爽やかで、すっきり整理された見た目。サイドバーは右 |
| `bloom` | 薄オレンジ系。余白をゆったりとった、やわらかい見た目 |
| `pukiwiki_default` | PukiWiki 1.5系の既定の見た目（薄青）を、`base` を土台に再現したもの |
| `post_it_1` | PukiWikiの配色をもとにした、付箋風の見た目 |
| `pkwk` | `post_it_1` を土台に、PukiWiki標準の配色（薄青）へ寄せたもの |
