# glossarytip — ページ内の用語をtooltipで参照できるようにする

| 使える記法 | |
|---|---|
| ブロック `#glossarytip()` | ○ |
| インライン `&glossarytip();` | — |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

ページの中の[定義リスト](/Syntax/Markdown/Block#定義リスト)（`用語` `: 説明`）を集め、本文の別の場所に同じ用語が出てきたら、
マウスを乗せて説明を読めるようにします。呼んだページだけで有効になり、その場には何も表示しません。

### 書きかた

```pukiwiki
#glossarytip()

wiki_dir
: そのWikiの実体ディレクトリ（絶対パス）

`resolve_page_ref(wiki_dir, pagepath)` は、wiki_dirを受け取ります。
```

1つの項目に `/` 区切りなどで複数のコードを並べると、それぞれが同じ説明を持つ別の用語になります。

```pukiwiki
`subpath` / `subpaths`
: ページの実体パス（wiki_dir相対、拡張子抜き）
```

### どこを対象にするか

- ページ内のすべての定義リストが用語集になります（`#glossarytip()` の前後は問いません）
- 用語と**完全に一致する**部分だけが対象です（`subpath` が `subpaths` の一部に一致することはありません）。大文字と小文字は区別します
- `` `コード` `` の中も対象です
- 定義リスト自身の中は対象外です
- 同じ用語が複数回定義されていれば、最初の定義を使います

### 性質

- 見た目は破線の下線とカーソルの変化だけで、説明はブラウザ標準のtooltip（`<abbr title="...">`）で出ます
- JavaScriptが無効なら、tooltipにならないだけで本文はふつうに読めます
- 定義リストが無いページで呼んでも、エラーにはなりません
