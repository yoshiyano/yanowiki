## 記法とプラグインの使い分け

**文章の形（見出し・箇条書き・表・リンク・画像）は記法**で書きます。
目次を差し込む、枠で囲む、更新されたページを並べる、といった**機能はプラグイン**で呼び出します。

```pukiwiki
* 見出し              ← 記法（PukiWiki記法の場合）
''強調'' です。        ← 記法（PukiWiki記法の場合）

#contents             ← プラグイン（目次を差し込む）
```

記法の部分はページの記法によって変わります（Markdownなら `## 見出し`、`**強調**`）。
**プラグインの呼びかたとリンクの指しかたは、どちらの記法でも同じ**です。

## 記法は切り替えられます

記法はページごとに選べ、**ページの拡張子で決まります。**

| 記法 | 拡張子 |
|---|---|
| PukiWiki記法 | `.txt` |
| Markdown（GitHub Flavored Markdown） | `.md` |

- **新しく作るページは、既定ではPukiWiki記法です**（管理者が設定 `edit.defaultwiki` で変えられます）
- 編集画面のツールバーの右端で切り替えられます。ツールバーとプレビューはその場で入れ替わり、
  保存するとファイルの拡張子も変わります（本文はそのまま）
