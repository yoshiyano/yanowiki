# 更新履歴

バージョンごとの、前のバージョンからの主な変更点です。

## 1.2.0（2026-10-27）

1.1.1 から 1.2.0 へは、[インストールの案内](/InstallGuide#更新する) の手順で手で更新してください。1.2.0 からは、管理者が画面から更新できます。

- 公開版からの更新
    - 新しいバージョンが出ると、既定のWikiの管理者と助手に、タイトル右端の info で知らせる
    - 管理の画面（`/.admin/update`）で、いまと最新のバージョン・更新で変わることを見て、更新して再起動できる
- 外部エディタ連動（新規）
    - 編集画面とセクション編集の本文を、手元の VS Code・Emacs・Neovim と同期して書ける
    - エディタのプラグインとブラウザ拡張機能は、この Wiki のページ（[外部エディタ連動の編集](/PageEdit/EditorSyncGuide)）から配る
- ファイル一覧
    - コピー、ページのフォルダ化、名前の変更の中断と再開（管理の画面「中断した操作」）
    - 添付のあるページを消すときは、添付をどうするか尋ねる。消したページの添付は trashbox へ移す
- アカウントと権限
    - 助手に与える権限を、助手ごと・操作ごとに管理者が決められる（`/.admin/staffperms`）
    - 承認制の申請の受付に上限を設け、止めているあいだは承認する人に info で知らせる
- テーマ
    - スロット型のテーマ（HTML に差し込む場所を書くだけで作れるテーマ）
    - 管理の画面「テーマのファイル」で、テーマのファイルを扱える
    - タイトルの右端に、本文の幅の上限を外すボタンと、info の知らせ
    - 設定に、標準の拡大率と、標準で本文の幅の上限を外す設定
    - メニューの下の階層を開け閉めでき、ブラウザが覚える
- 同じ名前の `.txt` と `.md`（と、同じ名前のファイルとフォルダ）があると info で知らせ、画面から整理できる
- 新しいWikiを作るとき、既定の書きかたとサイト名を選べる
- プラグイン
    - 新規: `mekuri`（中身を隠し、クリックでめくる）
    - `table`: セルの中に複数行・ブロック要素を書ける。列の幅・表の幅・二重線
    - `comment`・`vote`: ページを移らずに投稿・投票でき、メニューや表の中でも使える
    - `ref`・`attachls`: 画像以外の添付は、既定でダウンロードさせる（右クリックで表示も選べる）
    - `popular`: 除外の指定
- 守りの強化
    - 別のサイトから送られた POST を断る
    - HTTPS で開いたときは、cookie に `Secure` を付ける
    - 添付の中身を、Wiki のページと同じオリジンで動かさない

### 前のバージョンと使いかたが変わるもの

- リンク先が添付ファイルかどうかは、`::`（`[[::a.zip]]`）と、設定の拡張子の一覧（`attach.link_exts`）で決める。名前の形だけでは添付とみなさない
- `comment`・`vote` は、JavaScript が無いと投稿できない
- `/.restart?now=1` は POST でだけ受け付ける（GET では確認の画面）
- テーマ `pkwk_wide` をなくした。使っていたWikiは、ほかのテーマに切り替える
- 検索結果のテンプレート（`search.html`）を `theme/` から `_sys/search/` へ移した
- `PLUGIN_INFO` を宣言していないモジュールは、プラグインとして登録しない

## 1.1.1（2026-10-06）

- 初めて起動したとき、既定のWikiに管理者がいなければ、管理者のパスワードを決められるようにした
- 管理の画面（`/.admin`）に「新しいWikiを作る」を足した
- README にクイックスタートを足した。インストールの案内に、初期設定・自分のWikiをつくる手順・対応する Ubuntu と Python のバージョンを足した

## 1.1（2026-09-30）

動かすには Python 3.12 以上が要ります（uv が入れます）。

- アカウントと権限
    - アカウント・ログイン・グループ、承認制の登録
    - ページごとのアクセス制限（閲覧・編集）と、`#readauth`・`#writeauth`
    - 助手グループと管理の画面（`/.admin`）。助手の操作の記録と取り消し、認証の記録
    - 編集の入口を、編集の権限がある人にだけ出すようにした
- ファイル一覧（`/.files`）: ページとフォルダを一覧で見て、名前の変更・移動・削除・新規作成ができる
- 編集: 編集画面の「履歴」タブ、狭い画面でのページ一覧、添付ファイルの貼り付け
- Wiki の運用
    - Wikiを消す画面（`/.delwiki`。消す前に 7z に固める）
    - PukiWiki のデータを移す道具（`./wiki.py convwiki`）
    - リバースプロキシの後ろで、外向きの別名で公開できるようにした
    - 設定の画面で、定義ルール（文字列の置き換え）を書けるようにした
- プラグイン: カレンダー系、`newpage`・`new`・`navi`・`blockdiv`・`pagediv`・`attachls`・`viewable_period` などを足した
- テーマ: `pkwk_wide` を足した。全テーマで共通のメニュー、Ctrl+F で検索窓へ
- 前のバージョンと使いかたが変わるもの
    - `/.backup` をやめた。履歴は編集画面の「履歴」タブで見る
    - 設定の `theme.show_edit`・`theme.edit_hotkey` をやめた（編集の入口は権限で決まる）

## 1.0（2026-09-05）

- 編集
    - 見出しごとに編集できるようにした（セクション編集）
    - 編集が競合したら、3文書マージで統合できるようにした
    - 編集画面を、ページ自身のURLで開くようにした
- 記録
    - 差分のバックアップをファイルからDBへ移し、毎日の控えと、そこからの復元を足した
    - バックアップの画面に「一部を戻す」を足した
- 書きかた
    - PukiWiki の書きかたの残りを実装した
    - 相対リンク `{[…]}`、保存時のページ名の置き換え、注釈のツールチップを足した
    - コードブロックの色付け（Prism.js）
    - 本文に書いた HTML を、既定では通さないようにした
- 設定・テーマ
    - `config/` には `*.example.yaml` だけを置くようにした（直した設定は Wiki ごとの `config/` に書く）
    - 設定の `theme.default` を `theme.name` に改名した
    - テーマをフォルダの形でも置けるようにした。閲覧者がテーマを選べるようにした
- リネームの不具合をいくつか直した
- プラグイン: `code`・`comment`・`vote`・`popular`・`katex`・`hr`・`html`・`updateDB` を足した
