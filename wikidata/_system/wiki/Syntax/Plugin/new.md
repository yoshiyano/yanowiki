# new — 日付やページの更新が新しければ「New!」の印を付ける

| 使える記法 | |
|---|---|
| ブロック `#new()` | × |
| インライン `&new();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

日付や、ページの最終更新が新しいとき、そのうしろに印を付けます。PukiWikiの `new` の移植です。

| 経ったとき | 印 |
|---|---|
| 1日以内 | ` New!`（赤。クラス `new1`） |
| 5日以内 | ` New`（緑。クラス `new5`） |
| それより前 | 付けない |

印にマウスを重ねると、どれくらい前か（`(3h)`・`(2d)` など）が出ます。

## 引数

| 引数 | 意味 | 省略したとき |
|---|---|---|
| `page` | 更新の新しさを見るページ。末尾が `/` なら、その下のページのうち一番新しいもの | このページ |
| `nolink` | ページへのリンクを出さない | 出す |
| `nodate` | `{日付}` を書いたとき、日付の文字を出さない | 出す |

## 書きかた

### 日付を書く

PukiWikiの `#comment` が書き込んでいた形です。PukiWiki記法（`.txt`）では丸括弧を省けます。
Markdown（`.md`）では `&new(){日付};` と丸括弧を付けます。

```pukiwiki
- 質問です -- 山田 &new{2026-09-25 (金) 18:15:23};
```

生成されるHTML（1日以内のとき）:

```html
<span class="comment_date">2026-09-25 (金) 18:15:23<span class="__plugin_new new1" data-mtime="2026-09-25T18:15:23+09:00" title="(5h)"> New!</span></span>
```

`2026-09-25 18:15`・`2026/9/25`・`2026-09-25T18:15:23+09:00` のような形も読めます。
日付の文字を出さず印だけにするときは `&new(nodate){2026-09-25 (金) 18:15:23};` と書きます。

### ページの更新の新しさ

```pukiwiki
&new(お知らせ);
&new(日記/);
```

生成されるHTML（1つ目。5日以内に更新されたとき）:

```html
<a href="/お知らせ">お知らせ</a><span class="__plugin_new new5" data-mtime="2026-09-23T10:00:00+09:00" title="(3d)"> New</span>
```

- `日記/` のように末尾に `/` を付けると、その下で一番新しく更新されたページへのリンクと印を出します
- `nolink` を書くと、リンクを出さず印だけにします（`&new(お知らせ, nolink);`）
- 閲覧できないページは、無いページと同じ扱いです

## 古くなった日付の &new は外れます

日付を書いた `&new` は、5日を過ぎて印が付かなくなると、そのページを開いたときにプラグインが外れて
日付の文字だけになります（`&new(nodate){…};` は何も残りません）。見た目は変わりません。変更は履歴に残ります。

- ページを指定した `&new(ページ名);` は外れません（ページが更新されれば、また新しくなるため）
- 書きかたの例として書いたもの（囲みコード・コードスパン・PukiWiki記法の整形済みテキスト・`#code` などの中）は書き換わりません

## エラーについて

| 書きかた | エラーの内容 |
|---|---|
| `&new(なし);` | そのページはありません: なし |
| `&new(なし/);` | その下にページがありません: なし/ |
| `&new{きのう};` | 日付として読めません: きのう |
| `&new(お知らせ){2026-09-25};` | 日付を書くときは、ページ名は書けません（&new(nodate){日付};） |

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
