# ref — 添付ファイルを参照する

| 使える記法 | |
|---|---|
| ブロック `#ref()` | ○ |
| インライン `&ref();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

添付ファイル（または外部URL）を参照します。PukiWiki の `ref` と同じ値を指定できます。
画像ならそのまま表示し、それ以外（PDF・文書・圧縮など）なら、種類のバッジ・ファイルサイズ・更新日時の付いたリンクにします。
どちらにするかは拡張子で決まります（`noimg` で、画像もファイルとして扱えます）。

### 書きかた

```pukiwiki
#ref(src)                       ブロック
#ref(src, right)                右寄せ
#ref(src, right, around)        右寄せ＋回り込み
#ref(src, 300x200)              サイズを指定
#ref(src, 資料)                 表示する文字を変える
#ref(src, align=center, wrap)   名前付きでも書ける（align・size・title）
&ref(src);                      文中に差し込む
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| **`src`** | 添付ファイル名かURL | なし（**省略不可。常に1番目**） | 参照するファイル |
| `size` | `300x200`等（下記） | 元の大きさ | 大きさ（画像のみ） |
| `align` | `LEFT`/`CENTER`/`RIGHT` | `LEFT` | 寄せ方（ブロックのみ） |
| `around` | 単語を書くだけ | 回り込まない | 回り込ませる（ブロックのみ） |
| `wrap` | 単語を書くだけ | 囲まない | 枠（背景つきの箱）で囲む（ブロックのみ） |
| `noicon` | 単語を書くだけ | 出す | 画像以外のファイルで、種類のバッジを出さない |
| `nolink` | 単語を書くだけ | 画像そのものへのリンクにする | 画像をリンクにしない（クリックしても移動しない） |
| `noimg` | 単語を書くだけ | 画像として表示 | 拡張子が画像でも、ファイルとして扱う |
| `zoom` | 単語を書くだけ | — | 本家互換のために受け付けるだけ（出力は変わらない） |
| `title` | 任意の文字 | ファイル名 | 表示する文字 |

- `src` より後ろは好きな順で書けます。どれにも当てはまらなかった残りは `title` になります
- 単語だけの引数に `=true` は付けられません（`wrap=true` はエラー）
- `size` は [img](/Syntax/Plugin/img#zoom大きさの書きかた) の `zoom` とほぼ同じで、`300x200`/`300x`/`x200`/`300w`/`200h`/`50%` が使えます（`300px` の正方形指定はありません）
- `align`・`around`・`wrap` をインラインに書いても、エラーにはならず使われないだけです
- `src` の指しかたは、ほかのリンクと同じ規則です（[共通の書きかた](/Syntax/Common) 参照）
- 中身（`{…}`）は使いません

### 表示例

画像（`.png`/`.jpg`/`.jpeg`/`.gif`/`.webp`/`.svg`/`.avif`/`.bmp`/`.ico`）は `<img class="plugin-ref-image">` をリンクで包んで表示します。
それ以外は種類のバッジ（PDF・動画・音声・文書・表計算・スライド・圧縮・コード・テキスト・その他。編集画面の「添付ファイル」タブと同じ分類）付きのリンクになります。

`&ref(document.pdf);`（2.3MB・2026-08-20 10:15更新のファイル）の出力:

```html
<a href="/.attach/このページ/document.pdf" class="plugin-ref-file" title="2.3 MB・2026-08-20 10:15 更新">
<span class="ref-name">document.pdf</span>
<span class="ref-kind ref-kind-pdf">PDF</span>
<span class="ref-info">2.3 MB・2026-08-20 10:15 更新</span>
</a>
```

ブロックで `CENTER`・`wrap` を付けると、これが `<div class="plugin-ref">` と `<div class="plugin-ref-box">` で包まれます。

### 閲覧できないページの添付ファイル

添付ファイルの持ち主のページを閲覧する権限が無い人（[ページごとの権限](/Tech/PagePermissions)）には、
書かれた名前（`title` を書いていればその文字）に「閲覧できないファイル」と添えて表示します。
リンクにはならず、大きさ・更新日時も出さず、画像も展開しません。
ファイルが実在しなくても同じ表示なので、そのページに何があるかは分かりません。閲覧できる人には、ふだんどおり表示されます。

```html
<span class="plugin-ref-file plugin-ref-denied"><span class="ref-name">資料.pdf</span><span class="ref-kind ref-kind-denied">閲覧できないファイル</span></span>
```

外部のURL（`&ref(https://…);`）は対象外です。

### エラーになる書きかた

| 書きかた | 理由 |
|---|---|
| `#ref()` / `&ref();` | `src` を省略した |
| `&ref(nosuchfile.pdf);` | 添付ファイルが実在しない（まだ無いページへのリンクは許すこのWikiで、ここは例外です。持ち主のページを閲覧できない人には、エラーではなく上の「閲覧できないファイル」になります） |
| `&ref(src, size=abc);` | `size` がどの書式にも合わない |
| `#ref(src, wrap=true)` | 単語だけの引数に `=true` を付けた |

詳しくは [共通の書きかた](/Syntax/Common#うまく動かないとき) を参照してください。
