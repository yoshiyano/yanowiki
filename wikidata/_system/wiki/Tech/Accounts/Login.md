# ログイン（`#login` プラグイン経由）

#img(ログインのフォーム（/.login）>login-form.png)

IDとパスワードを `/.plugin/login` へ送ると、サーバー側で照合します
（[ページの中でログインする](/Tech/LoginPlugin)）。結果はその場では出さず、フォームを
置いたページ（`back`）へ303で転送してから案内を出します。そのまま出すと、再読み込みで
IDとパスワードが送り直されるためです。打った値は転送先へ持ち回しません。

| | 転送先のクエリ | 出るもの |
|---|---|---|
| 合っていた | `?login=done` | 「ログインしました。」の案内 |
| 違っていた | `?login=ng` | 1秒おいてから、断りの案内 |
| ロック中 | `?login=lock` | ロックされている旨の案内 |

ほかの値（承認待ちの `?login=pending` など）は
[ページの中でログインする](/Tech/LoginPlugin#結果はページのurlで受け取る) にあります。
1秒（`auth.RETRY_DELAY`）待つのはサーバー側です（総当たりの速度を落とすため）。

照合が通ると、ログイン状態をcookieに控え、次からはパスワードが要りません。

| 名前 | 中身 |
|---|---|
| `wikiuser_<Wiki名>` | そのアカウントの `uid`。`#login` のID欄を埋めるのにも使う |
| `wikiauth_<Wiki名>` | そのログイン状態が本物であることの**合言葉**（下記） |

どちらも `Path` はそのWikiのURL（`/=<Wiki名>`。既定のWikiは `/`）・`HttpOnly`・
`SameSite=Lax`・期限2日です。既定のWikiのcookieは `Path=/` でどのWikiにも送られるので、
名前にWiki名を付けて区別しています（`paths.wiki_cookie_name`）。サービス全体の操作をWiki名の無いURLに
限っているのもこのためです（[既定Wikiの役割](/Tech/DesignPolicy/Farm#デフォルトのwikiの役割)）。以下では `_<Wiki名>` を
略して `wikiuser`・`wikiauth` と書きます。

## 合言葉（`wikiauth`）の作りかた

次の材料を連結して SHA-1 にかけた値です（`wikilib.auth.session_token`）。`cnt` だけは
`\x00` を挟んで最後に付けます。

| 材料 | なぜ入れるか |
|---|---|
| `uid` | 誰のものかを分ける |
| Wiki名 | どのWikiのものかを分ける |
| 日付番号 | `time.time() // 1日`。1日ごとに変わる |
| `pw`（保存されているハッシュ値） | パスワードを変えると無効になる |
| 設置ごとの合言葉 | `config/secret.txt` の10文字。画面には出さない |
| `cnt`（`\x00` の後ろ） | ログイン状態の世代。上げると、それまでの合言葉がすべて無効になる。無い・空は0 |

`wikiuser` だけでは何も認めません。`wikiauth` と揃って、サーバー側で作り直した値と
一致したときだけ通ります（`wikilib.auth.current_user`）。`pw` を先頭2文字だけ混ぜる案は、
推測すべき部分が256通りしかなく手元で総当たりできるので採らず、`pw` 全体と設置ごとの
合言葉を混ぜています。

`config/secret.txt` は無ければ自動で作ります（`0600`、紛らわしい字を除いた英数字10文字）。
漏れると一覧のハッシュ値と合わせて合言葉を作られるので、Wikiの外に出さないでください
（gitの追跡からも外してあります）。

## 他端末からの認証を解除する（`cnt`）

`#login` の「アカウント」タブの、「ログアウト」の上にあるボタンです。パスワードは変えずに、
いま出回っている合言葉をすべて無効にします。

1. `passwd.cnt` を1つ上げる（`userdb.bump_cnt`）。それまでの合言葉は端末を問わず通らなくなる
2. 押した端末には、新しい `cnt` で合言葉を作り直して置き直す（`remember_login`）。
   押した端末は入ったまま、他の端末は次に開いたとき入れ直しになる

- 対象は押した人自身のアカウントだけです（`current_user` から決める）
- `cnt` はパスワードのハッシュ（`pw`）には混ぜません（生のパスワードを持たないので、
  混ぜると誰もパスワードで入れなくなる）
- 列はあとから足したもので、古いDBでは自動で足され、既存のアカウントは0です。
  この版に上げた直後は、全員のcookieが1度だけ通らなくなります

## 1日ごとに変わりますが、毎日開いていれば入れ直しは要りません

合言葉は1日で変わりますが、昨日のぶんも通し、通ったときにその場で今日のぶんに
置き換えます。毎日開いている人は入れ直しになりませんが、2日以上あくと切れます。
cookieの期限も2日にしてあるのは、25時間ぶりに開いた人がcookie自体を失わないためです。

#note(type=warn){{
**守れること・守れないこと**

- パスワードを変えれば、持ち出された合言葉は通らなくなります
- パスワードを変えずに取り消せるのは、「他端末からの認証を解除する」を押したときだけです。
  どちらもしなければ、持ち出された合言葉は最長2日通り続けます
- **管理者のログイン状態が1つあれば、そこから全部が開きます**（`/.admin/accounts` から
  他人のパスワードを書き換えられるため）。管理者の合言葉は、パスワードと同じ重さで扱ってください
}}
