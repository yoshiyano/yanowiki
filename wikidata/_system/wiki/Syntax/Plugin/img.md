# img — 画像を差し込む

| 使える記法 | |
|---|---|
| ブロック `#img()` | ○ |
| インライン `&img();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

画像を差し込みます。添付ファイル・外部URLのどちらも指定できます。

### 書きかた

```pukiwiki
#img(src)                    ブロック
#img(src, right)             右寄せ（回り込み）
#img(タイトル>src)            図の下にタイトルを表示
&img(src);                   文中に差し込む
&img(src, w50%);             表示幅の半分にする（レスポンシブ）
#img(, clear)                画像を出さず、回り込みを止める
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| **`src`** | URLか添付ファイル名 | なし（常に1番目） | 表示する画像 |
| `float` | `right`/`left`/`clear`（省略形`r`/`l`/`c`） | 指定なし | 回り込み（ブロックだけ。インラインでは無視） |
| `zoom` | [下記の書式](#zoom大きさの書きかた) | 元の大きさ | 大きさ |
| `makelink` | `true`/`false`/`nolink` | `true` | `true` でクリックすると[拡大表示](#クリックしたときの拡大表示)、`false`/`nolink` でしない |

- `src` より後ろは好きな順で書けます
- `src` の指しかたは、ほかのリンクと同じ規則です（[共通の書きかた](/Syntax/Common) 参照）。添付ファイルは実在しないとエラーになります
- `タイトル>src` の形（`[[タイトル>リンク先]]` と同じ）で書くと、図の下にタイトルを表示します

### 回り込み

| `float` | 意味 |
|---|---|
| `right` / `r` | 右寄せして、後ろの文章を回り込ませる |
| `left` / `l` | 左寄せして、後ろの文章を回り込ませる |
| `clear` / `c` | 回り込みはせず、その下で回り込みを止める |
| （省略） | ふつうのブロックとして並ぶ |

`src` を省略できるのは、`#img(, clear)` のときだけです。画像は出さず、回り込みを止める `<div style="clear:both">` だけを出します。

```pukiwiki
#img(sample.png, right)
これは画像の左に回り込んで表示されます。

#img(, clear)
ここからは全幅で表示されます。
```

`right`/`left` のブロックでは、中身（`{…}`／`{{ … }}`）に書いた文章が画像の横に回り込みます。中身にはブロック記法・インライン記法・ほかのプラグインが使えます。
回り込みは中身の範囲で閉じるので、あとに `#img(, clear)` は要りません。
それ以外のときの中身は、回り込まずに画像のすぐ後ろに出ます（インラインでは使われません）。

```pukiwiki
#img(sample.png, left){{
**強調**した文章や、[リンク](/UsageGuide)も書けます。

- 箇条書きも
- 使えます
}}
```

### `zoom`（大きさ）の書きかた

| 書きかた | 意味 |
|---|---|
| `300x200` | 幅300px・高さ200pxの枠に、縦横比を保って収める |
| `300px` | 幅300px・高さ300pxの正方形の枠に収める |
| `300x` / `300w` | 幅300px、高さは縦横比のまま |
| `x200` / `200h` | 高さ200px、幅は縦横比のまま |
| `50%` | 50%に縮小・拡大（CSSの `zoom`） |
| `w50%` | 表示幅（containing block）の50%（レスポンシブ）。回り込ませる（`right`・`left`）ときは、本文の幅の50% |
| `[200;80%;600]` | 表示幅の80%を目安に、幅200px〜600pxに収める |

`[MIN;VALUE%;MAX]` は CSS の `clamp(MIN, VALUE%, MAX)` に当たります（引数に丸括弧を書けないので角括弧）。
MIN・MAXは数値（px）か、`%`（画像の実寸に対する割合）で書けます。`%` はページの読み込み後にブラウザ側（`plugin/img.js`）で計算するので、JavaScriptが無効なら `VALUE%` の幅だけが効きます。

### クリックしたときの拡大表示

`makelink` が `true`（既定）なら、画像をクリックすると、ページを移動せずにダイアログで拡大表示します（画面に収まる大きさまで。タイトルがあれば添えます）。

| 操作 | 動き |
|---|---|
| 画像をクリック | ダイアログで拡大表示する |
| 拡大表示中に、どこかをクリック・Escキー | 閉じる（閉じた直後の0.5秒ほどは、画像をクリックしても開き直さない） |
| 拡大表示中に、ダブルクリック | 画像を別タブで開き、ダイアログを閉じる |
| Ctrl・⌘・Shift・Altを押しながらのクリック、中クリック | 拡大表示せず、ブラウザのふつうの動き |

拡大表示するのは `img` のリンク（`class="plugin-img-link"`）だけで、[ref](/Syntax/Plugin/ref) の画像リンクは画像そのものへ移動します。
JavaScriptが無効な環境や `<dialog>` に対応しないブラウザでは、画像へのふつうのリンクです。

### 出力

ブロックは `<div class="plugin-img">`（回り込みは `class="plugin-img plugin-img-float" style="float:right"` で、左右に1remずつ空きます。タイトルは `div.plugin-img-title`）、インラインは `<img class="plugin-img-inline">` です。
画像を `<a class="image-link plugin-img-link">` で包み、中身を回り込ませるときは全体を `div.plugin-img-wrap` で包みます。

### エラーになる書きかた

| 書きかた | 理由 |
|---|---|
| `#img()` / `&img();` | `src` を省略した（`clear` 以外） |
| `&img(sample.png, notazoom);` / `#img(sample.png, up)` | どの引数の値としても解釈できない |
| `&img(nosuchfile.png);` | 添付ファイルが実在しない |

詳しくは [共通の書きかた](/Syntax/Common#うまく動かないとき) を参照してください。
