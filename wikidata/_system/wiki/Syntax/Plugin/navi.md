# navi — 目次ページと子ページを行き来する送りを出す

| 使える記法 | |
|---|---|
| ブロック `#navi()` | ○ |
| インライン `&navi();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

1つのフォルダを本に見立て、入口ページを目次、下のページを各章として行き来できるようにします。本家PukiWikiの `navi` の移植です。

### 書きかた

```pukiwiki
#navi()
#navi(手引き)
#navi(手引き, reverse)
#navi(手引き, , "/_")
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `home` | ページ名（1番目） | いま開いているページ | 目次にするページ |
| `reverse` | 単語（2番目） | 名前順 | 一覧と前後送りの並びを逆にする |
| `exclude` | 正規表現（3番目） | 外さない | ページパス（`手引き/_下書き` の形）に部分一致するページを、一覧と送り先から外す |

- `home` の指しかたは本文のリンクと同じです。`手引き` と `/手引き` はどちらもWikiの先頭から（となりではない）、`./手引き` はいまのページの下、`../手引き` は1つ上から
- カンマや `=` を含む正規表現は引用符で囲みます（`#navi(手引き, , "^手引き/_,?")`）
- 外したページ自身に書いた `#navi` も、前後送りは出します

### 置いた場所で出るもの

子ページには、本文の先頭と末尾に1つずつ書きます。

| 置いた場所 | 出るもの |
|---|---|
| 目次ページ（`#navi()`） | 下にある子ページの一覧（`ul.navi_contents`） |
| 子ページの1回目 | 「前へ／目次ページの見出し／次へ」の送り（`ul.navi`）と、その下に区切り線（`hr.full_hr`） |
| 子ページの2回目以降 | 区切り線と、送り先のページ名・「目次」「上へ」を添えた送り |

- 並びは名前順で、数字は数として比べます（`page2` は `page10` より前）。大文字小文字は区別しません
- リンクの文字はページの見出し（無ければページパス）です
- 並びの先頭のページでは「前へ」が目次ページを指し、末尾のページでは「次へ」が空になります
- 「上へ」は1つ上のページです。1つ上にページが無いとき・浅いページでは出ません
- 閲覧する権限の無いページは、一覧にも送り先にも出ません（[ページごとの権限](/Tech/PagePermissions)）

### エラーになる書きかた

| 書きかた | エラー |
|---|---|
| `#navi(あり得ないページ名)` | 目次ページがありません: /あり得ないページ名 |
| `#navi(.hidden)`・`#navi(home="=other/手引き")` | 目次ページの指定が正しくありません |
| `/別のフォルダ/ページ` や `/手引き2` に `#navi(手引き)` | /手引き の子ページではありません（ページパスが `手引き/` で始まるかで判定） |
| 子ページを持たないページに `#navi()` | 子ページがありません |
| 目次ページに `#navi()` を2つ | 子ページの一覧はすでにこのページに出ています |
| `#navi(手引き, 逆)` | 逆順の指定が正しくありません |
| `#navi(手引き, , "[")` | exclude の正規表現が正しくありません |
| `#navi(手引き, reverse, "/_", よけい)` | 引数の解釈に失敗しました。 |

`=` で始まる名前を1番目にそのまま書く（`#navi(=other/手引き)`）と、共通の決まりで「知らない引数です:」のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。

### 本家PukiWikiとの違い

- リンクの文字は、ページ名ではなく見出しです
- `exclude` 引数は本家にありません（本家ではPHPの定数 `PLUGIN_NAVI_EXCLUSIVE_REGEX`）
- `<head>` への `<link rel="next">` などの差し込みはありません（本家も既定では無効）
- 「上へ」は、1つ上にページが無ければ出しません
- 送りの文字は日本語です（本家は `Prev`/`Next`/`Up`/`Home`）
