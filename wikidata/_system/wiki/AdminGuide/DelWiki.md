# Wikiの削除

使わなくなったWikiを、管理者メニューの「Wikiを消す」から1つ消せます。**消すと元の場所からは無くなる**ので、間違いを防ぐために、
確かめが4段あります。開けるのは**起点Wikiの管理者と助手**だけです（`/=<Wiki名>/.delwiki` の形では開けません）。
起点Wikiそのものは消せません。別のWikiを起点Wikiに切り替えてから削除してください。

## 4つの段

| 段 | 入れるもの | 何のため |
|---|---|---|
| 1 | 消すWikiの名前 | どれを消すかの確かめ（一覧から選ばず、書きます） |
| 2 | **そのWikiの管理者（`admin`）のパスワード** | 起点Wikiの管理者であっても、別のWikiを消すには、そのWikiの管理者の確認が必要なため |
| 3 | ディスク使用量とトップページの最終更新日 | いま、そのWikiを実際に見ていることの確かめ |
| 4 | 最後の確認 | ここで初めて消える |

どんなWikiがあるかは、管理者メニューの「Wikiの一覧」で見られます（[Wiki Farm](/FarmGuide#どんなwikiがあるか)）。

### 3段目に入れるもの

消すWikiのトップページを開き、フッターの値を写します。

```
Last-modified: 2026-09-18 14:33          → 「2026-09-18」と書く
DiskUsage: Page/Attached 1.2MB/349KB     → 「1.2MB/349KB」と書く
```

フッターの行をまるごと貼っても通ります。どちらが違ったかは伝えません。

## 消す前の書庫

2段目を通ると、裏で `wikidata/<Wiki名>.<yymmdd_hhmmss>.7z` という書庫を作り始めます（`7z` が必要です）。
書庫が出来上がるまで、実体は消えません。4段目で押したときにまだ作成中なら、少し待って押し直します。

書庫には、ページ・添付・アカウント・設定などが入っています。**間違えて消したら、`wikidata/` で展開すれば元どおりです。**

```bash
cd wikidata && 7z x sandbox.260918_143012.7z
```

消したあとも書庫は残ります。要らなければ手で消してください（消すと戻せません）。

仕組みは [Wikiを消す仕組み](/Tech/DelWiki) にあります。
