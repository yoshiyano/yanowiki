# Wiki Farm（複数のWiki）

1つのサーバーで、いくつものWikiを動かせます。このように複数のWikiをまとめて運用する仕組みを
**Wiki Farm** と呼びます。話題や用途ごとにWikiを分けても、同じサーバーと共通の機能を使えます。

## Wikiごとに別のもの・共通のもの

| | |
|---|---|
| Wikiごとに別 | ページ・添付ファイル・メニュー（`mainmenu` と `submenu`）・設定・アカウント・アクセス制限・変更の記録 |
| 全Wikiで共通 | プラグイン・共通のテーマ・共通の設定（Wikiごとの設定が、その上に重なります） |

アカウントもWikiごとなので、あるWikiで作ったアカウントは、別のWikiには入れません。
見た目は、共通のテーマから選んだり、そのWiki専用に作ったりできます（[見た目を変えよう](/ThemeGuide)）。

## 別のWikiを開く

名前の前に `=` を付けてアクセスします。

```
/=team/            team という名前のWikiのトップページ
/=team/UsageGuide  team という名前のWikiの UsageGuide ページ
```

名前を付けずに開く `/` や `/UsageGuide` は、**起点Wiki**のページです。起点Wikiとは、Wiki名をURLに
書かなかったときに表示するWikiです。また、サービス全体に関わる管理画面を開く Wiki にもなります。
どのWikiを起点にするかは設定ファイル `config/server.yaml` の `farm.default` で決まり、初期状態では
説明用の `_system` が指定されています。
起点Wikiも `/=<名前>/UsageGuide` と書いて開けます。そのときは、リンクをたどっても
`=<名前>/` が付いたままになります。

ページ名は `=` や `.` で始められません（`=` は別Wikiの指定、`.` はシステムの画面に使うため）。

### どんなWikiがあるか

管理者メニューの「Wikiの一覧」で、名前・トップページの見出し・ページ数を一覧で見られます。
開けるのは**起点Wikiの管理者と助手だけ**です（一覧を出さない設定にしているサイトもあります）。

## 起点Wikiの管理者が行うこと

サービス全体に関わる次の操作は、いま開いているWikiではなく、**起点Wikiの管理者と助手**が行います。
ここでいう助手は、管理者が管理作業を任せた人です。ほかのWikiの管理者が管理できるのは、自分のWikiの中だけです。

| 操作 | 案内 |
|---|---|
| Wikiを新しく作る | [Wikiの新規作成](/AdminGuide/NewWiki) |
| Wikiを消す | [Wikiの削除](/AdminGuide/DelWiki) |
| サービスの再起動 | [管理者権限でできること](/AdminGuide) |

Wikiの名前を変えるのは、そのWikiの管理者が設定画面で行います（[Wikiの設定](/AdminGuide/Config)）。

管理者のツールは [管理者権限でできること](/AdminGuide) にまとめてあります。
仕組みや設計の理由は [Wiki Farm とURLの設計](/Tech/DesignPolicy/Farm) にあります。
