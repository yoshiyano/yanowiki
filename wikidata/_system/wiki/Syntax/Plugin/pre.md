# pre — 整形済みテキスト（コード表示など）をそのまま表示する

| 使える記法 | |
|---|---|
| ブロック `#pre()` | ○ |
| インライン `&pre();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

中身を書いたとおりに `<pre>` で表示します。行頭にスペースを置く[整形済みテキスト](/Syntax/PukiWiki/Preformatted#pre)と同じ見た目で、スペースは要りません。
このシステム独自のプラグインです。

### 書きかた

```pukiwiki
#pre(){{
中身
}}
#pre(verb, copy, color=#223344){{
中身
}}
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `verb` | 単語を書くだけ | 展開しない | 中身をインライン記法・インラインプラグインとして展開する |
| `copy` | 単語を書くだけ | 出さない | 右上に「COPY」ボタンを出す（書いたとおりの生のテキストをコピー） |
| `color` | `#RGB` または `#RRGGBB` | 指定なし | 枠の背景色（色名やアルファつきの16進は不可） |

引数は好きな順で組み合わせられます。

`verb` が無ければ、中身は何を書いても解釈されず、そのまま出ます（コードやプラグインの書きかたの例を見せるのに向いています）。
`verb` があっても、段落・見出し・リストのようなブロックの記法は展開されません。

### 表示例

```pukiwiki
#pre(){{
def hello():
    print("hello")
}}
```

#pre(){{
def hello():
    print("hello")
}}

`copy` と `color`:

#pre(copy, color=#2b2b2b){curl https://example.com/}

`verb`（`<code>` で包まれず、展開後のタグが入ります）:

```pukiwiki
#pre(verb){{
**太字** や &note(type=tip){ヒント}; も展開されます
}}
```

#pre(verb){{
**太字** や &note(type=tip){ヒント}; も展開されます
}}

中身にほかのインラインプラグインを書くときは、`{{ ... }}` で書いてください。
1行の中身 `{ ... }` の中に別のプラグインの `{…}` を書くと、波括弧の対応が取れずエラーになります。

### エラーについて

中身の省略と、`color` の形の誤りはエラーになります。

```pukiwiki
#pre()
#pre(color=red){中身}
```

#pre()

#pre(color=red){中身}

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
