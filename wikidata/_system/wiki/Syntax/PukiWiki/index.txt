拡張子が .txt のページの書きかたです。書きかたの枠のすぐ下に、その表示が並びます。

#contents

* まずはこれだけ [#first]

#code(pukiwiki){{
* 見出しをつける              行頭に *
- 箇条書きにする              行頭に -
''強調する''                  ' を2つで囲む
[[リンクを貼る>UsageGuide]]   [[ ]] で囲む
|表を|つくる|                 | で区切る
}}

この5つで、ひととおりのページが書けます。

* ブロックとインライン [#kind]

ページは''ブロック''（行単位のかたまり）でできていて、その中に''インライン''（文字の飾り）を置きます。

** ブロック … ページを組み立てる「かたまり」

見出し・段落・箇条書き・引用・表は、どれもブロックです。

- 行の変わり目で始まり、行の変わり目で終わります
- 記号を置かずに書いた行は''段落''になります
- ''空行はブロックの区切り''です（箇条書きや引用は、空行で終わります）
- 箇条書きの中の段落、引用の中の箇条書きのように、中に別のブロックを入れられるものがあります

種類は、行の始まりに置く記号で決まります。

- ''*'' … [[見出し>/Syntax/PukiWiki/Block#heading]]
- ''-'' ''+'' … [[箇条書き>/Syntax/PukiWiki/Block#list]]
- ''>'' … [[引用>/Syntax/PukiWiki/Block#quote]]
- '':'' … [[定義リスト>/Syntax/PukiWiki/Block#deflist]]
- ''|'' '','' … [[表>/Syntax/PukiWiki/Table#table]]
- ''半角スペース'' … [[整形済みテキスト>/Syntax/PukiWiki/Preformatted#pre]]
- ''----'' … [[区切り線>/Syntax/PukiWiki/Block#hr]]
- ''//'' … [[表示されない行>/Syntax/PukiWiki/Inline#hidden]]
- ''#'' … ブロックのプラグイン（[[目次・画像・コメント欄など>#plugin]]）
- ''記号を置かない'' … 段落

** インライン … かたまりの中に置く「飾り」

強調・リンク・注釈などは、ブロックの中の文字の流れに置くインラインです。
見出し・表のセル・箇条書きの項目など、どのブロックの中でも使えます。

#code(pukiwiki){{
''強調''             クォート記号で挟む
[[UsageGuide]]       角かっこ2つで挟む
((注釈))             丸かっこ2つで挟む
&size(150%){文字};   & で始めて ; で閉じる
行末に ~             そこで改行する
}}

- 挟んで飾る … [[強調・斜体・打ち消し>/Syntax/PukiWiki/Inline#inline]]
- 挟んでリンクにする … [[リンク>/Syntax/PukiWiki/Link#link]]
- 挟んで注釈にする … [[注釈>/Syntax/PukiWiki/Inline#note]]
- ''&'' で始めるもの … インラインのプラグイン（[[一覧>/Syntax/Plugin]]）
- 行末の ''~'' … [[そこで改行>/Syntax/PukiWiki/Block#para]]

段落の中に、強調・リンク・プラグインの3つのインラインを入れた例です。

#code(pukiwiki){{
ここは ''強調'' して、[[リンク>UsageGuide]] を貼って、
&size(150%){大きな文字}; も混ぜられます。
}}

↓ こう表示されます

ここは ''強調'' して、[[リンク>UsageGuide]] を貼って、
&size(150%){大きな文字}; も混ぜられます。

** プラグインにも両方ある

- ''#名前(引数)'' … ブロックのプラグイン
- ''&名前(引数);'' … インラインのプラグイン（''末尾の ; を忘れずに''）

詳しくは [[プラグイン>#plugin]] の節をご覧ください。

* プラグイン [#plugin]

目次・画像・コメント欄など、記法だけではできないことはプラグインで行います。

#code(pukiwiki){{
#contents

文中に置くときは &size(150%){大きな文字}; のように書きます。
}}

- 行頭に ''#名前(引数)'' … 段落として置く（目次・画像・コメント欄など）
- 文中に ''&名前(引数);'' … 文の中に置く（文字色・ルビ・添付ファイルなど）

一覧は [[プラグイン>/Syntax/Plugin]]、呼びかたの決まりは [[共通の書きかた>/Syntax/Common]] にあります。よく使うもの：

|~やりたいこと|~プラグイン|h
|目次を出す|[[#contents>/Syntax/Plugin/contents]]|
|画像を貼る|[[#img>/Syntax/Plugin/img]] / [[#ref>/Syntax/Plugin/ref]]|
|文字に色をつける|[[&color>/Syntax/Plugin/color]]|
|文字の大きさを変える|[[&size>/Syntax/Plugin/size]]|
|ふりがなをふる|[[&ruby>/Syntax/Plugin/ruby]]|
|注意書きを目立たせる|[[#note>/Syntax/Plugin/note]]|
|コードを色つきで見せる|[[#code>/Syntax/Plugin/code]]|
|コメント欄をつくる|[[#comment>/Syntax/Plugin/comment]]|

* まだ使えない書きかた [#unsupported]

''生のHTMLは書けません''（文字として表示されます）。

#code(pukiwiki){{
<b>太字にしたい</b>
}}

↓ こう表示されます

<b>太字にしたい</b>

管理者が設定 pukiwiki.allow_html で許可すれば書けます（[[本文に書くHTMLの扱い>/Tech/HtmlPolicy]]）。

本家PukiWikiの標準プラグインは、よく使うものを用意しています（[[一覧>/Syntax/Plugin]]）。用意していないものは赤い枠のエラーになります。

* この記法で書くには [#editnotation]

''新しく作るページは、既定ではこの記法です''（管理者が設定 edit.defaultwiki を markdown にすると変わります）。

記法は''編集画面のツールバーの右端で選べます''（ツールバーとプレビューもその場で切り替わります）。
記法はページの''拡張子''で決まるので、すでにあるページで選び直すと、保存したときに Foo.md が Foo.txt になります。
''本文は変換されない''ので、プレビューを見ながら書き直してください。

** 置き場所の決まりは記法によらず同じ

- ''フォルダの階層をそのままなぞります''（/Tech/Reference は Tech/Reference.txt）
- ''フォルダの入口は index です''（/Tech は Tech/index.txt）
- ''ページ名の日本語は、そのままファイル名になります''

* うまくいかないとき [#trouble]

|~こうなった|~たぶん原因|h
|箇条書きにならない|''-'' の前に空白が入っていませんか。''-'' は行頭に置きます（行頭が半角スペースだと整形済みテキストになります）|
|強調されない|ダブルクォートを使っていませんか。シングルクォート2つです|
|表がずれる|行末の縦棒を忘れていませんか|
|改行されない|行末に ''~'' を置いてください。行を変えただけではつながります|
|区切り線が箇条書きになる|''-'' が3つ以下です。4つ以上書いてください|
|プラグインが赤い枠で出る|名前の綴りか、引数の書きかたが違います。枠の中に理由が出ます|
