# br — 強制的に1行分の空白（改行）を入れる

| 使える記法 | |
|---|---|
| ブロック `#br()` | ○ |
| インライン `&br();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

段落の区切りでは足りないときに、1行分空けたり、文の途中で改行したりします。
本家PukiWikiの `br` の移植で、引数はありません。

| 書きかた | 出力 |
|---|---|
| `#br()`（ブロック） | 1行分の空白 `<div class="spacer">&nbsp;</div>` |
| `&br();`（インライン） | 文中の改行 `<br class="spacer">` |

PukiWiki記法のページでは丸括弧を省いて `#br`／`&br;` とも書けます。
Markdownのページでは省くと展開されないので、必ず `#br()`／`&br();` と書いてください。

### 表示例

```pukiwiki
1行目です。
#br()
2行目です。

文中に&br();強制改行を入れます。
```

1行目です。
#br()
2行目です。

文中に&br();強制改行を入れます。

### エラーについて

引数を書くとエラーになります。

```pukiwiki
#br(foo)
```

#br(foo)

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
