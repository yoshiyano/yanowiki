# 保守と運用

管理者と助手が、ときどき使うツールです。

## 助手の操作の記録

助手が行った操作の記録を、管理者が、管理者メニューの「助手の操作の記録」で確かめ、間違いを元に戻します（既定では**管理者だけ**。
[助手の権限](/AdminGuide/StaffPerms)で許せば、助手も見る・戻すができます。
記録するのは助手の操作だけで、管理者の操作は残しません）。

#img(記録の一覧>/Tech/StaffLog/stafflog.png)

記録されるのは、ページの保存・削除・名前の変更や移動、添付の操作、設定・アクセス制限・グループ・アカウントの承認、
添付の整理、Wikiの作成・削除・名前の変更・再起動、テーマのファイルの操作です。

記録を開くと、操作の前後を見比べられます。戻せる操作には「**元に戻す**」が出ます。

#img(記録の詳細>/Tech/StaffLog/stafflog-detail.png)

- **いまの状態が、その操作の直後のままのときだけ戻せます。** あとから書き換えられていたら断ります。そのときは前後の内容を見て、手で直します
- 戻したことは記録に書き添えられ、同じ記録は二度戻せません
- Wikiの作成・名前の変更・再起動、テーマのファイルの操作は、記録だけで戻すボタンはありません

## 中断した操作を続ける

ページの名前の変更・移動は、時間がかかると途中で止まり、「中断」として残ることがあります。
続きは、[ファイル一覧](/FilesGuide)の何も無いところの右クリック「中断した操作を続ける」か、
管理者メニューの「中断した操作」から行います。サーバーを起動し直しても、自動では続きません。
中断しているあいだは、範囲が重なる名前の変更・移動・削除はできません（ページの編集はできます）。

## 消したページの添付を集める

ページを消すと、その添付はすぐ `/trashbox` というページへ移ります。見えなくなった添付が残ったときのために、
1時間ごとにも自動で集めています。すぐ集めたいときは、管理者メニューの「削除したページの添付」を開きます。
移すものの一覧が出るので、確かめて実行します。

#img(確認の画面>/Tech/GarbageCollect/garbagecollect.png)

- 移した添付は `元のフォルダ名__ファイル名` の名前になります（例: `講義_第01回__a.png`）
- `/trashbox` を開けるのは**管理者と助手だけ**です。元のページが閲覧を絞っていても、制限が外れないようにするためです

## サービスを再起動する

管理者メニューの「サービスの再起動」を開くと、確認の画面が出ます。ボタンを押すと、このWikiサービスが再起動します。
ファイルを更新したあと（[更新のしかた](/InstallGuide#更新する)）に、反映するために使います。

- 実行できるのは**起点Wikiの管理者と助手**だけです。`/=<Wiki名>/.restart` の形では開けません

## 公開版から更新する

公開版に新しいバージョンが出ると、既定のWikiのタイトル右端に、緑の上向きの矢印が出ます。押すか、管理者メニューの
「公開版からの更新」を開くと、いまのバージョン・最新のバージョンと、更新で変わること（[更新履歴](/ChangeLog)）が出ます。
「更新して再起動する」を押すと、最新版を取り込んで再起動します。

- 使えるのは**起点Wikiの管理者と、再起動を許された助手**だけです。矢印もその人にだけ出ます
- [インストールの案内](/InstallGuide) の `git clone` で入れたままの場合だけ更新できます。ほかのファイルを手で書き換えていると、
  更新できない理由が画面に出ます。そのときは [手で更新する](/InstallGuide#更新する) 手順を使ってください
- このサーバーで `_system` のページを書き換えていると、更新で公開版の内容に戻ります（画面に一覧が出ます）
- 途中で失敗したときは、更新の前の状態に戻します

## ページのファイルを直接書き換えたとき

ページの `.md`・`.txt` をエディタなどで直に書き換えたら、取り込みを実行します
（検索・一覧に反映されます）。

```bash
./wiki.py updatepage =<Wiki名>
```
