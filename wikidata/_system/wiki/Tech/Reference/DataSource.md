# DBと平文の読み分け

表示・検索・一覧がDBと平文のどちらを読むかと、保存のあとに行う後始末です。

## どこがDBを読み、どこが平文を読むか

本文は平文ファイル（`wiki/*.md` / `*.txt`）とDB（`pageinfo/wikiall.db`）の両方にある。
**DBに入っているものが「公開されたページ」**で、平文だけを書き換えた分は取り込む
（`./wiki.py updatepage`）まで公開されない。

| 場面 | 読む先 | なぜ |
|---|---|---|
| ページの表示・メニュー | **DB** | 公開されたものを見せる |
| 検索・更新順の一覧 | **DB** | 同上 |
| ページ一覧のタイトル・プラグインが見る目次 | **DB** | 表示した内容と食い違わないように |
| `#ls` の一覧（名前・見出し・日時・大きさ） | **DB** | 公開されたページだけを並べる |
| 保存時の差分の基準・「更新状況」の差分 | **DB** | 確定していない現存ファイルと比べても意味がない |
| 「履歴」タブの「今の内容」 | **DB** | 差分の連鎖と起点をそろえる（下記） |
| **編集画面** | **平文** | DBを読むと、直接編集した分が画面に出ないまま上書き保存されて消える |

DBに行が無いページも、平文ファイルがあればその場で取り込んでから表示する
（[ファイルがあれば取り込む](/Tech/PageDataBase/Writes#ファイルがあれば取り込む)）。

### さかのぼる起点もDB

編集画面の「履歴」タブ（`?cmd=history`）は、今の内容から差分を1本ずつ逆適用して各時点を
復元する。差分は「公開されていた内容 → 新しい内容」で記録されているので、起点も
DBでなければならない。平文を起点にすると、直接編集して取り込んでいない状態で
復元がずれ、しかも差分としては辻褄が合うため `broken` も立たず、保存した覚えのない
内容が「その時点の記録」として出る。ページが今も在るかの判断も同じ理由でDBを見る。

### 「在る」は `exists` と呼ばない

ページが「在る」かを返すJSONは2つあり、同じ「在る」でも見ている先が違うので、名前を分けている。

| API | キー | 意味 | なぜそちらか |
|---|---|---|---|
| `/.pagetree`（ページ選択ダイアログ・編集画面のページ一覧） | `has_file` | 平文ファイルがあるか | 編集が扱うのは作業中のもの |
| `?cmd=history` の `data=history`（編集画面の「履歴」タブ） | `published` | 公開されているか | 差分の基準・画面の表示と同じ判断 |

`PageRef.exists` は、作った関数で指すものが変わる。`resolve_page_ref()`（`paths.py`）が
作ったものは平文ファイルの有無、`pagedb.published_ref()` が作ったものは公開されているか
（公開されていなければ `exists=False` のPageRefを返す）。どちらでも `not ref.exists` が
その場面で正しい「無い」になる。

`published_ref()` の戻り値は、**`-`（読めない）でも本文を持っている**。表示する側は
本文を出す前に `ref.privilege` を見ること。ページの表示は、読めない名前なら無いページでも
403にしている（作成の誘いを出しても、作ったあと本人が開けないため）。

## ページ保存の後始末

本文が変わったときは、どこから変えても `pagesave.save_page` が差分の記録・平文の書き出し・
DBの入れ直しを行う（[ページのデータベース](/Tech/PageDataBase/Writes#保存save_page)）。

| 呼ぶところ | 変わるところ |
|---|---|
| 編集画面の保存（`editor`） | ふつうの保存。新規作成も「空からの差分」として残る |
| バックアップからの復元（`backupui`） | `merge=False`（戻した事実を必ず1本残す） |
| 平文の取り込み（`pagesync`） | `write=False`（すでにファイルにある内容を後から記録する） |
| 名前の変更に伴うリンクの直し（`pagerename`） | `merge=False` |

差分の基準はシステムが最後に知っている内容（DB）で、現存する平文ではない
（[どこがDBを読み、どこが平文を読むか](#どこがdbを読みどこが平文を読むか)）。
