# Markdown記法：表とコード

表と、コードを載せる書きかたです。

## 表

`|` で区切り、2行目に `---` を並べます。

```markdown
| 名前 | 説明 |
|---|---|
| base | 標準のテーマ |
| fresh | 薄緑のテーマ |
```

↓ こう表示されます

| 名前 | 説明 |
|---|---|
| base | 標準のテーマ |
| fresh | 薄緑のテーマ |

### 文字の位置を揃える

2行目の `---` に `:` を付けると、その列の位置が変わります。

```markdown
| 左寄せ | 中央 | 右寄せ |
|:---|:---:|---:|
| a | b | 100 |
| あああ | いいい | 20 |
```

↓ こう表示されます

| 左寄せ | 中央 | 右寄せ |
|:---|:---:|---:|
| a | b | 100 |
| あああ | いいい | 20 |

### 表の中でも飾れる

セルの中で太字・コード・リンクが使えます。

```markdown
| 項目 | 値 |
|---|---|
| **太字** | `コード` |
| [リンク](/) | ~~打ち消し~~ |
```

↓ こう表示されます

| 項目 | 値 |
|---|---|
| **太字** | `コード` |
| [リンク](/) | ~~打ち消し~~ |

**表の中では改行できません。**

## コード

### 文の中に埋め込む

前後を `` ` ``（バッククォート）で囲みます。

| 書きかた | 表示 |
|---|---|
| `` `wiki.py` を開く `` | `wiki.py` を開く |

コードの中に `` ` `` を含めたいときは、囲む側を2つにします
（`` `` `code` `` `` → `` `code` ``）。

### まとまったコードを載せる

前後を ``` で囲みます。言語名は省略できます。

````markdown
```python
def hello():
    print("こんにちは")
```
````

↓ こう表示されます

```python
def hello():
    print("こんにちは")
```

コードの中に ``` を含めるときは、囲む側を4つ（````）にします。

### 色を付ける

**言語ごとの色付けは、ページのどこかに `#code()` と書いたときだけ有効です。**

````markdown
#code()

```python
def hello():
    print("こんにちは")
```
````

`#code()` 自体は何も表示せず、ページのどこに置いても全体に効きます。行番号やコピーボタンは
[`#code`](/Syntax/Plugin/code) をご覧ください。
