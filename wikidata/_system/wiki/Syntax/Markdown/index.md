# Markdown記法

拡張子が `.md` のページの書きかたです。**GitHub Flavored Markdown（GFM）** に準拠しています
（`.txt` のページは [PukiWiki記法](/Syntax/PukiWiki)）。

新しく作るページの既定はPukiWiki記法です。Markdownで書くときは、編集画面のツールバーの右端で
`Markdown` を選びます（既定は、管理者が設定 `edit.defaultwiki` を `markdown` にすると変わります）。

## まずはこれだけ

この6つで、ひととおりのページが書けます。

| やりたいこと | 書きかた |
|---|---|
| 見出しをつける | 行頭に `## ` |
| 太字にする | `**太字**` |
| 箇条書きにする | 行頭に `- ` |
| リンクを貼る | `[文字](/ページ名)` |
| 表をつくる | `\|` で区切る |
| 区切り線を引く | `---` |

## 使えない書きかた

他のMarkdownで見かけても、このWikiでは使えない（文字として表示される）ものです。

| 書きかた | 代わりに |
|---|---|
| 脚注 `[^1]` | 引用や小さい文字で本文に書く（下の注意も参照） |
| 絵文字コード `:smile:` | 絵文字を直接貼る 😊 |
| 上付き `x^2^` / 下付き `H~2~O` | HTMLの `<sup>` / `<sub>` を使う |
| ハイライト `==重要==` | `**太字**` か `<mark>` を使う |

- `<sup>` `<mark>` は[HTMLを直接書く](/Syntax/Markdown/Html#htmlを直接書く)ので、管理者が許可している場合だけ使えます
- **脚注の定義行（`[^1]: 説明`）は書かないでください。** リンクの定義として読まれてその行は消え、
  本文の `[^1]` が `^1` という文字のリンクになります

## よくあるつまずき

| 症状 | 原因 |
|---|---|
| 太字にならず `**` が出る | 太字にしたい部分の**内側**に空白が入っている（`** 強調 **`）。かっこや句読点の隣には[空白を入れずに書けます](/Syntax/Markdown/Inline#かっこや句読点をまたいでも太字になります) |
| 見出しにならない | `#` のあとに半角スペースが無い |
| 改行されない | 行を変えただけでは改行にならない。末尾に `\` を置く |
| 箇条書きにならない | `-` のあとに半角スペースが無い |
| 表が崩れる | 2行目の `\|---\|---\|` の数が、見出しの列数と合っていない |
| 入れ子にならない | 字下げが全角スペースになっている。**半角スペース2つ**で |
| リンクが切れる | ページへのリンクなのに `/` から始めていない |
| 意図せず見出しになった | 段落のすぐ下に `---` を書いた。空行を空ける |
