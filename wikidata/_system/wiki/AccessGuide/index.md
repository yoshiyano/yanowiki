# アカウント

アカウントは、IDとパスワードで「だれか」を確かめるためのものです。ログインすると、**書けるページが増える**
Wikiがあり、誰の文責かを残したいWikiでは、ログインした人だけが編集できます。
ログイン・パスワード・グループ・ページごとの制限の入口です。

## アカウントについて

- **アカウントはWikiごと**です。あるWikiで作ったアカウントは、ほかのWikiでは使えません（[Wiki Farm](/FarmGuide)）
- アカウントを作れるかどうかは、Wikiごとの設定で決まります。**誰でも作れて、すぐ使える**Wikiと、
  申請して、**管理者か助手が承認するまで使えない**Wiki（承認制）があります。Wikiを作るとき、使いかたと一緒に選びます
  （[Wikiの新規作成](/AdminGuide/NewWiki#使いかた)）
- パスワードを間違え続けると、そのIDは一時的に入れなくなり、さらに続くとロックされます
  （[アカウント作成とログイン](/AccessGuide/Login#間違えたときロックされたとき)）
- 読める人・書ける人は、アカウントとは別に、ページごとに決まります（[ページのアクセス制限](/AccessGuide/Privileges)）

### アカウントの種類

| 種類 | 中身 |
|---|---|
| 管理者（`admin`） | Wikiごとに**1人**。すべての管理ツールを使える（[管理者権限でできること](/AdminGuide)） |
| 助手 | 管理者が管理作業を任せた人。`staff` というグループに登録され、多くの管理ツールを使える（[アカウントと助手](/AdminGuide/Accounts#助手を増やす)）。操作は記録に残る |
| ふつうのアカウント | ふつうに読み書きする人。何が読めて書けるかは、ページのアクセス制限で決まる |
| ログインしていない人 | アカウントを持たない人、またはログインしていない人。読める・書けるは、Wikiの使いかたとページのアクセス制限で決まる |

人をまとめて呼ぶための**グループ**もあります。ログインしていれば誰でも作れ、ページのアクセス制限で
「このグループの人だけ」と書くときに使います（[グループ](/AccessGuide/Groups)）。
