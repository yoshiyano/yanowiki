# plugin_debug — ページの中だけ一時的にプラグインの詳細表示を切り替える

| 使える記法 | |
|---|---|
| ブロック `#plugin_debug()` | ○ |
| インライン `&plugin_debug();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

プラグインのエラーの[詳細]は、ふだんは設定で `plugin.debug` が有効なときだけ出ます
（[エラーが出たときは](/Syntax/Plugin#エラーが出たときは)参照）。
設定を変えられない編集者でも、このプラグインを置けば、そのページの中だけ[詳細]を確かめられます。

### 書きかた

```pukiwiki
#plugin_debug(true)     以降のプラグインのエラーに [詳細] を出す
#plugin_debug(false)    以降を元の設定に戻す
```

### 引数

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| **`value`** | `true`/`false`（`yes`/`on`/`1`、`no`/`off`/`0`も可） | なし（**省略不可**） | [詳細]表示を有効にするか |

### 性質

- ページには何も表示しません
- 効くのは、これより**後ろ**に書かれたプラグインだけです
- 設定で `plugin.debug` が有効なときは、`#plugin_debug(false)` でも無効にできません
- 部分プレビューでも動きます（効くのは同じプレビューの中だけ）

仕組みは [エラーの扱い](/Tech/dev_plugin/spec/errors#ページの中だけ一時的に有効にするplugin_debug) を参照してください。
