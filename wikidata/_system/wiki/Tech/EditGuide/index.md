# 編集機能の仕組み

編集画面と、その保存についての説明です。編集画面は `.edit` という別URLを
持たず、**そのページ自身の通常URLへ `cmd=edit` をPOSTすることで開きます**
（詳しくは[POSTで受ける、cmdの一覧](#postで受けるcmdの一覧)参照）。
使いかたは [使ってみよう](/UsageGuide) の「編集する」をご覧ください。

## POSTで受ける、cmdの一覧

編集に関わる送信先は常に**そのページ自身の通常URL**で、`cmd` の値だけで
操作を区別します（[`wiki.py`のdispatch](/Tech/Reference/Routing)参照）。
GETでは常にただの閲覧画面が返り、`cmd` の有無・値がその判断材料の
すべてです——URLだけを見ても、そこに編集の入口があることは分かりません。

| `cmd` | 動き |
|---|---|
| `edit` | 編集フォームを開く（本文は送らない）。`?tab=attach` を付けると添付タブで開く |
| `save` | 送られた本文で保存する。本文を空にして送ると削除になる（[ページの削除](/Tech/EditGuide/PageFolder#ページの削除)参照） |
| `draft` | 一時保存（[一時保存](/Tech/EditGuide/Draft)参照） |
| `attach` | 添付ファイルの追加・削除・移動（[添付ファイルの管理](/Tech/EditGuide/Attach)参照） |
| `pause` | 一時中断（ESC）。いまの内容を一時保存してページ本体へ戻る |
| `discard` | 内容破棄。一時保存を消してページ本体へ戻る |
| `preview` | プレビューのHTMLを返す（本文を本体に載せて送るため、`cmd` はクエリ `?cmd=preview` で渡す。[プレビュー](/Tech/EditGuide/Screen#プレビュー)参照） |
| `diff` | 差分のHTMLを返す（同じく `?cmd=diff`。[更新状況](/Tech/EditGuide/Diff)参照） |

**編集の権限（`W`）が無いと、どの `cmd` も403で断ります。** テーマは権限が無ければ
編集の入口を出しませんが、それは見た目のことなので、サーバー側でも止めています
（[ページごとの権限](/Tech/PagePermissions)）。

旧URL `/.editwikipage/<ページパス>` は後方互換のためだけに残っており、
メソッドを問わずこの名前を除いた通常URLへ303で送り返すだけです（編集画面を
返すことはありません）。

この受け皿の名前は2026-09-06に `.edit` から `.editwikipage` へ変わりました
（Wiki設計者の指示）。**`/.edit/…` で来る古いリンクは、もう送り返しません**
（ただの無いページになります）。編集画面そのものはこのパスを使っていないので、
画面から辿るぶんには影響しません。

## まだ無いもの

- ページの凍結（**付けません**。書き込みを止めたいページは、
  [ページごとのアクセス制限](/Tech/PagePermissions)で権限を絞って行います）

認証・権限管理、差分表示・バックアップからの復元、セクション編集からの保存は
実装済みです。それぞれ [アカウントの仕組み](/Tech/Accounts)・
[変更履歴（履歴タブ）の仕組み](/Tech/BackupUI)・
[セクション編集](/Tech/SectionEditing) をご覧ください。
