# Emacs のプラグイン

[外部エディタ連動の編集](..) で、**エディタ側**にインストールする Emacs のプラグイン（wikiedit）です。
ブラウザ側の拡張機能（[Chrome](../Chrome)・[Firefox](../Firefox)）もインストールしてください。

Emacs 28 以上で動きます。ほかのパッケージは要りません。

## インストール
#attachls()

1. 上の一覧から `wikiedit.el` をダウンロードする（一覧の日時が、更新した日時です）
2. 好きなフォルダ（たとえば `~/.emacs.d/mylisp/`）に置き、`init.el` に書く

   ```elisp
   (add-to-list 'load-path "~/.emacs.d/mylisp/")
   (require 'wikiedit)
   (wikiedit-start)
   ```

3. Emacs を起動し直す

### 動いているかを確かめる

起動したときに、エコーエリアに「wikiedit: 4100 で待ち受けています」と出ます（見逃したら
`*Messages*` バッファにあります）。「ほかの Emacs が待ち受けています」と出たときは、先に
起動した Emacs が待ち受けています。

手元のプラグインがいつのものかは、ファイルの冒頭の「更新:」の行か、`M-x wikiedit-version` で
分かります。

## 使う

編集画面で「外部エディタにつなぐ」を押すと、`*wiki: ページ名*` というバッファが新しいフレームで
開きます。

#img(つないだところ（`wikiedit-display` を `window` にして、今のウィンドウに出した例）>/PageEdit/EditorSyncGuide/emacs.png)

初めての Wiki から接続したときは、「http://wiki.example.com からの接続を許しますか？」と
尋ねます（ミニバッファか、ダイアログで尋ねます）。
許可すると `~/.emacs.d/associated_wiki.el` に覚え、次からは尋ねません。
許さなかった Wiki サイトは、その Emacs を閉じるまでつながりません。
知らないサイトのページから手元のエディタを読み書きされないようにするためです。
`localhost` と `127.0.0.1` の Wiki は尋ねずにつなぎます。
なお、覚えた Wiki の許可を取り消すときは、`associated_wiki.el` からそのアドレスを消します。

#img(初めての Wiki から接続したとき>/PageEdit/EditorSyncGuide/emacs-ask.png)

| キー | |
|---|---|
| `C-x C-s` | 編集画面の保存を押す（変更が無ければ編集を終える。詳しくは [エディタから保存したとき](/PageEdit/EditorSyncGuide#エディタから保存したとき)） |
| `C-c C-c` | バッファを閉じる（編集画面には「エディタ側で閉じました」と出る） |
| `C-c C-a` | ``添付ファイル``をミニバッファで選び、本文での書きかた（`[[::a.zip]]` など）を挿入する |
| `C-u C-c C-a` | ``添付ファイル``の書きかたを、挿入せずに kill-ring にコピーする |

モード行の `Wiki` のあとに、ページの添付ファイルの数が出ます（例: `Wiki 添付3`。無ければ `添付0`）。
マウスを重ねると、ファイル名の一覧が出ます。

`M-x wikiedit-stop` で待ち受けをやめ、同期しているバッファを閉じます。`M-x wikiedit-start` で
始め直します。

Emacs を同じパソコンで複数動かしているときは、最初に起動した Emacs が待ち受けます。ほかの
Emacs は5秒ごとに確かめ、待ち受けていた Emacs を閉じると、残っている Emacs のどれかが
引き継ぎます（編集画面はそのあいだ「エディタを待っています」になり、引き継ぐとつながります）。

### 編集画面との通信が切れたとき

通信が切れても、Emacs での編集はそのまま続けられます。モード行の表示が変わります。

| モード行 | 状態 |
|---|---|
| `Wiki` | つながっている |
| `Wiki:応答なし` | つながっているが、編集画面から 45 秒応答がない。変更は送らずにため、応答が戻ったら送る |
| `Wiki:再読み込み中` | 保存などで、編集画面が再読み込みしている。すぐ戻る（10 秒たっても戻らなければ `Wiki:切断` になる） |
| `Wiki:切断` | 通信が切れている。同じタブの編集画面がつなぎ直したら送る |

まだ送っていない変更があるときは `(未送信)` が付きます（例: `Wiki:切断(未送信) 添付3`）。
送っていない変更があるあいだは、バッファを閉じずに残します。

つなぎ直したときは、最後にそろえた本文を基準に、次のように合わせます。

| 切れているあいだに変わったもの | 合わせかた |
|---|---|
| Emacs だけ | Emacs の変更を編集画面に送る |
| 編集画面だけ | 編集画面の本文に合わせる |
| 両方 | 最後に変えたほうに合わせる。合わせなかったほうの本文は消さずに残す（Emacs は「控え」のバッファ、編集画面はブラウザの中） |

## 設定

`init.el` の `(require 'wikiedit)` のあと、`(wikiedit-start)` の前に `setq` で書きます。

| 変数 | 既定 | |
|---|---|---|
| `wikiedit-port` | 4100 | 待ち受けるポート番号。編集画面の「設定」とそろえる |
| `wikiedit-associated-file` | `~/.emacs.d/associated_wiki.el` | 許した Wiki のアドレスを覚えておくファイル |
| `wikiedit-allow-extensions` | `t` | ブラウザ拡張機能を通した接続も受け付けるか（受け付けるときも、Wiki のアドレスで許すかを決める） |
| `wikiedit-display` | `frame` | バッファの表示方法（`frame` 新しいフレーム・`window` 今のウィンドウ・`none` 出さない） |
| `wikiedit-mode-alist` | Markdown は `markdown-mode` | 書きかたごとのモード。無いモードなら `text-mode` |
| `wikiedit-takeover-interval` | 5 | ほかの Emacs が待ち受けているとき、いなくなったかを確かめる間隔（秒） |
| `wikiedit-keep-seconds` | 10 | 保存などで編集画面が再読み込みされるあいだ、バッファを保つ秒数（タブを閉じたときは待たずに閉じる） |
| `wikiedit-stale-seconds` | 45 | 編集画面から何も届かないまま、この秒数がたったら「応答なし」とみなす |

## 新しいバージョンにするとき

新しい `wikiedit.el` で置き換え、Emacs を起動し直します。
