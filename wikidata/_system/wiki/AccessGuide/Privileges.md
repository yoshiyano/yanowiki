# ページのアクセス制限

どのページを、だれが読めて、だれが書けるかを決めます。管理者と助手が、管理者メニューの「アクセス制限」で行います。

#img(アクセス制限の画面>/Tech/PagePermissions/Privileges/privileges.png)

## 決めかた

1行が1ページです。列は「ページ名・閲覧の許可者（R）・編集の許可者（W）・更新日・操作」です。

| 書くもの | 意味 |
|---|---|
| ページ名 | `Tech/Secret` のように、フォルダも含めて書く。`Tech/*` のように末尾か先頭に `*` を付けると、その配下（孫も）や同じ名前の並びにまとめて効く。`Tech/*` は入口の `Tech` 自身にも効く |
| 閲覧（R）の許可者 | 読める人 |
| 編集（W）の許可者 | 書ける人 |
| 許可者 | ログインID、`g:グループ名`（グループのメンバー全員）、`admin`（管理者）、`g:all`（ログインした人全員）、`g:any`（だれでも。未ログインを含む） |

- **R・Wのどちらも、書いていない側はだれにでも許します**。ただし**書けるのは読める人だけ**です
  （Rの許可者に載っていない人は、Wに載っていても読めないので書けません）
- ページ名を `*` だけにした行が、**既定の行**です。ほかの行が当たらないページに効きます
  （例: `*` の R を `g:any`、W を `g:all` にすると、「読むのはだれでも、書くのはログインした人」）
- **ログインを求めるだけでは、書ける人は絞れません。** だれでもアカウントを作れる設定なら、1つ作れば書けるためです。
  絞りたいときは、アカウントを承認制にします（[アカウントと助手](/AdminGuide/Accounts#承認制のとき)）

| 使いかた（新しいWikiを作る画面の選択肢） | 既定の行 |
|---|---|
| 自由に書き換える | 行なし（だれでも読み書き） |
| ログインした人が編集・外部に公開（承認制） | R `g:any`、W `g:all` |
| メンバー限定（承認制） | R `g:all`、W `admin, g:staff` |

Wikiを作るとき、使いかたを選ぶとこれらの行が最初から入ります（[Wikiの新規作成](/AdminGuide/NewWiki#使いかた)の表の4つ）。

## 権限が無いとき

- **読めないページ**は、開くと「閲覧する権限がありません」と出ます。検索結果・`#recent`・[ファイル一覧](/FilesGuide)・添付ファイルにも出ません
- **書けないページ**は、「編集」「新規」のボタンが出ません。編集画面・プレビュー・添付・履歴・セクション編集・競合の統合も使えません。ログインすると書けるようになるWikiもあります（[アカウント作成とログイン](/AccessGuide/Login)）
- `#comment`・`#vote` は、読める人なら、書けなくても使えます。`#tasklist` のチェックは、書ける人だけです

#note(type=warn){{
**アクセス権は、見せたくないものを隠すための仕組みです。秘密を守る仕組みではありません。**
本当に読ませたくないものは、置かないか、前段のWebサーバーなどで止めてください。
}}

## 画面の使いかた

- **足す**: いちばん上の入力欄に、ページ名と許可者を入れます。同じページ名がすでにあれば、許可者が**足し合わされます**（何を足したかは通知に出ます）
- **直す**: 行の鉛筆を押し、許可者を書き換えてチェック（確定）を押します。確定は、**入力したとおりに置き換えます**（許可者を外せます）。Enterで確定、Escでやめる。ページ名は直せないので、付け替えるときは新しい名前で足してから古い行を削除します
- **消す**: 「削除」を押し、確認で消える許可者を確かめます
- 片側（RかW）を空にして確定すると、その種類の行が無くなります。両方を空にする確定はできません
- 列の見出しで並べ替えます。ほかの人が先に書き換えていたら、断って最新の一覧を出します

ページの名前を変えたり移したりすると（[ファイル一覧](/FilesGuide)）、行も新しい名前へ付け替わります。

## ページの中に書く方法

ページ本文に `#readauth(…)`・`#writeauth(…)` と書いても、同じ制限をかけられます
（[readauth](/Syntax/Plugin/readauth)・[writeauth](/Syntax/Plugin/writeauth)）。
こちらは画面の一覧には出ません。

仕組みと評価の細かい決まりは [ページごとの権限](/Tech/PagePermissions) にあります。

### 消したあとの記録の後始末

`#readauth`・`#writeauth` を消したあとに、記録が残っていることがあります。1時間以内に自動で消えますが、
すぐ消したいときは、アドレス欄に `/.updatePageAuth` と入力して開きます（だれでも開けますが、1時間に10回までです）。
