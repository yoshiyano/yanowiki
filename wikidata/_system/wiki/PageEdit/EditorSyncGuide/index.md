# 外部エディタ連動の編集

編集画面の本文を、手元のエディタ（VS Code・Emacs・Neovim）で書けます。エディタで打った内容は
すぐ編集画面のプレビューに出て、エディタから保存もできます。

#img(左が Wiki の編集画面、右がエディタ（Emacs）。同じ本文を、エディタで書いてプレビューで見る>/PageEdit/EditorSyncGuide/overview.png)

仕組みは [外部エディタ連動](/Tech/EditorSync)（技術資料）をご覧ください。

## 用意するもの

**エディタ側とブラウザ側に、1つずつインストールします。**

| | インストールするもの | インストール方法 |
|---|---|---|
| ① エディタ側 | エディタのプラグイン（使うエディタのものを1つ） | [VS Code](./VSCode)・[Emacs](./Emacs)・[Neovim](./Neovim) |
| ② ブラウザ側 | ブラウザ拡張機能 wikiedit（使うブラウザのものを1つ） | [Chrome](./Chrome)・[Firefox](./Firefox) |

② は、編集画面と手元のエディタのあいだの通信を中継します（[ブラウザ拡張機能](./BrowserExt)）。
インターネットに公開した Wiki を http で開くと、ブラウザがページから手元のエディタへの通信を
断るので、② が要ります。社内などの LAN にある Wiki では、② が無くてもつながります。

配布するファイルは、それぞれのページの「インストール」の一覧にあります。一覧の日時が、そのファイルを
更新した日時（バージョンの目安）です。

## つなぐ

1. エディタを起動して、プラグインを動かしておく（インストール方法は各エディタのページ）
2. 編集画面の下の「**外部エディタにつなぐ**」を押す

#img(編集画面の下の「外部エディタにつなぐ」>/PageEdit/EditorSyncGuide/link-button.png)

3. エディタに、そのページの本文が開く。編集画面には「エディタとつながっています」と、
   エディタの名前とプラグインのバージョンが出る

#img(つながったところ>/PageEdit/EditorSyncGuide/link-connected.png)

エディタが起動していないときは「エディタを待っています」と出ます。そのままエディタを起動すると、
自動でつながります。

#img(エディタを待っているところ>/PageEdit/EditorSyncGuide/link-waiting.png)

初めての Wiki からつないだときは、エディタが「（Wiki のアドレス）からの接続を許しますか？」と
尋ねます。許すとエディタが覚え、次からは尋ねません。知らないサイトのページから、手元のエディタを
読み書きされないようにするためです（`localhost`・`127.0.0.1` の Wiki は尋ねません）。

一度つなぐと、ブラウザが覚えます。次からは編集画面を開くたびに自動でつなぎます。

## つないでいるあいだ

つないでいるあいだは、編集画面の本文の欄とツールバーを隠し、プレビューを広く出します。

#img(つないでいるあいだの編集画面>/PageEdit/EditorSyncGuide/edit-connected.png)

- エディタで打った内容は、すぐプレビューに出ます。プレビューは、エディタのカーソルのある行に
  ついてきます
- 保存は、エディタからでも（キーは各エディタのページ。下の「エディタから保存したとき」）、編集画面の「保存」でもできます
- 保存しても、同じタブでページを替えても、エディタは同じバッファ（VS Code ではドキュメント）のまま使えます
- 別のタブで開いた編集画面は、エディタでも別のバッファ（VS Code ではドキュメント）になります
- ページの添付ファイルを選んで、本文での書きかた（`[[::a.zip]]` など）をエディタから挿入できます
- 書きかたを変えるときは「切断」してから選びます（つないでいるあいだは、書きかたの選択も隠れます）

両方で同時に書いて本文が食い違ったときは、**最後に書いたほう**にそろえます。もう片方の本文は
消さずにバックアップします（エディタは「控え」という名前のバッファ、編集画面はブラウザ内）。

### エディタから保存したとき

エディタから保存すると、編集画面の状態によって次のようになります。

| 編集画面 | 起きること |
|---|---|
| 変更が無い（「保存」が押せない） | 編集を終えます（「一時中断」と同じく、ページの表示に戻ります）。エディタのバッファも閉じます |
| 変更があり、「連続編集」がオン | 保存して、編集を続けます。エディタは同じバッファのまま使えます |
| 変更があり、「連続編集」がオフ | 保存して、編集を終えます（ページの表示に戻ります）。エディタのバッファも閉じます |

書き終えたら、エディタから保存を2回押すと、保存してから編集を終えられます（連続編集がオンのとき）。

## やめる・閉じる

| すること | 起きること |
|---|---|
| 編集画面の「切断」を押す | エディタのバッファも閉じる。次からは自動でつながない |
| エディタでバッファ（VS Code ではドキュメント）を閉じる | 編集画面に「エディタ側で閉じました」と出る。「もう一度つなぐ」でつなぎ直せる |
| 編集画面のタブを閉じる・リンクでほかのページへ移る | エディタのバッファも閉じる |
| 「一時中断」を押す・連続編集がオフで保存する（通常表示に戻る） | エディタのバッファも閉じる |

#img(エディタ側で閉じたところ>/PageEdit/EditorSyncGuide/link-closed.png)

## セクション編集でつなぐ

[セクション編集](/UsageGuide/Edit/SectionEdit)（本文を Ctrl+Alt+ダブルクリック）でも、エディタとつなげます。
「保存」「閉じる」の右にある「外部エディタにつなぐ」を押します。

- つないでいるあいだは、入力欄を隠してプレビューだけを出します
- エディタには、編集画面とは別のバッファ（VS Code ではドキュメント）で開きます。名前は「ページ名#見出し」です
- 一度つなぐと、次からはセクション編集を開くたびに自動でつながります（編集画面と同じで、オン・オフはブラウザで1つです）
- エディタから保存すると、「保存」を押したのと同じです。変更があれば保存してページを読み直し、無ければ閉じます
- 「閉じる」を押したとき・保存してページを読み直したときは、エディタのバッファも閉じます

## 設定

「外部エディタにつなぐ」の横の「設定」で、エディタのポート番号を変えられます（既定は 4100）。
エディタのプラグインの設定のポート番号とそろえてください。

#img(設定を開いたところ>/PageEdit/EditorSyncGuide/link-settings.png)

## うまくつながらないとき

| 様子 | 確かめること |
|---|---|
| 「エディタを待っています」のまま | エディタでプラグインが動いているか（各エディタのページの「動いているかを確かめる」）。ポート番号がエディタとそろっているか |
| 公開している Wiki で「エディタを待っています」のまま | ブラウザ拡張機能をインストールし、その Wiki のサイトを許したか（[Chrome](./Chrome)・[Firefox](./Firefox)） |
| エディタが尋ねたときに断ってしまった | エディタを起動し直してからつなぐと、もう一度尋ねます |
