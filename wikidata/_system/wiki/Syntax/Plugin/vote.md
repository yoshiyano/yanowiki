# vote — 簡易投票（アンケート）フォームを置く

| 使える記法 | |
|---|---|
| ブロック `#vote()` | ○ |
| インライン `&vote();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

選択肢ごとに投票ボタンと、票数・割合の棒グラフを並べます。
票数は、このページの本文の `#vote(...)` に直接書き戻されます（本家PukiWikiと同じ仕組み）。

### 書きかた

```pukiwiki
#vote(カレー,ラーメン,寿司)
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `candidates` | 選択肢を `,` 区切りで並べたもの | なし（**2つ以上必要**） | 投票の選択肢 |

選択肢は2つ以上ならいくつでも書けます。選択肢名に `,` は含められません。

### 表示例

3人がカレーに、1人がラーメンに投票すると、本文はこう書き換わります。

```pukiwiki
#vote(カレー[3],ラーメン[1],寿司[0])
```

![clip001.png](clip001.png)

棒グラフの幅は、その `#vote()` の総得票数に対する割合です。

### 選択肢名の末尾に`[数字]`を置かない

票数は `名前[票数]` の形で書かれるので、`#vote(第1[2],第2)` は「第1」に2票入っている意味になります。
逆に、この形を手で書けば票数を直接直せます。

### 性質

- 1つのページに複数置くと、それぞれ別に集計します
- 投票のたびにページのいまの内容を読み直して1票足すので、同時に投票しても正しく数えます。ページのほかの場所の編集との衝突は検出しません
- 重複投票は防ぎません（本家と同じ）
- そのページを閲覧できる人なら、ログインしていなくても、編集の権限が無くても投票できます（[ページごとの権限](/Tech/PagePermissions)）。投票できる人を絞るには、閲覧できる人を絞ります（[readauth](/Syntax/Plugin/readauth) など）
- 選択肢が1つ以下だとエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）
