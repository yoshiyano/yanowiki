# 新しいWikiを作る

1つのサーバーでいくつものWikiを動かせます（Wiki Farm）。話題や用途ごとにWikiを分けるときに使います。
Wikiごとに、ページ・見た目（テーマ）・メニューを別々に持てます。

## 別のWikiへ移動する

名前の前に `=` を付けてアクセスします。

```
/=team/           team という名前のWikiのトップページ
/=team/UsageGuide team という名前のWikiの UsageGuide ページ
```

**どんなWikiがあるかは [Wikiの一覧](/.allwiki) で見られます**（名前・トップページの見出し・ページ数）。

- 開けるのは**既定のWikiの管理者と助手だけ**です
- `/=<Wiki名>/.allwiki` の形では開けません
- 一覧を出さない設定にしているサイトもあります

## 新しいWikiを作る

**[新しいWikiを作る画面](/.newwiki) で次の項目を入れて「作る」を押します。**
使えるのは**既定のWikiの管理者と助手だけ**です。

#img(新しいWikiを作る画面>newwiki.png)

| 項目 | 入れるもの |
|---|---|
| 名前 | URL（`/=名前/`）になる名前。**半角英数字と `-` `_`**（先頭は英数字、64文字まで）。すでにある名前は使えません |
| トップページの見出し | 省略すると名前になります |
| 管理者のパスワード | そのWikiの管理者（`admin`）のパスワード。**空にはできません**。あとから変えられます |
| 使いかた | 誰が読めて誰が書けるか（下の表） |
| Wiki設定を独立させる | 初めはチェックが入っています（下記） |
| 既定のWikiにする | `/` を開いたときに出るWikiにするか（下記） |

作ると、トップページとメニューが用意されてトップページが開きます。どちらもふつうのページです。

### 使いかた

あとから、アクセス制限の画面（`/.admin/privileges`）と設定画面の「アカウント」タブで
変えられます。迷ったらいちばん上のままで構いません。

| 選ぶもの | 読める人 | 書ける人 | アカウントの作成 |
|---|---|---|---|
| 自分だけ、またはLAN内で自由に（**初期値**） | 誰でも | 誰でも（ログイン不要） | 誰でも |
| LAN内で、ログインした人だけが編集 | 誰でも | ログインした人 | 誰でも自由に |
| 外部に公開（承認制） | 誰でも | ログインした人 | 誰でも申請でき、助手・管理者が**承認するまで使えない** |
| 閲覧にもログインが要る（承認制） | ログインした人 | **管理者と助手だけ** | 誰でも申請でき、助手・管理者が承認するまで使えない |

### Wiki設定を独立させる

チェックを入れて作ると、共通の設定（`config/default.example.yaml`）を写した専用の設定ファイル
（`wikidata/<名前>/config/default.yaml`）が用意され、サイト名や見た目をそのWikiだけ変えられます
（[見た目を変えよう](/ThemeGuide)）。

写した値は作った時点のままなので、あとで共通の設定を直してもそのWikiには届きません。
共通の設定に合わせ続けたいときは、チェックを外して作ります（あとから設定ファイルを作れば独立させられます）。

### 既定のWikiにする

チェックを入れて作ると、`/` を開いたときに出るWikiが新しいWikiに切り替わります。
初期値は、まだ自分のWiki（`_system` 以外）が無ければチェックあり、あれば無しです。

**既定のWikiを切り替えると、Wikiの作成・削除・一覧と再起動ができる人も、新しいWikiの管理者と助手に移ります**
（[既定のWikiの役割](/Tech/DesignPolicy/Farm#デフォルトのwikiの役割)）。
