# tasklist — チェックリスト（`- [ ]`/`- [x]`）にチェックボックスを付ける

| 使える記法 | |
|---|---|
| ブロック `#tasklist(sync)` | ○（書き戻しを有効にするためだけの呼びかた） |
| インライン `&tasklist();` | — |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

Markdownのページで、`- [ ]`/`- [x]` の箇条書きをチェックリストとして表示します。表示だけならプラグインの呼び出しは要りません。
チェックを押した結果を本文へ書き戻す機能だけを、`#tasklist(sync)` で有効にします。
PukiWiki記法（`.txt`）のページでは使えません。

### 書きかた

```markdown
- [x] 終わったこと
- [ ] これからやること
```

- [x] 終わったこと
- [ ] これからやること

`x` は半角（大文字の `X` も可）、`[ ]` の間は半角スペース1つ、`]` のあとにも半角スペースが要ります。
条件に合わない行は、エラーにはならず、ただの箇条書きになります。

### 押せるようにする（`sync`）

`#tasklist(sync)` が無いページでは、チェックボックスの代わりに状態の絵文字（⬜・✅）が出て、押せません。
押して保存したいページでは、どこか1か所に書きます。位置に関わらず、ページ全体に効きます。自身は何も表示しません。

```markdown
#tasklist(sync)

- [ ] やること
- [x] やったこと
```

`sync` のページで押すと、その場でON/OFFが切り替わり、本文の `- [ ]`/`- [x]` も書き換わります。
保存に失敗したら（通信が切れた・その間に内容が変わっていた等）、元の状態へ戻り、その項目が一瞬赤く縁取られます。

### 性質

- そのページの編集の権限がある人のみチェックボックスを切り替えられます（[ページごとの権限](/Tech/PagePermissions)）
- チェックボックスはJavaScriptが組み立てます。無効な環境では、チェックボックスの無い箇条書きとして読めます
- 出力は `<li class="task-list-item" data-page=… data-line=… data-checked=…>` で、`sync` のページでは `data-api="/.plugin/tasklist"` が付きます
- `#tasklist(sync5)` のように `sync` 以外を書くとエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）
