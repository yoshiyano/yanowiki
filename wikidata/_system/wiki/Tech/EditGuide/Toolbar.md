# ツールバーと書きかた

使いかたは [編集する](/UsageGuide/Edit/Page#ツールバーと書きかた) にあります。このページは仕組みの説明です。

ツールバーの書式の定義と、ページの書きかたの選びかたです。

## 書式は差し替えられる

ツールバーの中身は、サーバー側の `MARKUP_FORMATS` という定義だけで決まります。
**書きかたそのもの（太字が `**` なのか `''` なのか等）はJavaScriptに書かれていません。**

```python
MARKUP_FORMATS = {
    "markdown": {
        "label": "Markdown",
        "ext": ".md",
        "actions": [
            {"name": "bold", "label": "太字", "icon": "B", "wrap": ["**", "**"], "sample": "太字"},
            {"name": "heading", "label": "見出し", "icon": "H", "prefix": "## ", "line": True},
            ...
        ],
    },
}
```

アクションは次のいずれか1つの方法を指定します。

| 指定 | 動き |
|---|---|
| `wrap` | 選択範囲の前後を囲む `[開始, 終了]` |
| `prefix` | 選択した各行の先頭に付ける（もう一度押すと外れる） |
| `block` | 選択範囲を独立した行として前後で囲む |
| `template` | 定型文を挿入する（`${text}` が選択文字列に置き換わる） |

`sample` は、何も選択せずに押したときに入る文字です。

**書きかたを足すときは、ここに同じ形の定義を足すだけ**で、同じツールバーがその書きかた用として
働きます（PukiWiki記法もこの形で足しました）。`_sys/editor/editor.js` は変更不要です。

### 書きかたの選択

編集画面のツールバーの右端に、書きかたを選ぶラジオボタンがあります。選べるのは
`MARKUP_FORMATS` のうち**拡張子を持つもの**です（`selectable_markups()`）。

- 初期値は、開いたページの拡張子から決まります（まだ無いページは `DEFAULT_MARKUP`）。
- ブラウザ側は、渡された全書式の定義（`<script class="edit-formats">`）から
  ツールバーを組み直します。**書きかたそのものはJavaScriptに書かれていません。**
- プレビューは `?markup=…` を付けて送ります。**保存前に切り替えた書きかたで
  確かめられる**ようにするためで、ここが保存済みの拡張子に固定だと、
  書きかたを移す作業の途中でプレビューだけ古い書きかたのままになります。
- 保存時、選ばれた書きかたの拡張子が元と違えば、新しい拡張子で書いたあと
  **前のファイルを消します**。残すと同じページが2つある状態になり、
  どちらが開かれるかは `PAGE_EXTS` の順（`.txt` が先）で決まってしまいます。
- **本文は変換しません。** 書きかたを移すのは書き直す作業で、機械が変換すると
  元のとおりには戻せなくなるためです。

ページの置き場所（フォルダの階層・`index`・日本語のファイル名）は書きかたによらず同じで、
変わるのは拡張子だけです。
