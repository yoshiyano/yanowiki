# VS Code の拡張機能

[外部エディタ連動の編集](..) で、**エディタ側**にインストールする VS Code の拡張機能（wikiedit）です。
ブラウザ側の拡張機能（[Chrome](../Chrome)・[Firefox](../Firefox)）もインストールしてください。

VS Code 1.82 以上で動きます。ほかの拡張機能は要りません。

## インストール
#attachls()

1. 上の一覧から `wikiedit.vsix` をダウンロードする（一覧の日時が、更新した日時です）
2. 端末でインストールする

   ```sh
   code --install-extension wikiedit.vsix
   ```

   VS Code の画面からは、拡張機能のビュー（`Ctrl+Shift+X`）の上の「…」→
   「VSIX からのインストール...」で選んでもインストールできます。
3. 拡張機能のビューの「Installed」に wikiedit が出ればインストールされています

#img(拡張機能のビューに wikiedit が出たところ。右下のステータスバーの「Wiki」は、待ち受けていることを示すアイコン>/PageEdit/EditorSyncGuide/vscode-installed.png)

インストールすると、VS Code を起動するたびに待ち受けを始めます。

### 動いているかを確かめる

右下のステータスバーに「Wiki」（プラグのアイコン）が出ていれば、待ち受けています。押すと、拡張機能の
更新日時と待ち受けているポート番号が出ます（コマンドパレットの「wikiedit: バージョンを表示」でも同じ）。
アイコンが線の切れたプラグのときは、ほかの VS Code のウィンドウが待ち受けています。

## 使う

編集画面で「外部エディタにつなぐ」を押すと、ページが `ページ名.md`（PukiWiki 記法のページは
`ページ名.txt`）というドキュメントのタブで開きます。

#img(つないだところ。Wiki のページがタブで開く>/PageEdit/EditorSyncGuide/vscode.png)

初めての Wiki から接続したときは、接続を許すかを尋ねます。「許す」を押すと設定の
`wikiedit.allowedOrigins` に覚え、次からは尋ねません。許さなかった Wiki は、その VS Code のウィンドウを
閉じるまでつながりません。許可を取り消すときは、設定の `wikiedit.allowedOrigins` からその
アドレスを消します。

#img(初めての Wiki から接続したとき>/PageEdit/EditorSyncGuide/vscode-ask.png)

| 操作 | |
|---|---|
| `Ctrl+S`（保存） | 編集画面の保存を押す（変更が無ければ編集を終える。詳しくは [エディタから保存したとき](/PageEdit/EditorSyncGuide#エディタから保存したとき)） |
| タブを閉じる | 編集画面には「エディタ側で閉じました」と出る |
| タブの右上のボタン・右クリックの「添付ファイルの書きかたを挿入」 | ページの添付ファイルを一覧から選び、本文での書きかた（`[[::a.zip]]` など）を挿入する |
| 右クリックの「添付ファイルの書きかたをコピー」 | 選んだ添付ファイルの書きかたを、挿入せずにクリップボードにコピーする |

Wiki のドキュメントを開いているあいだ、ステータスバーにページの添付ファイルの数が出ます（例: `添付 3`。
無ければ `添付 0`）。マウスを重ねるとファイル名の一覧が出て、押すと挿入する添付ファイルを選べます。

コマンドパレット（`Ctrl+Shift+P`）の「wikiedit: 待ち受けをやめる」で待ち受けをやめ、Wiki の
ドキュメントを閉じます。「wikiedit: 待ち受けを始める」で始め直します。

本文は打つたびに編集画面へ送るので、タブに未保存のマーク（●）は残りません。ただし、
保存のときに本文を変える設定（`editor.formatOnSave`・`files.insertFinalNewline` など）を
有効にしていると、マークが残ります（勝手に保存すると本文が変わるため）。閉じるときに保存を
尋ねられても、本文はもう編集画面に届いています。

VS Code のウィンドウを複数開いているときは、最初に開いたウィンドウが待ち受けます。ほかのウィンドウは
5秒ごとに確かめ、待ち受けていたウィンドウを閉じると、残っているウィンドウのどれかが引き継ぎます。

### 編集画面との通信が切れたとき

通信が切れても、VS Code での編集はそのまま続けられます。Wiki のドキュメントを開いているあいだ、ステータスバーに状態が出ます。

| ステータスバー | 状態 |
|---|---|
| （出ない） | つながっている |
| `Wiki 再読み込み中` | 保存などで、編集画面が再読み込みしている。すぐ戻る（10 秒たっても戻らなければ「切断」になる） |
| `Wiki 応答なし`（黄色） | つながっているが、編集画面から 45 秒応答がない。変更は送らずにため、応答が戻ったら送る |
| `Wiki 切断`（赤） | 通信が切れている。同じタブの編集画面がつなぎ直したら送る |

まだ送っていない変更があるときは `（未送信）` が付きます。
送っていない変更があるあいだは、閉じずに残します。

つなぎ直したときは、最後にそろえた本文を基準に、次のように合わせます。

| 切れているあいだに変わったもの | 合わせかた |
|---|---|
| VS Code だけ | VS Code の変更を編集画面に送る |
| 編集画面だけ | 編集画面の本文に合わせる |
| 両方 | 最後に変えたほうに合わせる。合わせなかったほうの本文は消さずに残す（VS Code は「控え」、編集画面はブラウザの中） |

## 設定

VS Code の設定（`Ctrl+,`）で「wikiedit」を探すと出ます。

| 設定 | 既定 | |
|---|---|---|
| `wikiedit.port` | 4100 | 待ち受けるポート番号。編集画面の「設定」とそろえる |
| `wikiedit.allowedOrigins` | なし | 許した Wiki のアドレス。ユーザーの設定にだけ書ける（開いたフォルダの設定では変えられない） |
| `wikiedit.allowExtensions` | オン | ブラウザ拡張機能を通した接続も受け付けるか（受け付けるときも、Wiki のアドレスで許すかを決める） |
| `wikiedit.autoStart` | オン | VS Code を起動したら待ち受けを始める |
| `wikiedit.display` | `focus` | ドキュメントの表示方法（`focus` 開いて移る・`background` 開くが今の場所から移らない・`none` 開かない） |
| `wikiedit.languages` | なし | 書きかたごとの言語（例: `{"pukiwiki": "pukiwiki"}`）。書かない書きかたは、拡張子（`.md`・`.txt`）で決まる |
| `wikiedit.takeoverInterval` | 5 | ほかのウィンドウが待ち受けているとき、いなくなったかを確かめる間隔（秒） |
| `wikiedit.keepSeconds` | 10 | 保存などで編集画面が再読み込みされるあいだ、ドキュメントを保つ秒数（タブを閉じたときは待たずに閉じる） |
| `wikiedit.staleSeconds` | 45 | 編集画面から何も届かないまま、この秒数がたったら「応答なし」とみなす |

## 新しいバージョンにするとき

新しい `wikiedit.vsix` を、同じようにインストールします（上書きされます）。そのあと、VS Code を起動し直すか、
コマンドパレットの「Developer: Reload Window」でウィンドウを再読み込みします。

## 中身（直す人向け）

| ファイル | |
|---|---|
| `wikiedit.vsix` | 配布物。下の2つからビルドする |
| `package.json` | マニフェスト（名前・コマンド・設定の項目）。直したら `version` を上げる |
| `extension.js` | 本体。冒頭の「更新:」が更新日時 |
| `build_vsix.py` | 2つから `wikiedit.vsix` をビルドする |
