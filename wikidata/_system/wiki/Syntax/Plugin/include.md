# include — 別のページの本文をこのページに差し込む

| 使える記法 | |
|---|---|
| ブロック `#include()` | ○ |
| インライン `&include();` | — |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

指定したページの本文を、ここに差し込みます。案内文やFAQなどの共通部分を1ページにまとめ、複数のページから差し込む使いかたに向きます。

### 書きかた

```pukiwiki
#include(About)
#include(About, notitle)
#include(../Overview)
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| **page** | ページ名 | （必須。1番目） | 差し込むページ（`page=About` とも書ける） |
| `title` | `title` / `notitle` | `title` | 見出しの有無（ほかの値は `title` として扱う） |

ページ名の指しかた（`[[ページ名]]` と角括弧で囲んでも読めます）:

| 書きかた | 意味 |
|---|---|
| `/Tech/Overview` または `Tech/Overview` | Wikiの先頭から（`/` が無くても隣ではなく先頭から。本家PukiWikiと同じ） |
| `./Overview` | いまのページの下 |
| `../Overview` | 1つ上から |

`title` では、差し込んだ内容の前にページ名の見出し（`<h1 class="include-title">`）を付けます。
見出しを押すとそのページの編集画面が開きます（そのページを編集できない閲覧者には、ふつうのリンク）。
差し込んだページ自身の1行目の見出しは、ふつうの表示と同じく取り除かれます（[タイトルの扱い](/Tech/dev_plugin/spec/title)）。

### 差し込まれる内容

- そのページを直接開いたときと同じ処理で作られます。中の相対パス（添付ファイル名だけの指定など）は、差し込まれたページを基準に解決されます
- 中で使われているプラグインのCSS/JSも読み込まれます
- 中に `#include` があれば、それも辿ります
- 差し込み先が [viewable_period](/Syntax/Plugin/viewable_period) などで本文を止めていれば、そのページ自身が書いた期間外の案内文が入ります（`title` の見出しは出ます）
- 差し込んだページの見出しは、こちらの目次（`#contents`）に入りません
- 差し込んだ内容は、こちらのページとしては検索に当たりません
- [セクション編集](/Tech/SectionEditing)の部分プレビューでは処理されません

### 差し込めなかったとき

引数は正しいのに差し込めなかったときは、エラー（赤い枠）ではなく、その場所に案内文（`<div class="include-notice">`）が入ります（本家PukiWikiと同じ）。

| 状況 | 案内文 |
|---|---|
| 閲覧する権限が無い（[ページごとの権限](/Tech/PagePermissions)） | 「このページを閲覧する権限がありません: ページ名」（見出しも付かない） |
| ページが存在しない | 「このページはまだありません: ページ名」 |
| 同じページ（自分自身を含む）をもう一度差し込もうとした | 「既に差し込み済みのページです: ページ名」 |
| 1ページで差し込める上限（入れ子も含めて12）を超えた | 「差し込めるページ数の上限（12件）を超えました: ページ名」 |

赤い枠のエラーになるのは、`#include()` のように `page` を省略したときだけです（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
