文の中にコードを書くプラグインです。Markdown記法の `コード` と同じ表示で、PukiWiki記法のページで使います。

|~使える書きかた||h
|ブロック #icd()|×|
|インライン &amp;icd{};|○|

呼びかたのルールは [[共通の書きかた>/Syntax/Common#プラグインの呼びかた]] をご覧ください。

#contents

* 書きかた

#code(pukiwiki){{
&icd{コード};
}}

引数はありません。

#code(pukiwiki){{
設定は &icd{config/server.yaml}; にあります。
}}

↓ こう表示されます

設定は &icd{config/server.yaml}; にあります。

* 中身の扱い

中身の書きかたやプラグインは展開しません。< や & もそのまま文字として表示します。

#code(pukiwiki){{
&icd{''強調'' <b>タグ</b> &br; &amp;};
}}

↓ こう表示されます

&icd{''強調'' <b>タグ</b> &br; &amp;};

対になっている波括弧と、表のセルの中の縦棒は、そのまま書けます。

#code(pukiwiki){{
&icd{f() { g(); }};

|&icd{a|b};|c|
}}

↓ こう表示されます

&icd{f() { g(); }};

|&icd{a|b};|c|

* エスケープ

周りの書きかたに読まれる文字は、前に \ を付けます。

|~書きたいもの|~書きかた|~場面|h
|&icd{\{}; &icd{\}};|&icd{\\\{}; &icd{\\\}};|波括弧が対になっていないとき|
|&icd{''};|&icd{\\\'\\\'};|強調の中|
|&icd{%%};|&icd{\\\%\\\%};|打ち消しの中|
|&icd{|};|&icd{\\\|}; または &icd{|};|表のセルの中|
|\ で終わるもの|&icd{C:\\\\};|中身の末尾|

#code(pukiwiki){{
&icd{\{};
''&icd{a\'\'b};''
&icd{C:\\};
}}

↓ こう表示されます

&icd{\{};~
''&icd{a\'\'b};''~
&icd{C:\\};

ほかの \ はそのまま表示します。&icd{C:\Users}; や &icd{\d+}; は、そのまま書けます。

エスケープの形そのものを見せたいときは、\ を重ねます（&icd{\\\\|}; で &icd{\\|}; と表示されます）。

* Markdown記法のページでは

Markdown記法のページでは、ふつうに `コード` と書いてください。プラグインとして呼ぶなら丸括弧つきの &icd{&amp;icd(){a};}; です（丸括弧のない形は文字のまま表示されます）。

* エラーについて

中身を省いたとき、引数を書いたときはエラーになります。

#code(pukiwiki){{
&icd();
&icd(x){コード};
}}

↓ こう表示されます

&icd();

&icd(x){コード};
