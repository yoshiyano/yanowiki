# Markdown記法：コメントとHTML

表示されないコメントと、HTMLを直接書く場合の扱いです。

## コメント

`<!--` と `-->` で囲んだところは表示されません。書く人のためのメモに使います。

```markdown
表示される文。<!-- ここは表示されない --> 続きの文。

<!--
何行でも書けます。
## 見出しを書いても、目次には入りません
-->
```

↓ こう表示されます

表示される文。<!-- ここは表示されない --> 続きの文。

<!--
何行でも書けます。
## 見出しを書いても、目次には入りません
-->

- 設定 `markdown.allow_html` に関わらず使えます
- **消えるのは表示だけです。** 編集画面やファイルからは読めるので、秘密は書かないでください
- 行頭から書いたコメントの閉じ `-->` を忘れると、そこから最後までが表示されなくなります
- 箇条書きの項目の間に行頭から書くと、箇条書きがそこで2つに分かれます
- PukiWiki記法では `//` で始まる行がコメントです

## HTMLを直接書く

**既定では書けません**（タグごと文字として表示されます）。

```markdown
<span class="x">文字</span>
```

↓ こう表示されます → <span class="x">文字</span>

管理者が設定 `markdown.allow_html` で許可すると書けます。

| 設定 | 書いたHTMLの扱い |
|---|---|
| `false`（既定） | 一切通らない。文字として表示される |
| `true` | **表示のためのタグだけ**通る。`<script>` や `<style>`、`onclick=`、`javascript:` などは文字になる |
| `all` | すべて通る |

**編集できる人を全面的に信頼できる場合以外は、`all` にしないでください**
（[本文に書くHTMLの扱い](/Tech/HtmlPolicy)）。飾りたいだけなら、設定に関わらず動く
[プラグイン](/Syntax/Plugin/color)（`&color()` `&size()` など）が使えます。
