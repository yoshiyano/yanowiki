# note — 中身を囲んで目立たせる

| 使える記法 | |
|---|---|
| ブロック `#note()` | ○ |
| インライン `&note();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

囲んだ中身を目立たせます。お知らせ・ヒント・注意書きに使います。

### 書きかた

```pukiwiki
#note(){{ 中身 }}
#note(type=warn){1行の中身}
&note(type=tip){文中の補足};
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `type` | `info` / `tip` / `warn` | `info` | 枠の種類（位置引数でも書ける。それ以外の値は `info` として扱い、エラーにはならない） |
| `label` | 任意の文字 | 種類ごとの既定（お知らせ・ヒント・注意） | 左上に出す見出しの文字 |

中身にはほかの記法やプラグインを書けます。

### 表示例

```pukiwiki
#note(){お知らせの中身です。}
#note(type=tip){ヒントの中身です。}
#note(type=warn, label="やってはいけないこと"){データを消す前に確認してください。}
```

#note(){お知らせの中身です。}

#note(type=tip){ヒントの中身です。}

#note(type=warn, label="やってはいけないこと"){データを消す前に確認してください。}

出力は `<div class="note note-warn"><div class="note-label">…</div>…</div>` の形です。

複数行の中身:

```pukiwiki
#note(type=tip){{
**太字**や[リンク](/)、箇条書きも使えます。

- ひとつめ
- ふたつめ
}}
```

#note(type=tip){{
**太字**や[リンク](/)、箇条書きも使えます。

- ひとつめ
- ふたつめ
}}

文の中では `<span class="note-inline note-tip">` になります:
この処理は時間がかかります &note(type=tip){数分かかることがあります}; のでご注意ください。

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
