# 表記の変換

使いかたは [ページ編集](/UsageGuide/Edit/Page#書きかたを変える表記の変換) にあります。このページは仕組みの説明です。

編集画面の**表記ボタン**（タブの行の右端）から、ページの本文を PukiWiki記法 ⇔ Markdown に
変換して、書きかたを移します。変換そのものは `wikilib.markupconv`、画面とファイルの置き換えは
`wikilib.markupswitch` です。

## 流れ

送り先はどれもページ自身のURLで、`cmd=convert` に `step` を添えて区別します。

| 操作 | `step` | 動き |
|---|---|---|
| 表記ボタン | なし | 編集画面の今の本文を受け取り、もう一方の書きかたへ変換する。変換先を `=名前.拡張子` に書き出し、管理ページを返す |
| ［確定］ | `apply` | `=` のファイルの中身でページを保存し直し、元の拡張子のファイル・`=` のファイル・書きかけを消す。編集画面を開き直す |
| ［やめる］（Esc） | `cancel` | `=` のファイルを消して、編集画面を開き直す（書きかけは残る） |

権限は編集（`W`）と同じです。編集画面へ戻るときは、連続編集のあとと同じ道
（`render_edit` の `_reopened`）で開き直します。

### 本文の受け取りかた

表記ボタンは、編集画面のボタンのフォーム（`#edit-actions`）の送信ボタンです。保存と同じく、
書きかけを預けてから `from_draft=1` で送ります（`editor.js` の submit。長い本文も分けて
預けられます）。サーバーは `editor.posted_source` で本文を読みます。

### 変換先のファイル（`=` で始まる名前）

`A.txt` の変換先は同じフォルダの `=A.md`、フォルダの入口 `X/index.txt` なら `X/=index.md` です。
`=` で始まる名前はページ名に使えないため（`paths.is_valid_pagepath`）、ページの列挙・取り込み・
ページ一覧・ファイル一覧のどれにも拾われません（ロードマップで設計者が決めた形）。

- 管理ページを開くたびに変換し直し、上書きします
- ページを消す（`pagesave.remove_page`）・名前を変える（`pagerename` のページの移動）ときは、
  一緒に消します。フォルダごと動かすときは、フォルダと一緒に付いていきます
- 変換の材料を集めるとき（`markupconv.collect_referenced_anchors`）も、`=` で始まる名前は読みません

### 確定のとき

- 保存は `save_page(..., merge=False)` です。直前の保存とまとめず、変換を1回の保存として
  履歴に残すので、変換前の内容へ戻せます
- `&date;` などの保存時の置き換え（`save_time_replace`）は、ふつうの保存と同じく行います

## 設計者が選んだこと（2026-11-15）

- 変換するのは**編集画面の今の本文**（保存していない書き換えを含む）
- 管理ページでは**見るだけ**。直すのは確定したあと、編集画面で
- ［確定］で**その場で置き換える**
- 本文を変えずに拡張子だけを変える「書きかた」の選択は、**新しいページのときだけ**出す

## クロコの実装例（設計者は未確認）

- 管理ページは編集画面の枠組み（`editor.css` のタブ・2枚の欄）を使い、`editor.js` は読み込まない。
  プレビューは同名ファイルの整理（`solvedup.render_previews`）と同じ手順で描く
- 開くと「変換後」のタブを選んでおく。失われるものの一覧は折りたためる枠に出す
- 次のときは断って編集画面へ戻す
  - 新しいページ（変換するものが無い）
  - 編集中に、ほかの場所でページが保存されていた（保存すれば競合になる状態）
  - 同じ名前の、変換先の書きかたのファイルが既にある（ページの重複。上書きしてしまうため）
  - ［確定］のとき、開いてからページか `=` のファイルが書き換えられていた（本文のハッシュで照合）
- 外部エディタとつないでいるあいだも、表記ボタンを出す（設計者の指示、2026-11-18）。
  表記ボタンで離れるときは、一時中断と同じく `bye` を送ってエディタのバッファを閉じる
  （`editor.link.js` の `leavesEditing`。管理ページは連動しないので、`reload` だと戻りを待ってから
  閉じることになる。クロコの実装例）。編集画面に戻れば、つなぎ直して変換後の書きかたで開き直す
- 新しいページでは、表記ボタンを押せなくする

## まだ無いもの

- Markdown の表示側は、まだ注釈 `^[…]` を読みません。PukiWiki記法の `((…))` を変換すると、
  Markdown のページでは文字のまま出ます（`markupconv` の冒頭）
