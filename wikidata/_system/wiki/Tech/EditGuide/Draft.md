# 一時保存

**入力が30秒止まると、そこまでの本文を確認なしで預かります。**
一覧から別のページを選んだときも同じように預かります。

「保存しますか？」と訊かれるより、黙って預かっておいて、戻ってきたら
続きから書けるほうが素直だと考えたためです。預かっていることは、
一覧の赤い太字で分かります。

置き場所は `wikidata/<Wiki名>/pageinfo/draft/` で、ファイル名の付けかたは
[バックアップ](/Tech/EditGuide/Save#バックアップ差分の記録) と同じです。
更新履歴にもバックアップにも残りません。**保存の代わりではなく、退避です。**

`<ページ名>.draft`（本文）と対で、`<ページ名>.draft.origin`（預けた時点の
本文のハッシュ）も置かれます。後者は
[競合の判定](#競合の判定は書きかけの元になった内容を基準にする) に使い、
競合したときは[統合する画面](/Tech/ConflictMerge)へも引き継がれます。

| きっかけ | 動き |
|---|---|
| 入力が30秒止まる | `cmd=draft` で預ける（書いている最中なので、本文は返さず204で終える） |
| 一覧から別のページへ移る | 預けてから移動する |
| 編集画面を開く | 預かりがあればそれを表示し、知らせを出す |
| 保存する | 預かりを消す |
| 「一時中断（ESC）」を押す | `cmd=pause` でいまの内容を預けて、閲覧画面へ戻る |
| 「内容破棄」を押す | `cmd=discard` で預かりを消して、閲覧画面へ戻る |
| 本文を元に戻して預ける | 預かりを消す（同じ内容を赤くしても意味がない） |
| ページを削除する | 預かりを消す |

## 保存は本文を送らない

保存のとき、本文はもう一度送りません。`from_draft=1` だけを送り、サーバーは
**預かってある書きかけをそのままファイル**にします。4万バイトほどのページで、
保存の送信は 113713 バイトから **36バイト**になりました。

預かりが無い場合は、いま保存されている内容をそのまま使います。書きかけは
保存されている内容と同じになった時点で解かれるので、**無いことは「変えていない」**
を意味します。JavaScript が動かない場合は、従来どおり本文をフォームで送ります。

## 預かれなかったときは必ず知らせる

黙って続けると、預かってもらえたつもりで書き続けたぶんが、保存のときに
失われます。断られた理由はその場に出し、成功と区別が付くようにします。

長い本文は1回のPOSTに収まらないので、[何回かに分けて送ります](/Tech/EditGuide/ChunkedUpload)。

## 競合の判定は「書きかけの元になった内容」を基準にする

競合の判定（`origin`）は、**書きかけが無ければ**保存されているファイルを
基準にします。**書きかけがあれば、それを預けた時点の本文のハッシュ**
（`.draft.origin`）をそのまま使います（今のファイルへ最新化し直しません）。

ここを毎回最新化してしまうと、一時中断→再開のあいだに他の誰かがページを
更新していても、`cmd=edit`で開き直すたびに`origin`がその更新後の内容へ
すり替わり、保存時の競合検出（`sent_hash != source_hash(original)`）を
すり抜けてしまいます。書きかけを書き始めてからの更新のほうを、預かった
時点の内容と比べて見つける必要があるためです。

一覧以外の方法でページを離れる場合（ブラウザの戻る・URL直接入力など）は、
これまでどおり確認が出ます。
