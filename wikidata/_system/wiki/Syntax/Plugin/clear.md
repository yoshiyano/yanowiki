# clear — 画像などの回り込みを止める

| 使える記法 | |
|---|---|
| ブロック `#clear()` | ○ |
| インライン `&clear();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

[img](/Syntax/Plugin/img) などで画像を左右に回り込ませたあと、回り込みを止めたい位置に置きます。
本家PukiWikiの `clear` の移植で、引数はありません。

### 書きかた

```pukiwiki
#img(logo.png, right)

#clear()

回り込みが終わった後の文章です。
```

`<div class="clear"></div>`（`clear: both;`）を出力するので、これより後ろは左右どちらの回り込みも受けません。
画像のあとで止めるだけなら、`#img(, clear)` でも同じことができます。

### エラーについて

引数を書くとエラーになります。インライン（`&clear();`）でもエラーです。

```pukiwiki
#clear(foo)
```

#clear(foo)

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
