# 共通の書きかた

#code()

**記法によらず、どのページでも同じ書きかた**です。記法ごとの書きかたは
[PukiWiki記法](/Syntax/PukiWiki) と [Markdown記法](/Syntax/Markdown) をご覧ください。

## プラグインの呼びかた

用意されている機能をページに差し込む書きかたです。プラグインの一覧と引数は
[プラグイン](/Syntax/Plugin) をご覧ください。

### 段落として置く（ブロック）

行の先頭に `#` とプラグイン名を書きます。

```pukiwiki
#contents()
```

**`#` のあとに空白を入れないでください**（Markdownのページでは見出しになります）。

| 書きかた | 意味 |
|---|---|
| `#name()` | 引数なし |
| `#name(引数)` | 引数つき |
| `#name(引数){中身}` | 1行の中身つき |
| `#name(引数){{` … `}}` | 複数行の中身つき |

```pukiwiki
#note(type=warn){{
複数行の中身です。

空行も入れられます。
}}
```

↓ こう表示されます

#note(type=warn){{
複数行の中身です。

空行も入れられます。
}}

- 中身に `{{{` のような波括弧が含まれる場合は、**それより多い数**で囲みます（`{{{{` … `}}}}`）
- **中身にページへのリンクを書かないでください。** ページの名前を変える（[ファイル一覧](/FilesGuide)）ときのリンクの自動修正が、
  中身を対象にしないためです

ブロックプラグインは、箇条書きや引用の中でも動きます。

```
- 通常の項目
- #note(type=tip){項目の中のプラグイン}
```

↓ こう表示されます

- 通常の項目
- #note(type=tip){項目の中のプラグイン}

### 文の中に置く（インライン）

`&` で始めて `;` で終わります。

```pukiwiki
ここは &note(type=tip){補足}; です。
```

↓ こう表示されます

ここは &note(type=tip){補足}; です。

| 書きかた | 意味 |
|---|---|
| `&name();` | 引数なし |
| `&name(引数);` | 引数つき |
| `&name(引数){中身};` | 中身つき |

**末尾の `;` が無いと、ただの文字として表示されます。**

### 引数の書きかた

かっこの中はカンマ区切りです。`名前=値` の形も使えます。

```pukiwiki
#note(warn)                      位置で指定する
#note(type=warn)                 名前で指定する
#note(type=warn, label="注意")    両方を並べる
```

位置で指定するとき、途中の引数は空けて飛ばせます。

```pukiwiki
#ls(, , TITLE)                   1つ目・2つ目は既定のまま、3つ目だけ指定する
```

**カンマや `=` を値に含めたいときは、`"`（二重引用符）か `'`（単一引用符）で囲みます。**

```pukiwiki
#note(type=warn, label="カンマ, を含む値")
```

↓ こう表示されます

#note(type=warn, label="カンマ, を含む値"){引用符で囲めば、値にカンマを入れられます。}

### プラグインの中にプラグインを書く

**中身に記法や別のプラグインを書けるかどうかは、プラグインごとに違います**（各プラグインのページに
あります）。書けないプラグインでは、そのまま文字として出ます。

`note` は書けるプラグインです。中身の記法は、そのページの記法です（下の例はMarkdown。
PukiWiki記法なら `''強調''` と `[[リンク>/]]`）。

```pukiwiki
#note(type=tip){**太字**や[リンク](/)が使えます}
```

↓ こう表示されます

#note(type=tip){**太字**や[リンク](/)が使えます}

### うまく動かないとき

**赤い枠のエラー**は、書きかたの誤りか、そのプラグインが無いかです（枠の中に説明が出ます）。
存在しないプラグインを呼ぶとこうなります。

#nosuchplugin()

- 「部分プレビューでは処理されません」は、目次のようにページ全体を見るプラグインです。
  見出し単位の編集のプレビューでは出ませんが、ページを開けば表示されます
- エラーが出ても、ページの他の部分は普通に表示されます
- プラグインを追加・変更しても、サーバーの再起動は要りません

## リンクとファイルの指しかた

リンクの書きかたは記法で違いますが（PukiWiki記法 `[[文字>リンク先]]`、Markdown `[文字](リンク先)`）、
**リンク先の解決のしかたは共通**です。見分けるのは、**`/` で始まるか**と**拡張子が付いているか**です。

### `/` から始める＝Wikiの中の絶対パス

```
/UsageGuide          このWikiの UsageGuide ページ
/Tech/Reference      階層の下のページ
/                    トップページ
```

どのページから見ても同じ場所を指します。**迷ったら `/` から書いてください。**
まだ無いページを指すと、たどった先から作れます。

### `./` `../` を付ける＝そのページから見た相対パス

**`./` や `../` で始めたときだけ相対パス**です。起点はいま書いているページ自身です（親フォルダではありません）。
`/foo/bar` に書いた場合：

| 書きかた | 指す先 | |
|---|---|---|
| `./uha` | `/foo/bar/uha` | そのページの下 |
| `../piyo` | `/foo/piyo` | 1つ上から |
| `../age/ten` | `/foo/age/ten` | 1つ上から下りる |

`..` がトップより上に行こうとした場合は、トップで止まります。

### `/` も `./` も付けない＝トップからの絶対パス

**`./` を付けない名前は、トップからの絶対パス**です（`/` を付けたのと同じ）。

| 書きかた | 指す先 |
|---|---|
| `moge` | `/moge` |
| `abc/def` | `/abc/def` |

PukiWikiの文書の `[[FrontPage]]` などを、そのまま読めるようにするための決まりです。
**`moge` と `./moge` は違う意味です。** そのページの下を指すときは `./` を付けてください。

### 拡張子が付いていれば添付ファイル

```
logo.png             このページに添付した logo.png
```

末尾が拡張子の形（`.` のあとに英数字1〜6文字）のものは**添付ファイル**です。
そのため、`memo.txt` のような名前のページは作れません。

添付ファイルの置き場所は、ページのパスをなぞります。

| ページ | 添付の置き場所 |
|---|---|
| `index`（トップ） | `attach/index/` |
| `Tech/Reference` | `attach/Tech/Reference/` |
| `Tech/index`（`/Tech`） | `attach/Tech/index/` |

**ページ名を書かなければ、いま書いているページの添付**です。ページ名の部分の読みかたは、
上のページの指しかたと同じです。`/foo/bar` に書いた場合：

| 書きかた | 指す先 |
|---|---|
| `img.jpg` | `/foo/bar` に添付した `img.jpg` |
| `./img.jpg` | `/foo/bar` に添付した `img.jpg` |
| `../img.jpg` | `/foo` に添付した `img.jpg` |
| `../bbb/img.jpg` | `/foo/bbb` に添付した `img.jpg` |
| `bbb/img.jpg` | `/bbb` に添付した `img.jpg` |
| `/bbb/img.jpg` | `/bbb` に添付した `img.jpg` |
| `/img.jpg` | トップページに添付した `img.jpg` |

置き場所を直に指したいときは `/` から書きます。

```
/.attach/index/logo.png
```

添付ファイルが無いとき、閲覧の権限が無いときは、`File not found`（404）が返ります。

### 書き換えられないもの

次のものはそのまま残ります。

- 外部URL（`https://example.com/`）
- ページ内の見出しへのリンク（`#見出し名`）
- メールや電話（`mailto:` / `tel:`）
- すでに `=Wiki名` を含んでいるもの

### 別のWikiを見ているときも大丈夫

`/=team/` のように別のWikiを見ている間は、`/` から始まるリンクもそのWikiの中を指します。
サブパスに設置されている場合（`https://example.com/wiki/` の下など）も、接頭辞は自動で補われます。
**書くときにWiki名を気にする必要はありません。**

## ページの名前のルール

**（1）`=` と `.` で始まる名前は使えません**（フォルダの名前も同じ）。システムが使う記号です。

| 記号 | 使いみち |
|---|---|
| `=` | 別のWikiを指定する目印（例: `/=team/`） |
| `.` | システムのファイル用（例: `/.theme/base.css`） |

**（2）拡張子の形で終わる名前は使えません**（`memo.txt` `bar.jpg` `v1.2` など）。
リンクに書くと[添付ファイル](#拡張子が付いていれば添付ファイル)と見なされるためです。

## 特別な名前のページ

次のページ名は決まった用途で使います（中身はふつうのページです）。

| ページ名 | 用途 |
|---|---|
| `index` | フォルダの入口。`/Tech` でアクセスすると `Tech/index` が開く |
| `mainmenu` | サイドバー上段のメニュー |
| `submenu` | サイドバー下段のメニュー |

`mainmenu` と `submenu` は、管理者の設定で別の名前に変えられます。
