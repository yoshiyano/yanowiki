# login — ページの中でログイン・ログアウト・パスワード変更・アカウント作成をする

| 使える記法 | |
|---|---|
| ブロック `#login()` | ○ |
| インライン `&login();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

`#login()` は、ログイン・アカウント作成・パスワード変更・ログアウトのフォーム一式をページに置きます。
`&login();` は、いまログインしている人の名前を出すだけです。
ヘッダの「ログイン」リンクが開く `/.login` も、中身は `#login()` と同じフォームです。

### 書きかた

```pukiwiki
&login();
&login(id);
#login()
#login(){会員限定ページです。ログインしてください。}
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `id` | 単語を書く | 表示名を出す | `&login();` の表示をIDにする（`#login()` では無視） |

`#login(){中身}` の中身は、フォームの上に案内文として出ます（記法も使えます）。

### `&login();`

表示名（`name`。無ければ `uid`）を出します。`id` を書くとIDです。未ログインなら、表示名は「来訪者」、IDは「未登録」です。

```pukiwiki
ようこそ、&login(); さん（&login(id);）。
```

→「ようこそ、あやち さん（alice）。」

### `#login()`

全体を `<fieldset class="login">`（見出しは「ログインフォーム」）で囲み、中をタブ（`div.login-tabs`）で切り替えます。タブはCSSだけで動きます。

| 状態 | タブ |
|---|---|
| 未ログイン | 「ログイン」「アカウント作成」 |
| ログイン中 | 「アカウント」「パスワード変更」 |
| ログイン中（管理者・助手） | 上の2つに「管理者メニュー」（`/.admin` と同じ道具の一覧）が加わる |

- 「アカウント」タブには、いまのユーザー（表示名とID）、ログイン状態が続く期間の説明、「他端末からの認証を解除する」ボタン、「ログアウト」ボタンが出ます
- 「他端末からの認証を解除する」は、ほかの端末・ブラウザのログイン状態を取り消します。押した端末はログインしたままです
- 管理者・助手には、承認待ちのアカウントがあれば「承認待ち x人」が赤字で出ます（押すと `/.admin/approvals`）
- パスワード変更の対象は、いまログインしているアカウントだけです
- 同じページに複数書いても、要素の `id` は重なりません

### 送信後の案内

送信すると、いま開いていたページへ戻り、タブの下に結果の案内（`div.login-notice`）が出ます。入力ミスも赤い枠のエラーではなく、この案内で伝えます。

| 操作の結果 | 出る案内 |
|---|---|
| ログイン成功 | 「ログインしました。」 |
| アカウント作成成功 | 「アカウントを作成しました。」 |
| アカウントを申請した（承認制のWiki） | 「アカウントを申請しました。管理者か助手が承認するまで、ログインできません。」 |
| 承認待ちのアカウントでログインしようとした | 「このアカウントは承認待ちです。承認されるまで、ログインできません。」 |
| ログアウト | 「ログアウトしました。」 |
| 他端末からの認証を解除した | 「他の端末のログイン状態を取り消しました。この端末はそのままご利用いただけます。」 |
| ID・パスワードが違う | 「IDかパスワードが違います。」（ロックが近ければ「（ロックまで残り2回）」「（次回失敗したらロックします）」を添える。[アカウントの仕組み](/Tech/Accounts/AuthLog#ロックが近いことの断り)） |
| ロックされている | 「このアカウントはロックされています。管理者に解除を頼んでください。」 |

部分プレビューでもフォームは出ますが、結果の案内は出ません。

### アカウント作成の受け入れかた

「アカウント作成」タブは誰でも使えます。作ったあとの扱いは、Wikiの設定 `account.policy` で決まります。

| 設定 | 作ったアカウント |
|---|---|
| `open`（既定） | そのままログインした状態になる |
| `approval` | 承認待ちになる。管理者か助手が承認するまでログインできない |

作ったアカウントで何を読めて書けるかは [ページごとの権限](/Tech/PagePermissions) で決まります。
設定は [アカウントの仕組み](/Tech/Accounts) の「ユーザ登録の受け入れかた」、フォームの送り先などは [ページの中でログインする](/Tech/LoginPlugin) をご覧ください。

`login` に固有のエラーはありません。書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
