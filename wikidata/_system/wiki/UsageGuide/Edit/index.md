# 編集する

ページを書く・直す・消す方法の入口です。ページを見る・探す方法は [閲覧する](/UsageGuide/Read)、
書く内容（書きかた・プラグイン）は [書きかた](/Syntax) にあります。

## 編集を始める

現在のページを編集するには、ヘッダメニューの「編集」を押します。キーボードでは **Alt+E** でも
編集画面を開けます。「編集」が表示されないページは、編集する権限がありません
（[ページのアクセス制限](/AccessGuide/Privileges#権限が無いとき)）。

#img(ヘッダメニューの「編集」と「新規」>/UsageGuide/Edit/header-menu.png)

ページ全体ではなく、見出しや段落ごとに編集することもできます。編集したい場所を
**Ctrl+Alt+ダブルクリック**すると、その部分だけを編集できます（[セクション編集](/UsageGuide/Edit/SectionEdit)）。

新しいページを作るには、ヘッダメニューの「新規」を押してページ名を入力します。本文中のリンクから
まだ存在しないページを開いた場合は、表示される「このページを作る」を押して作成できます。
ページは、編集内容を保存したときに作られます。

## 何をしたいか

| やりたいこと | ページ |
|---|---|
| ブラウザの編集画面で書く（タブ・ツールバー・書きかた・保存・ページの名前・削除） | [ページ編集](/UsageGuide/Edit/Page) |
| 画像やファイルを添付する | [添付ファイル](/UsageGuide/Edit/Attach) |
| 保存の記録（履歴）を見る・過去の内容へ戻す（すべて・部分的に） | [変更履歴](/BackupGuide) |
| 書きかけを預ける・差分を見る・同時に編集された・消したページを戻す | [ページの履歴管理](/UsageGuide/Edit/History) |
| ページやフォルダの名前を変える・動かす・写す・消す | [ファイル操作](/FilesGuide) |
| 見出しや段落を、その場で直す | [セクション編集](/UsageGuide/Edit/SectionEdit) |
| ページのテキストファイルを、エディタやスクリプトで直接書き換える（書き換えたあとの取り込み） | [ローカルファイルの編集](/UsageGuide/Edit/LocalFile) |
| タイトルの右端に ⚠ が出ている（同じ名前の `.txt` と `.md` がある） | [同じ名前の .txt と .md があるとき](/UsageGuide/Edit/Duplicate) |
| 手元のエディタ（Emacs など）で書く | [エディタ連動の編集](/PageEdit/EditorSyncGuide) |
| AIエージェントに書かせる | [AIとの共同作業](/PageEdit/AI_Collabo) |

ここにない開発者向けの操作（HTTP から取り込む方法など）は、
[平文ファイルの取り込み](/Tech/UpdateDB) にまとめています。

編集画面の仕組みや設計の理由は [編集機能の仕組み（技術ドキュメント）](/Tech/EditGuide) にあります。
