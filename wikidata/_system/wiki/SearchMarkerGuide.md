# 検索・マーカー

ページを探す**検索**と、用語をページをまたいで追いかける**マーカー**の使いかたです。

## 検索する

画面の右上に検索窓があり、その左のボタンで探す範囲（「サイト全体」／「このページ内」）を選びます。
クリックすると範囲が入れ替わり、押したまま動かすとメニューから選べます。

**Ctrl+F**（Mac は ⌘F）を押すと、検索窓に入ります。検索窓に入っているときにもう一度押すと、
ブラウザのページ内検索になります。

### サイト全体から探す

**検索窓を選ぶと、条件を指定するパネルが出ます。** 条件は結果のページでも変えられ、
URLに残るので、その検索結果をそのまま人に伝えられます。

#img(「テーマ」で検索した結果>search.png)

| 項目 | できること |
|---|---|
| 検索語 | 空白で区切ると複数の語を指定できます。空白を含む語は `"..."` で囲みます |
| 条件 | **すべての語を含む**（AND）か、**いずれかの語を含む**（OR）か |
| 対象 | **ページ名と本文** / **ページ名だけ** / **本文だけ** |
| 絞り込み | ページ名の一部を書くと、その範囲だけを探します（例: `Tech/`） |

- 閲覧の権限が無いページは、結果に出ません
- 結果の**見出しか抜粋を押すと、そのページの該当箇所へ移ります。** 探した語は色付きで示され、
  そのままページ内検索に引き継がれます
- 結果は**20件ずつ**出ます（見出しに「41 件 21〜40件目」のように全体の件数も出ます）。
  ページ番号はURLに残るので、ブラウザの「戻る」で前の結果に戻れます

#### ページ名のワイルドカード

ページ名には次の記号が使えます（検索語の欄でも絞り込みの欄でも同じ）。本文の検索には効きません。

| 記号 | 意味 |
|---|---|
| `*` | 任意の文字列（長さ0でも可、`/` にも一致します） |
| `?` | 任意の1文字 |

| 書きかた | 見つかるもの |
|---|---|
| `Tech/*` | `Tech` フォルダの下にあるページすべて |
| `*Guide` | どの階層でも、名前が Guide で終わるページ |

### いま開いているページの中を探す

範囲を「このページ内」にすると、その場で本文を探します。

- 一致した箇所がすべて色付きで示され、右側に**一致箇所の一覧**（前後の文章つき）が出ます
- 検索窓の横の **‹ ›**、または Enter / Shift+Enter で一致箇所を順に辿れます
- Escape キー、または一覧の × で解除します

## マーカーで用語を追う

マーカーは、**複数の用語に色を付けて、ページをまたいで**追いかける機能です。
ヘッダのメニュー（テーマによって「マーカー」のリンクとスイッチ・セレクトボックス）から使います。

#img(3つの用語を登録したところ>marker-page.png)

### 用語を登録する

**`Alt+M`** か、メニューの「マーカー」で操作用のウィンドウが開きます。

&img(操作用のウィンドウ>marker-panel.png);

- 入力欄に用語を入れて「追加」で登録します（1つの用語セットにつき10個まで）
- 色のボタンでパレットが開きます。一覧の「×」で削除します

登録した用語は、**同じブラウザで開くどのページでも**自動で光ります。
光るのは本文とフッタだけで、メニューや検索フォームなどは対象外です。

### 色を選ぶ

32色のパレットから選びます。**プリセット20色**（淡いトーン）と、✎で色相・彩度・明度を
決める**自分の12色**です。新しい用語には、まだ使っていない色が自動で選ばれます。

### 見つけた場所を移動する

入力欄の外にフォーカスがあるとき、次のキーが使えます。

| キー | 動き |
|---|---|
| `1`〜`9`・`0` | アクティブな用語を切り替える（1番目〜10番目） |
| `←` / `→` | アクティブな用語の、隣の一致へ移動 |
| `↑` / `↓` | 今の画面の外にある次/前の一致へジャンプ |

用語を切り替えても先頭には戻らず、いま見ている場所の近くから続きます。

### 用語セットを使い分ける

用語をまとめて**用語セット**として持てます。操作用のウィンドウの上のプルダウン（またはメニューの
セレクトボックス）で、切り替え・新規作成・名前の変更・削除をします。

メニューのスイッチで、マーカー全体を有効/無効にできます。無効の間も `Alt+M` は使えます。

### 覚えておくこと

- **状態はこのブラウザだけに残ります**（サーバーには保存しません。ログインしていても同じです）
- プライベートブラウズなど保存できない環境では、閉じると消えます
- **24時間動かしていない用語は、次に開いたときに消えます。** その用語の一致へ移動すると
  「使った」扱いになります
