# スロットHTML のテーマ

Jinja2 を通さずに描くテーマの形式です。テーマは式・ループ・`<script>` を持たないふつうの HTML で、
本体が値と部品を埋める場所に目印（`data-text`・`data-slot`・`<wiki-slot>` など）を付けておきます。
本体は **HTML5 パーサで解析 → 許可リストでサニタイズ → 目印を埋める** の順に処理するので、
テーマからサーバのコードは動きません。

書きかた・スロット・値の名前・許可リストは、wikiThemes の仕様案（`wikiThemes/slot/SPEC.md`）に従います。書きかたの案内は [スロット型のテーマでデザインを変える](/SlotThemeGuide) にあります。
仕様案はクロコの案で、設計者は書きかた・名前・許可リストを確認していません。

## 置き場所で分ける

Jinja2 のテーマは、閲覧者が cookie で選べば誰でも描かせられます。そのため、スロットHTML は
Jinja2 が一切読まない別のフォルダに置きます（Wiki設計者の指示「置き場所で分ける方針で」、2026-10-03）。

| 場所 | 中身 |
|---|---|
| トップレベルの `slottheme/` | 全Wiki共通のスロットHTML |
| `wikidata/<Wiki名>/slottheme/` | そのWiki固有のスロットHTML（共通より先に探す） |

テーマは `<名前>.html`、またはフォルダ形式の `<名前>/<名前>.html` です。テーマ名の一覧に入るので、
`theme.name`・テーマのセレクタ（cookie）で、Jinja2 のテーマと同じように選べます。

## 資材

CSS・画像・フォントは `/.slottheme/<テーマ名>/<ファイル名>` で配ります。`.html`・`.js`・`.svg` は配りません。
CSS は、下の検査で取り除いてから配ります（結果はファイルの更新日時ごとに覚えておく）。
テーマからは `data-asset="名前"` で指し、`common:` で始まる名前は共通の `/.theme/` の資材を指します。

## CSS の検査

CSS は tinycss2 で読み、次のものを取り除きます（`slottheme.clean_css`）。tinycss2 の導入は設計者の決定（2026-10-05）、
取り除くものの範囲はクロコの案です（設計者は未確認）。

| 取り除くもの | 理由 |
|---|---|
| `@import`・`@namespace` | 検査を通さない CSS を読み込める |
| 外への `url()`・`image-set()` の文字列 | 閲覧者の情報がよそへ漏れる。行き先はテーマの資材の名前（`/` を含まない）と `data:` の画像（svg も可）だけ |
| `expression()`・`behavior`・`-moz-binding` | 古いブラウザでスクリプトが動く |

画面を覆う `position: fixed` などは、正しい使いかたが多く CSS だけでは偽装を防げないので、検査しません。
文字のエスケープ（`u\72l(`）は、tinycss2 が仕様どおりに解いてから見ます。

## 検索結果は Jinja2 のテーマで描く

検索結果のようにテンプレートを名指しする画面は、スロットHTML を選んでいても Jinja2 のテーマ
（`theme.name`、それもスロットHTML なら `base`）で描きます。Wiki設計者の「検索結果は jinja2 で記述すれば良い。
問題にしているのはユーザが設置するテーマについてのみ」（2026-10-04）。

## クロコの実装例（設計者は未確認）

- フォルダの名前は仕様案の仮の名前（`slottheme`）のまま
- 同じ名前の Jinja2 のテーマがあれば、Jinja2 のほうを描く
- `data-asset` の名前がスロットHTML のフォルダに無ければ、共通の `/.theme/` の資材を指す
- 部品（検索窓・目次など）のマークアップは `theme/base.html` と同じ class で本体が出す。base.html の部品を
  直したら `wikilib.slottheme.make_slots` も合わせる

## 実装の置き場所

| 何を | どこが |
|---|---|
| 解析・サニタイズ・目印の埋めかた・CSS の検査・資材の配信 | `_sys/wikilib/slottheme.py` |
| どちらの形式で描くか | `themes.render_theme`・`themes.jinja_theme_exists` |
| 自動テスト | `tests/test_slottheme.py` |
