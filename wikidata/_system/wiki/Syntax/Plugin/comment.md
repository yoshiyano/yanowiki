# comment — コメント投稿フォーム

| 使える記法 | |
|---|---|
| ブロック `#comment()` | ○ |
| インライン `&comment();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

コメント投稿フォームと、投稿済みコメントの一覧を置きます。
投稿すると、このページの本文（`#comment()` の中身）に1行書き足して保存し直します。

### 書きかた

```pukiwiki
#comment()
#comment(見出し, noname, nodate, newbottom)
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `legend` | 文字列 | `コメント`（**常に1番目**） | 枠の左上（`<legend>`）に出す見出し |
| `noname` | 単語を書くだけ | 出す | 名前欄を隠し、コメント行にも名前を残さない（`msg 日時` の形になる） |
| `nodate` | 単語を書くだけ | 付ける | 投稿日時を付けない |
| `newtop` | 単語を書くだけ | （既定の動き） | 新しいコメントを上（フォームの直下）に追加する |
| `newbottom` | 単語を書くだけ | 書かない | 新しいコメントを一覧の末尾に追加する（本家PukiWikiと同じ並び） |

`legend` 以外は好きな順で書けます。候補に無い単語（`#comment(たいとる, xyz)` の `xyz`）はエラーです。

### 中身（`{{ }}`）

中身は書かなくてかまいません。最初の投稿のときに書き足されます。

```pukiwiki
#comment(){{
- 最初のコメント -- 名無しさん &new{2026-08-28 (金) 09:00:00};
}}
```

- 投稿日時は [new](/Syntax/Plugin/new) で囲んで書き足されるので、新しいコメントには ` New!` の印が付きます。
  5日を過ぎると `&new` が外れて日時の文字だけになります（Markdownのページでは `&new(){…};` の形で書き足されます）

- フォームと一覧は1つの `<fieldset class="comment-fieldset">` の枠に入り、間は `<hr>` で区切られます
- 名前はただの文字列として書き足されます（リンクにはなりません）。空欄なら「名無しさん」です
- 名前欄には前回の名前が入っています（そのブラウザの localStorage に覚えるだけで、サーバには送りません）。空にして投稿すると忘れます
- PukiWiki記法のページでは、コメントの先頭に `-` や `--` を書くと、そのぶん深い返信になります。Markdownのページでは階層にならず、ふつうの文になります
- 1つのページに複数置くと、それぞれ別にコメントを溜めます

### 投稿を断られるとき

閲覧できるページなら、編集の権限が無くても、ログインしていなくても投稿できます（[ページごとの権限](/Tech/PagePermissions)）。
次の場合は、ページを変えずに断ります（赤い枠ではなく、短い文だけの画面）。

| 状況 | 応答 |
|---|---|
| コメント欄が空 | 何もせず、ページの表示へ戻る |
| フォームを開いてから、ページが別の場所で更新されていた | 409。ページを読み直してから投稿し直す |
| 編集で `#comment(...)` の位置がずれ、書き足す場所が見つからない | 409 |
| 閲覧する権限が無い | 403 |
| ページがもう無い | 404 |

[セクション編集](/Tech/SectionEditing)の部分プレビューでは、投稿できない場合があります。
