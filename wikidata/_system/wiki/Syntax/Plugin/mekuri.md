# mekuri — 中身を色で隠し、クリックでめくって見せる

| 使える書きかた | |
|---|---|
| ブロック `#mekuri(){{ }}` | ○ |
| インライン `&mekuri();` | ○ |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

中身を指定した色で塗りつぶして隠します。めくれる人がクリックすると、**右から徐々に**（既定は1.5秒）開いて中身が見えます。暗記用の答え隠しや、ネタバレの伏せ字に使います。

### 書きかた

```pukiwiki
#mekuri(color){{
複数行の中身
}}
&mekuri(color){文中の一部};
&mekuri(red, 3000){3秒かけてめくる};
&mekuri(red, 500, "alice g:staff"){0.5秒でめくる・めくれる人を限る};
&mekuri(, "=w"){このページを編集できる人だけがめくれる};
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `color` | 色の指定 | `gray` | 塗りつぶしの色。[color](/Syntax/Plugin/color) と同じ書きかた（`red` のような色名、`#f00`／`#ff0000`／`#ff0000cc`。`rgb()` のような丸括弧の関数表記は不可） |
| `speed` | 整数（ミリ秒） | `1500` | めくる時間。整数だけが書ける（`0` なら一瞬で開く） |
| `auth` | ログインID・`g:グループ名`（空白区切り）、または `"=w"` | 閲覧できる人は誰でも | めくることができる人 |

- `color` は1番目に書きます。`speed` と `auth` は、どちらの順でも、片方だけでも書けます（整数なら `speed`、それ以外は `auth` と読みます）
- **数字だけの文字列は、最初の1つが `speed` になります。** 数字だけのログインIDを `auth` にするときは `auth=12345` と名前を付けて書きます（`&mekuri(red, 500, 12345)` のように `speed` のあとに書いても通ります）
- ブロックは `{{ … }}` で書きます。インラインは `{ … }` です
- `auth` に複数書くときは引用符で囲みます（`"alice g:staff"`）。登録されていないIDやグループを書くとエラーになります
- **`"=w"` と書くと、このページの編集権限（W）がある人だけ**がめくれます。**引用符で囲んでください**（`auth="=w"` でも可）。囲まないと `=w` が名前付き引数の書きかたと読まれ、「知らない引数です」のエラーになります
- めくれない人には、塗りつぶされたままの表示だけが出ます（クリックしても開きません）。目印として、覆いの**補色の1px枠**が付きます。gray・black・white のような無彩色には補色が無いので、**明るさを反転した色**の枠にします（明るさが中間の灰色は、反転しても差が出ないため、黒か白のうち遠いほうにします。既定の `gray` は黒の枠）。補色の計算に対応していない古いブラウザでは、有彩色の枠は覆いと同じ色になって見えません）
- いちど開くとそのまま見えます。ページを再読み込みするとまた隠れます
- めくれる人は、キーボード（Tab で移動して Enter／Space）でも開けます
- 中身にはMarkdown記法・ほかのプラグインを書けます。ブロックの中にブロックのプラグイン（`#note(){{ }}` など）を入れるときは、外側を `{{{ … }}}` にします

### 隠した中身の扱い（読まれにくさ）

中身は、ページのソースを見ても直接は読めない形（暗号ではない、簡単な変換）でHTMLに入っています。JavaScript が読める人なら元に戻せるので、**強く守りたい内容には使わず**、ページの閲覧権限（[readauth](/Syntax/Plugin/readauth)）で制限してください。

- **`auth` を指定したときは、めくれない人には中身そのものを送りません**（塗りつぶしだけが届きます）。ソースを見ても中身はありません
- `auth` を省略したときは誰でもめくれるので、変換した中身が全員に届きます
- 中身はページを開いたときにブラウザが元に戻し、見えない状態で置きます（隠した部分は本来の大きさで塗りつぶされます）。HTMLソースには中身が無いものの、ブラウザの開発者ツールでは読めます
- 隠している間は、ブラウザ内検索（Ctrl+F）・文字の選択・印刷に中身は出ません
- めくれない人には中身を送らないので、塗りつぶしの大きさは本来の大きさになりません
- 中身の `<script>` は、めくったあとも実行されません。数式（[katex](/Syntax/Plugin/katex)）とコード（[code](/Syntax/Plugin/code)）の表示は、めくったときに描かれます

### 表示例

```pukiwiki
答えは &mekuri(navy){東京}; です。

#mekuri(crimson){{
複数行の
**隠したい**中身
}}
```

生成されるHTML（インラインは `<span>`、ブロックは `<div>`。覆いはCSSの疑似要素で、色は `--mekuri-color` で渡されます。`data-mekuri-d`・`data-mekuri-k` が変換した中身と鍵で、呼ぶたびに値が変わります）:

```html
<span class="mekuri mekuri-inline" style="--mekuri-color:navy" data-mekuri="flip" data-mekuri-d="…" data-mekuri-k="…" tabindex="0" role="button" aria-expanded="false" aria-label="隠された内容。クリックでめくる"><span class="mekuri-dummy"></span></span>
```

`data-mekuri` 以降の属性は、**めくれる人にだけ**付きます。めくれない人のHTMLは `<span class="mekuri mekuri-locked mekuri-inline" style="--mekuri-color:navy"><span class="mekuri-dummy"></span></span>` だけです。

### エラーになる書きかた

| 書きかた | 理由 |
|---|---|
| `&mekuri(red){};` | 中身が無い |
| `&mekuri(bad!){x};` | 色の指定が16進・色名のどちらの形にも合わない |
| `&mekuri(red, nobody){x};` | `auth` に登録されていないIDやグループを書いた |
| `&mekuri(red, 1.5){x};` | `speed` は整数だけ。小数は `auth` として読まれ、IDとして使えない |
| `&mekuri(red, =w){x};` | `=w` を引用符で囲んでいない（`"=w"` と書く） |

詳しくは [共通の書きかた](/Syntax/Common#うまく動かないとき) を参照してください。
