# table — セルの中を複数行で書ける表

| 使える書きかた | |
|---|---|
| ブロック `#table()` | ○ |
| インライン `&table();` | × |

呼びかたのルールは [共通の書きかた](/Syntax/Common#プラグインの呼びかた) をご覧ください。

#code()

セルの中で改行したい表を、複数行で書けるようにします。表計算ソフトからコピーした内容（タブ区切り）を、そのまま表にすることもできます。

### 書きかた

```pukiwiki
#table(){{ 表の中身 }}
#table(tsv){{ 表計算ソフトからコピーした内容 }}
#table(tsv, header){{ 1行目を見出しにする }}
#table(cols="120px | 30% || calc(100% - 200px)", width=100%){{ 列の幅と二重線 }}
```

| 引数 | 値 | 既定 | 意味 |
|---|---|---|---|
| `format` | `pukiwiki` / `tsv` | `pukiwiki` | 中身の書きかた（位置引数でも書ける） |
| `header` | （書くだけ） | 書かない | `tsv` のとき、1行目を見出し行にする |
| `cols` | 列の幅を `\|` で区切って並べる | 内容に合わせる | 列の幅と縦の二重線（[幅と罫線](#幅と罫線)） |
| `width` | `100%`・`600px` など | 内容に合わせる | 表全体の幅 |

### 表の1行を `|\\` で終える書きかた（pukiwiki）

表の1行は、行末の `|\\` が来るまで続きます。途中で改行してよく、セルの中の改行はそのまま改行として表示されます。

```pukiwiki
#table(){{
|~品名|~説明|h\\
|りんご|赤い
甘い
果物|\\
|みかん| 冬の果物 |\\
}}
```

#table(){{
|~品名|~説明|h\\
|りんご|赤い
甘い
果物|\\
|みかん| 冬の果物 |\\
}}

`|` のすぐ前とすぐ後の改行は無視するので、1つのセルを1行ずつ書くこともできます。

```pukiwiki
#table(){{
|りんご
|赤い
甘い
|\\
}}
```

セルの頭の目印と、行の種類は [PukiWiki記法の表](/Syntax/PukiWiki/Table) と同じです。

| 書きかた | 意味 |
|---|---|
| `\|~字\|` | 見出しセル（`th`） |
| `\|>\|` | 右のセルとつなぐ |
| `\|~\|` | 上のセルとつなぐ |
| `LEFT:` `CENTER:` `RIGHT:` | 寄せかた（セルの頭に書く） |
| `COLOR(色):` `BGCOLOR(色):` `SIZE(数):` | 文字の色・背景の色・文字の大きさ（px） |
| `\|h\\` `\|f\\` `\|c\\` | その行を見出し行・フッタ行・書式指定だけの行にする |

- セルの中の文字は、そのページの書きかたで書きます。Markdown のページなら `**強調**` や `[文字](リンク)`、PukiWiki のページなら `''強調''` や `[[リンク]]` です。インラインのプラグイン（`&color(){…};` など）も使えます
- 箇条書き・引用・ブロックのプラグインなども、本文と同じようにセルの中に書けます（下の「セルの中のブロック要素」）
- セルの中に `|` を書くときは `\|` と書きます
- `//` で始まる行は、行と行のあいだに書くとコメントになります。PukiWiki のページでは、セルの中に書いてもコメントになります（Markdown のページのセルでは文字のまま）
- 最後の行の `|\\` は省けます（`|` で終わっていれば1行とみなします）

出力は `<table>` の中に `<thead>`・`<tbody>`・`<tfoot>` を置いた形で、ほかの表と同じ見た目になります。

### セルの中のブロック要素

セルの中には、箇条書き・引用・ブロックのプラグインなど、本文と同じ書きかたができます（`tsv` を除く）。

```markdown
#table(){{
|~手順|~注意|h\\
|- 電源を切る
- ケーブルを抜く|> 抜く前に保存すること|\\
}}
```

Markdown のページでは、次の HTML になります。

```html
<div class="table-plugin">
<table>
<thead>
<tr>
<th>手順</th>
<th>注意</th>
</tr>
</thead>
<tbody>
<tr>
<td><ul>
<li>電源を切る</li>
<li>ケーブルを抜く</li>
</ul></td>
<td><blockquote>
<p>抜く前に保存すること</p>
</blockquote></td>
</tr>
</tbody>
</table>
</div>
```

- 段落が1つだけのセル（ふつうの文字だけのセル）は、段落の余白を付けずに表示します。空行で区切って段落を2つ以上にすると、それぞれ `<p>` になります
- 見出しも書けますが、**目次やページ内リンクの飛び先にはならない、飾りの見出し**になります（`id` を付けません）。Markdown のページで、文字の次の行に `==`・`--` だけを書くと見出しになるのも、本文と同じです
- [include](/Syntax/Plugin/include)・[pagediv](/Syntax/Plugin/pagediv) でセルにページを差し込んだときも、そのページの見出しは飾りの見出しになります（差し込んだページの中の `#contents` のリンクは、飛び先がなくなります）
- [comment](/Syntax/Plugin/comment)・[vote](/Syntax/Plugin/vote) もセルの中に置けます。投稿・投票もできます

### タブ区切り（tsv）

表計算ソフトでセルを選んでコピーし、`#table(tsv){{` と `}}` のあいだに貼り付けます。

```pukiwiki
#table(tsv, header){{
品名	値段
りんご	120
"みかん
（箱）"	980
}}
```

#table(tsv, header){{
品名	値段
りんご	120
"みかん
（箱）"	980
}}

- タブでセルを、改行で行を区切ります。`"` で囲んだセルの中では改行とタブを書けます（`""` は `"` 1文字）。表計算ソフトからコピーすると、この形になります
- セルの中の文字は、そのページの書きかたのインライン記法（強調・リンクなど）だけを展開します。表計算ソフトから貼った値が `-`・`>`・`*` で始まっていても、箇条書き・引用・見出しにはなりません。`~`・`>`・`CENTER:` などの表の目印も、書いた文字のまま表示します
- 空の行は飛ばします。セルの数が足りない行は、右を空のセルで埋めます
- 編集欄でタブキーを押すと次の欄へ移るので、手で書くより貼り付けて使う書きかたです

### 幅と罫線

**列の幅**は `cols` に、左の列から順に `|` で区切って並べます。

```pukiwiki
#table(cols="120px | 30% | calc(100% - 200px)", width=100%){{
|品名|産地|説明|\\
|りんご|青森|赤くて甘い|\\
}}
```

#table(cols="120px | 30% | calc(100% - 200px)", width=100%){{
|品名|産地|説明|\\
|りんご|青森|赤くて甘い|\\
}}

- 書ける値は `120px`・`30%`・`8em` のような単位付きの数（単位を省くと px）、`auto`、`calc()`・`min()`・`max()`・`clamp()` です
- 空欄（`120px | | 80px` の真ん中）の列は、内容に合わせた幅になります。右のほうの列を書かなければ、それらも内容に合わせます
- `%` と `calc(100% - …)` は表全体の幅が基準なので、表全体の幅 `width` も一緒に書きます
- `cols` に幅を書くと、列は中身で押し広げられず、長い語は折り返します

**縦の二重線**は、`cols` の区切りを `||` にしたところに引きます。先頭・末尾に `||` を書くと、表の左右の外枠が二重線になります。幅を決めずに線だけ引くときは、幅を空欄にします。

**横の二重線**は、表の行と行のあいだに `==` だけの行を書いたところに引きます。表の最初・最後に書くと、上下の外枠が二重線になります。

```pukiwiki
#table(cols="|| | || |"){{
|~品名|~数|~値段|h\\
==
|りんご|3|300円|\\
|みかん|12|480円|\\
==
|合計|15|780円|f\\
}}
```

#table(cols="|| | || |"){{
|~品名|~数|~値段|h\\
==
|りんご|3|300円|\\
|みかん|12|480円|\\
==
|合計|15|780円|f\\
}}

- 結合したセルが線の位置をまたぐところには、線を引きません
- 見出し行（`h`）・フッタ行（`f`）の上下に書いた `==` は、その行と一緒に表の上・下へ移ります
- `tsv` でも、貼り付けたあとに `==` の行を書き足せます（`"=="` と引用符で囲めば、文字の `==` のセルになります）
- セルの中に `==` だけを書いたときは、文字のまま表示されます（Markdown のページで、文字の次の行に書くと見出しになります。上の「セルの中のブロック要素」）

### エラーになる書きかた

| 書きかた | 理由 |
|---|---|
| `#table()` （中身が無い） | 表の中身を書いてください |
| `\|` で始まらない行がある | 表の行は `\|` で始めてください |
| 最後の行が `\|` で終わっていない | 行の終わりは `\|\\` です |
| `#table(pukiwiki, header){{…}}` | `header` は `tsv` のときだけ使えます |
| 書式指定の行（`\|c\\`）しかない | 表に出す行がありません |
| `cols`・`width` に書けない値がある（`1px;color:red` など） | 列の幅（表の幅）には 120px・30%・calc(100% - 200px) のような値を書いてください |
| `cols` に `\|\|\|` のような区切りがある | 列の幅の区切りは \| か \|\| です |

書きかた自体が壊れている場合は、共通のエラーになります（[共通の書きかた](/Syntax/Common#うまく動かないとき) 参照）。
